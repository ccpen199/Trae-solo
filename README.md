# 婚庆服务本地化撮合平台运营系统

## 项目说明
本项目是一个婚庆服务本地化撮合平台，实现商家免费入驻、新人直连、去中介化交易的完整业务闭环。

## 技术栈
- 前端：React 18 + Vite + React Router + Ant Design
- 后端：Node.js + Express + SQLite
- 数据库：SQLite (文件数据库 data/app.sqlite)

## 端口配置
基于项目ID may-89104 (tail4=9104):
- 前端端口: 49104 (40000 + 9104)
- 后端端口: 59104 (50000 + 9104)

## 快速启动
```bash
# 安装依赖
./scripts/install.sh

# 启动服务（后台运行）
./scripts/start.sh

# 检查服务状态
./scripts/status.sh

# 停止服务
./scripts/stop.sh
```

## 访问地址
- 前端首页: http://127.0.0.1:49104
- 后端API: http://127.0.0.1:59104/api
- 健康检查: http://127.0.0.1:59104/api/health

## 核心功能模块

### 商家端
- 服务品类管理（摄影/司仪/酒店/婚纱）
- 案例库上传与展示
- 点赞互动排名系统
- 本地化营销活动创建

### 新人端
- 婚期倒推计划表
- 预算智能拆解
- 服务组合比价
- 真实评价过滤（含图文/视频/订单核验）

### 平台管理
- 婚礼筹备知识图谱
- 城市站长协作管理
- 服务商履约保证金监管
