# External Resources Setup

## Scripts
- `external_resources/install_all_projects.sh`: install dependencies for runnable Node projects.
- `external_resources/start_all_projects.sh`: start all pulled projects with automatic non-conflicting port allocation.
- `external_resources/stop_all_projects.sh`: stop all services started by the start script.
- `external_resources/start_control_panel.sh`: start the web control panel page.
- `external_resources/stop_control_panel.sh`: stop the web control panel page.

## Port Policy
- Preferred ports are in `46100-46220`.
- If a preferred port is already in use, `start_all_projects.sh` automatically increments to the next free port.
- Runtime mappings are saved to:
  - `external_resources/.runtime/ports.tsv`
  - `external_resources/.runtime/pids.tsv`

## Service Mapping
- Static preview:
  - `HSK-3.0-Study-Game`, `Android-HSKFlashcardsWidget`, `pinyin_hero`, `nihao`, `Mandarin_Learning_App`, `OpenHSK`, `HanBaoBao`

## Notes
- Unity projects are source projects and need Unity Editor to build/play as native games.
- Some repos are libraries/datasets (not full standalone apps), so they are served as source/static preview.
- Flutter mobile repos (`nihao`, `pinyin_hero`) can be upgraded from static preview to real app run after installing Flutter SDK.
- Android repos require Android Studio / SDK for emulator or APK run; in this setup they are kept as source preview links in the control panel.
- Logs are written to `external_resources/logs/`.

## Mobile-to-Web Preview
- To support browser-only review, mobile-focused projects now have dedicated web preview pages in:
  - `external_resources/mobile_web_versions/Android-HSKFlashcardsWidget/index.html`
  - `external_resources/mobile_web_versions/pinyin_hero/index.html`
  - `external_resources/mobile_web_versions/nihao/index.html`
  - `external_resources/mobile_web_versions/Mandarin_Learning_App/index.html`
  - `external_resources/mobile_web_versions/OpenHSK/index.html`
  - `external_resources/mobile_web_versions/HanBaoBao/index.html`
- The control panel links for these projects open the web preview versions.

## Web Control Panel
- Backend: `external_resources/control_panel/server.py`
- UI page: `external_resources/control_panel/index.html`
- Starts on `127.0.0.1:46250` by default and auto-increments if busy.
- Features:
  - Start all projects (`/api/start`)
  - Stop all projects (`/api/stop`)
  - Live status + clickable URLs (`/api/status`)
