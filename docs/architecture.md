## 2. 核心子系统设计

### 2.1 统一身份认证体系

#### 2.1.1 架构设计

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  用户登录入口│───►│   Keycloak  │───►│ 身份数据源  │
│  (多端统一) │    │  认证服务器  │    │ (多源融合) │
└─────────────┘    └──────┬──────┘    └─────────────┘
                          │
            ┌─────────────┼─────────────┐
            ▼             ▼             ▼
        ┌───────┐   ┌───────┐   ┌────────┐
        │ OAuth2│   │ SAML  │   │ 微信/支付宝│
        │  Token│   │  断言  │   │  身份认证 │
        └───────┘   └───────┘   └────────┘
            │             │             │
            └─────────────┼─────────────┘
                          ▼
                   ┌────────────┐
                   │  会话管理  │
                   │  (Redis)   │
                   └──────┬─────┘
                          ▼
                   ┌────────────┐
                   │ 权限校验   │
                   │ (RBAC+ABAC)│
                   └────────────┘
```

#### 2.1.2 核心功能
- **多认证方式**: 账号密码、短信验证码、人脸识别、数字证书、第三方登录
- **单点登录(SSO)**: 一次登录，全平台访问
- **身份融合**: 多身份源数据融合，建立唯一身份标识
- **权限模型**: RBAC + ABAC 混合权限模型
- **审计日志**: 全量认证审计，支持事后追溯

### 2.3 电子证照全生命周期管理

#### 2.3.1 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                    电子证照管理平台                      │
├──────────┬──────────┬──────────┬──────────┬──────────┤
│  证照签发│  证照存储│  证照使用│  证照核验│  证照注销│
└─────┬────┴────┬─────┴────┬─────┴────┬─────┴────┬─────┘
      │         │          │          │          │
      ▼         ▼          ▼          ▼          ▼
┌─────────┐ ┌───────┐ ┌─────────┐ ┌───────┐ ┌─────────┐
│ 签发流程│ │ IPFS  │ │ 二维码  │ │ OCR+  │ │ 过期自动│
│ (审批流)│ │ 分布式│ │ 展示/  │ │ 人脸  │ │ 注销/   │
│         │ │ 存储  │ │ 授权码  │ │ 比对  │ │ 主动注销│
└────┬────┘ └───┬───┘ └────┬────┘ └───┬───┘ └────┬────┘
     │          │           │          │           │
     └──────────┼───────────┼──────────┼───────────┘
                ▼           ▼          ▼
          ┌──────────────────────────────────┐
          │        区块链存证网络            │
          │ (证照哈希、操作日志不可篡改)     │
          └──────────────────────────────────┘
```

#### 2.3.2 核心功能
- **证照签发**: 对接各部门业务系统，自动签发电子证照
- **分布式存储**: IPFS分布式存储，确保证照不可篡改
- **区块链存证**: 证照全生命周期操作上链
- **多场景使用**: 二维码、授权码、API调用等多种使用方式
- **智能核验**: OCR识别+人脸比对+区块链核验
- **自动管理**: 过期自动提醒、自动注销

              │         资金监管引擎             │

- **核销监管**: 补贴使用场景核验、防止套取

## 3. 数据架构设计

### 3.1 数据分类

| 数据类型 | 存储方案 | 安全等级 | 保留期限 |
|---------|---------|---------|---------|
| 用户身份数据 | PostgreSQL | 最高 | 永久 |
| 业务交易数据 | MySQL + 归档 | 高 | 10年 |
| 电子证照数据 | IPFS + 区块链 | 最高 | 永久 |
| 补贴资金数据 | MySQL + 区块链 | 最高 | 永久 |
| 日志审计数据 | Elasticsearch | 中 | 3年 |
| 监控指标数据 | Prometheus | 低 | 1年 |
| 缓存数据 | Redis | 中 | 动态 |

- 安全物理环境
- 安全通信网络
- 安全区域边界
- 安全计算环境
- 安全管理中心
- 安全管理制度
- 安全管理机构
- 安全管理人员
- 安全建设管理
- 安全运维管理

## 5. 非功能需求

### 5.1 性能指标
- **并发用户**: 支持10万+并发用户
- **响应时间**: 页面加载 < 2秒，API响应 < 200ms
- **吞吐量**: 单节点 > 1000 TPS
- **可用性**: > 99.95% (年停机时间 < 4.38小时)

### 5.2 可扩展性
- 支持水平扩展，按需扩容
- 模块化设计，支持功能快速迭代
- API-first设计，便于系统集成

### 5.3 可维护性
- 全链路追踪
- 统一日志管理
- 自动化部署
- 灰度发布支持
