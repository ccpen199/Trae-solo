## 1. 开发概述

### 1.1 开发目标

根据规划文档 `docs/PROJECT_EVALUATION_REPORT.md` 的建议，本次开发聚焦于**从"翻译工具"到"语言桥梁"的升级**，选择规划文档中最核心的功能进行扩展，特别是满足人类高维需求的功能，将实时翻译平滑转化为无障碍沟通的便利。

### 1.2 开发范围

**核心功能选择原则：**

| 优先级 | 功能类别 | 选择理由 |
|-------|---------|---------|
| **P0** | 对话翻译模式 | 满足"高维需求"，从单次翻译到持续对话，真正的"语言桥梁" |
| **P0** | 实时翻译 | 平滑转化，输入即翻译，无需手动触发 |
| **P0** | 翻译历史记录 | 用户粘性、数据持久化、工作连续性 |
| **P1** | 暗黑模式 | 视觉体验、长时间使用、用户偏好 |
| **P1** | 语言自动检测 | 减少操作步骤，提升流畅度 |
| **P1** | 本地存储服务 | 数据持久化基础，所有功能的基础支撑 |

**不做移动端开发** - 遵循用户明确要求，专注桌面端体验优化。

## 4. 核心功能详细说明

### 4.1 对话翻译模式

#### 4.1.1 设计理念

对话翻译模式的核心设计理念是**将"单次翻译"转化为"持续对话"**，让用户感觉像是在与对方进行实时交流，而不是反复使用翻译工具。

**用户场景模拟：**

```
传统翻译流程：
输入中文 → 点击翻译 → 查看英文 → 复制 → 发给对方
    ↓
对方回复英文 → 复制 → 粘贴 → 翻译 → 查看中文

对话翻译流程：
输入中文 ↔︎ 自动翻译为英文 ↔︎ 对方看到英文
    ↑                                          ↓
    │                                          │
    └────────── 来回切换，无缝体验 ────────────┘
```

#### 4.1.2 消息数据模型

```javascript
// 消息角色定义
MESSAGE_ROLES = {
  USER: 'user',       // 用户发送的消息（源语言）
  TRANSLATED: 'translated',  // 翻译后的消息（目标语言）
  SYSTEM: 'system'    // 系统消息（提示、错误等）
}

// 消息状态定义
MESSAGE_STATES = {
  SENDING: 'sending',       // 发送中
  TRANSLATING: 'translating', // 翻译中
  COMPLETED: 'completed',     // 已完成
  ERROR: 'error'              // 错误
}
```

#### 4.1.3 会话数据模型

```javascript
class Conversation {
  id: string;                    // 会话唯一标识
  title: string;                 // 会话标题（自动从第一条消息生成）
  sourceLanguage: string;        // 源语言
  targetLanguage: string;        // 目标语言
  messages: Message[];           // 消息列表
  createdAt: number;             // 创建时间戳
  updatedAt: number;             // 最后更新时间戳
  isFavorite: boolean;           // 是否收藏

  // 核心方法
  addMessage(message: Message);           // 添加消息
  updateMessage(id, updates);             // 更新消息
  removeMessage(id);                      // 删除消息
  swapLanguages();                        // 交换源目标语言
  getFormattedUpdatedAt();                // 格式化时间显示
}
```

#### 4.1.4 消息发送流程

```
用户输入文本
    │
    ▼
创建用户消息 (Message.createUserMessage)
    │
    ▼
添加到会话 → 通知 UI 渲染 → 显示用户消息气泡
    │
    ▼
创建加载消息 (Message.createLoadingMessage)
    │
    ▼
添加到会话 → 通知 UI 渲染 → 显示加载动画
    │
    ▼
调用翻译服务 (translationService.translate)
    │
    ├── 成功 ──► 更新消息内容 → 显示翻译结果
    │
    └── 失败 ──► 更新消息状态为 ERROR → 显示错误提示
    │
    ▼
保存会话到 LocalStorage
```

### 4.2 实时翻译功能

#### 4.2.1 设计理念

实时翻译的核心是**消除"点击翻译"这个动作**，让用户在输入过程中就能看到翻译结果，实现"所想即所得"。

#### 4.2.2 防抖策略

```javascript
// 防抖延迟（毫秒）
const REAL_TIME_TRANSLATE_DELAY = 500;

// 防抖实现原理
this._debouncedRealTimeTranslate = debounce(
  this._executeRealTimeTranslate.bind(this),
  REAL_TIME_TRANSLATE_DELAY
);

// 用户输入时的流程：
// 1. 用户输入字符 → 调用 realTimeTranslate()
// 2. 触发防抖定时器（500ms）
// 3. 如果用户继续输入，重置定时器
// 4. 当用户停止输入 500ms 后，执行实际翻译
```

**防抖策略的优势：**

| 场景 | 不使用防抖 | 使用防抖 (500ms) |
|-----|-----------|------------------|
| 输入"你好" (2个字符) | 2 次 API 调用 | 1 次 API 调用 |
| 输入"今天天气怎么样" (7个字符) | 7 次 API 调用 | 1 次 API 调用 |
| 用户快速打字 | 频繁请求，可能被限流 | 只有 1 次请求 |

#### 4.2.3 可开关设计

```html
<!-- 界面上的开关 -->
<div class="conversation__auto-translate">
  <label class="conversation__auto-translate__label">实时翻译</label>
  <input type="checkbox" id="autoTranslateToggle" checked>
</div>
```

用户可以根据需要开启或关闭实时翻译功能，提供灵活性。

### 4.4 语言自动检测功能

#### 4.4.1 检测策略

语言检测采用**多层级检测策略**，从高置信度到低置信度依次进行：

```
检测流程：
    │
    ▼
第一步：字符范围检测（高置信度）
    │
    ├──► 中日韩文字符范围检测
    ├──► 阿拉伯文、泰文、印地文、俄文、希腊文、希伯来文
    └──► 置信度 >= 0.9 直接返回
    │
    ▼
第二步：常见单词检测（中置信度）
    │
    ├──► 英文常见单词检测
    ├──► 法文、德文、西班牙文、葡萄牙文、意大利文
    └──► 置信度 >= 0.7 返回
    │
    ▼
第三步：混合检测（低置信度）
    │
    └──► 结合字符范围和单词检测结果
```

#### 4.4.3 检测缓存机制

```javascript
// 检测缓存（最多 100 条）
const MAX_CACHE_SIZE = 100;

// 缓存结构
this._detectionCache = new Map();
// Key: 文本内容
// Value: { language: 'zh', confidence: 0.95 }

// 检测流程中的缓存检查：
async detect(text) {
  // 1. 检查缓存
  const cached = this._detectionCache.get(text);
  if (cached) {
    return cached;
  }
  
  // 2. 执行检测
  const result = await this._executeDetection(text);
  
  // 3. 保存到缓存
  this._detectionCache.set(text, result);
  
  // 4. 缓存超限清理
  if (this._detectionCache.size > MAX_CACHE_SIZE) {
    const firstKey = this._detectionCache.keys().next().value;
    this._detectionCache.delete(firstKey);
  }
  
  return result;
}
```

async sendMessage(content, options = {}) {
  try {
    // 执行翻译
    const translatedContent = await translationService.translate(
      content,
      sourceLang,
      targetLang
    );
    
    // 更新消息
    this.currentConversation.updateMessage(loadingMessage.id, {

      state: MESSAGE_STATES.COMPLETED

    this.logger.error('翻译失败', error);
