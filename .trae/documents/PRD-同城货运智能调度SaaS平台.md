## 1. 产品概述

同城货运智能调度SaaS平台，专注解决小批量、多点配送场景下的运力匹配效率问题。通过AI智能派单引擎、多维货物属性发布、车辆传感器数据自动校验履约、动态计价模型、订单保险等核心能力，连接货主与司机两端，构建高效、透明、可追溯的同城货运生态。

- 目标用户：中小货主企业、个体货车司机、平台运营方
- 核心价值：提升运力匹配效率30%+，降低空驶率25%，履约纠纷率下降80%

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |

| 货主 | 手机号+企业认证 | 发布货源、追踪订单、投保、查看发货热力图、对账结算 |

3. **智能调度中心**：派单引擎监控、算法调优、实时路况、匹配度分析
4. **运营管理后台**：用户管理、订单审核、保险管理、运力饱和度预警、数据大屏
5. **订单保险模块**：人保API对接、按单投保、保费自动分摊、理赔流程

## 3. 核心流程

### 3.1 发货→派单→履约主流程

货主发布货源（填写体积/重量/温控/装卸难度/多点地址/时间窗）→ 系统动态计价并显示预估运费 → 货主确认并选择是否投保 → 订单进入待匹配池 → 智能派单引擎（结合实时路况/司机履约率/车型匹配/返程空驶率）计算Top3候选司机 → 推送订单给司机 → 司机接单 → 车辆传感器开始上送数据（载重/温度/开门）→ 到达取货点→装货完成(载重校验)→开始配送 → 按多点顺序依次送达(每站校验开门+载重变化) → 全部送达 → 系统自动校验履约完整性 → 订单完成→保费自动结算 → 运费T+1结算至司机账户

```mermaid
flowchart LR
    A["货主发布货源"] --> B["动态计价预览"]
    B --> C["确认&可选投保"]
    C --> D["订单进入匹配池"]
    D --> E["智能派单引擎计算"]
    E --> F["推送至候选司机"]
    F --> G["司机接单"]
    G --> H["传感器数据实时上送"]
    H --> I["取货+装货校验"]
    I --> J["多点依次配送"]
    J --> K["每站开门+载重校验"]
    K --> L["全部送达"]
    L --> M["系统自动履约判定"]
    M --> N["保费结算+运费打款"]
```

### 3.2 履约校验异常处理流程

传感器数据异常（温度超标/开门次数不符/载重偏离）→ 系统标记异常并预警 → 运营介入审核 → 判定责任方 → 按保险条款触发理赔/扣罚

## 4. 用户界面设计

### 4.1 设计风格

**设计主题：专业工业风（Industrial & Trustworthy）**

- 主色调：深邃藏青 `#0F172A`（稳重可靠），搭配活力橙 `#F97316`（行动力、调度感）
- 辅助色：信号绿 `#10B981`（正常/完成）、警示黄 `#F59E0B`（预警）、告警红 `#EF4444`（异常）、冷灰蓝 `#64748B`
- 背景：深灰基底 `#0B1220` + 微噪点纹理 + 数据网格线，营造工业控制舱氛围
- 按钮风格：直角切边设计，主按钮橙色渐变+描边光效，次要按钮半透玻璃拟态
- 字体：展示字体使用 `Orbitron`（科技感数字/标题），正文字体 `Noto Sans SC`
- 布局：卡片化模块化，数据仪表盘风格，关键指标大数字展示，折线/柱状/热力图交织
- 图标：Lucide线性图标统一2px描边，传感器仪表使用拟物化仪表盘组件
