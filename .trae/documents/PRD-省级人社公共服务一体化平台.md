## 1. 产品概述

省级人社公共服务一体化平台是面向个人用户、企业HR、基层经办机构三类主体的一站式公共服务门户，整合社保、就业、考试、政策咨询四大核心业务领域，提供全周期、智能化、便捷化的人力资源和社会保障公共服务。

- 解决群众办事"多地跑、反复跑"问题，实现"一网通办"
- 提升人社服务效率和透明度，优化营商环境
- 目标用户：参保人、求职者、退休人员、企业HR、基层经办人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 个人用户 | 身份证实名认证 | 社保查询办理、求职应聘、考试报名、政策咨询 |
| 企业HR | 企业营业执照认证 | 基数申报、岗位发布、简历管理、员工社保管理 |
| 基层经办机构 | 机构编码+工作人员实名认证 | 业务审核、统计分析、时效监测、满意度管理 |
| 系统管理员 | 后台授权 | 系统配置、用户管理、权限分配、数据监控 |

### 2.2 功能模块

1. **首页门户**：统一身份认证、服务导航、待办提醒、热门服务快捷入口
2. **社保服务**：参保登记、基数申报、待遇资格认证、转移接续、电子凭证签发
3. **就业服务**：岗位智能推荐、简历投递追踪、招聘会预约、职业技能培训报名与学分认定
4. **人事考试**：考试公告发布、在线报名、准考证生成、成绩查询与证书核验
5. **政策咨询**：按人群/事项/地域三维检索、智能问答、FAQ自动归因、语音问答
6. **运营管理**：业务办理时效监测、群众满意度评价、服务缺口热力分析

## 3. 核心流程

### 3.1 社保转移接续流程

用户登录 → 选择社保转移服务 → 填写转入转出地信息 → 上传证明材料 → 提交申请 → 基层经办审核 → 生成转移工单 → 跨层级协同办理 → 资金划转 → 办结通知 → 用户评价

```mermaid
flowchart LR
    A["用户登录"] --> B["选择转移服务"]
    B --> C["填写信息"]
    C --> D["上传材料"]
    D --> E["提交申请"]
    E --> F["经办审核"]
    F --> G["生成工单"]
    G --> H["跨层级办理"]
    H --> I["资金划转"]
    I --> J["办结通知"]
    J --> K["用户评价"]
```

### 3.2 求职应聘流程

用户完善简历 → 浏览/搜索岗位 → 智能推荐匹配岗位 → 查看岗位详情 → 投递简历 → 企业查看 → 面试邀请 → 参加面试 → 录用通知 → 状态更新

```mermaid

    B --> C["智能推荐"]
    C --> D["投递简历"]
    D --> E["企业查看"]
    E --> F["面试邀请"]
    F --> G["参加面试"]
    G --> H["录用通知"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：政务蓝 `#1E6FDB`，代表专业、可信、稳重
- **辅助色**：政务红 `#DC3545`（重要提醒）、成功绿 `#28A745`（办理成功）、警告橙 `#FFC107`（待办提醒）
- **中性色**：深灰 `#343A40`、中灰 `#6C757D`、浅灰 `#F8F9FA`
- **按钮风格**：圆角4px，扁平设计，hover状态有轻微阴影和颜色加深
- **字体**：-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif
- **布局风格**：顶部导航栏 + 左侧菜单 + 主内容区，卡片式布局，清晰的信息层级
- **图标风格**：Ant Design 图标体系，简洁线性图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 登录页 | 统一认证 | 左侧品牌展示区 + 右侧登录表单，渐变背景，政务风格插画 |
| 个人中心首页 | 首页门户 | 顶部欢迎语 + 快捷服务九宫格 + 待办事项列表 + 数据概览卡片 |
| 社保账户页 | 社保服务 | 账户总览卡片 + 险种标签页 + 缴费明细表格 + 图表可视化 |
| 岗位列表页 | 就业服务 | 搜索筛选栏 + 岗位卡片列表 + 侧边智能推荐栏 |
| 政策法规页 | 政策咨询 | 三维检索面板（人群/事项/地域） + 政策列表卡片 + 相关推荐 |
| 时效监测页 | 运营管理 | 数据看板 + 超时预警列表 + 办理时长趋势图 + SLA达标率环形图 |

### 4.3 响应式

- **桌面端优先**：1280px及以上为主要设计尺寸
- **平板适配**：1024px-1279px，侧边栏可折叠，网格布局自适应
- **移动端适配**：768px以下，顶部导航变为汉堡菜单，卡片变为单列布局，优化触控区域

### 4.4 交互体验

- 页面加载时骨架屏占位，避免布局跳动
- 表单提交时按钮loading状态，防止重复提交
- 操作成功/失败使用全局Message提示
- 重要操作（如删除、提交）使用Modal二次确认
- 表格支持排序、筛选、分页
- 图表支持hover显示详情，数据钻取
