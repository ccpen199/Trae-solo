# 产品需求文档：猫语翻译实验平台

## 1. 产品概述

聚焦猫科动物的行为语义解析与人宠交互实验平台，通过叫声声纹特征分析实现情绪识别与行为建议，并提供反向语音合成功能，打造轻量科普工具。

- 核心价值：让养猫爱好者科学理解猫咪情绪，通过实验日志增进人宠互动
- 目标用户：猫咪主人、动物行为学爱好者、科普教育人群
- 差异化：端侧离线运行保障隐私、声纹库+合成双向功能、科普与实验结合

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，本地使用 | 使用全部功能、管理本地实验日志 |

### 2.2 功能模块

1. **声纹分析页**：音频上传/录制、情绪置信度评分、行为建议、波形可视化对比
2. **语音合成页**：文字指令输入、猫音频合成播放、预期响应概率标注
3. **声纹特征库**：6类基础情绪标签（呼噜、喵叫、嘶叫、哀鸣、低吼、满足）、样本展示
4. **科普知识页**：动物行为学参考文献索引、猫咪生理常识图谱
5. **实验日志页**：交互记录管理（时间/场景/猫咪反应）、匿名化统计看板
6. **关于页**：平台介绍、隐私声明、使用说明

## 3. 核心流程

### 3.1 声纹分析流程

用户上传或录制音频 → 本地Web Audio API解析 → 提取声纹特征 → 匹配6类情绪模型 → 计算置信度评分 → 生成行为建议 → 波形可视化展示 → 可选择保存至实验日志

```mermaid
flowchart LR
    A["音频输入"] --> B["本地解析"]
    B --> C["特征提取"]
    C --> D["情绪匹配"]
    D --> E["置信度计算"]
    E --> F["行为建议生成"]
    F --> G["波形可视化"]
    G --> H["保存至日志"]
```

### 3.2 语音合成流程

用户输入文字指令 → 语义解析映射为猫情绪状态 → 基于频段参数生成拟真音频 → 播放合成音频 → 展示预期响应概率 → 可记录实验结果

```mermaid
flowchart LR
    A["文字指令输入"] --> B["语义映射"]
    B --> C["频段参数生成"]
    C --> D["音频合成"]
    D --> E["播放试听"]
    E --> F["响应概率展示"]
    F --> G["记录实验"]
```

## 4. 用户界面设计

### 4.1 设计风格

**设计主题：科技生物感 · 暗色科研风**

- 主色调：深海青色 `#0F172A`（背景）+ 琥珀橙 `#F59E0B`（强调色，代表猫咪毛色）
- 辅助色：薄荷绿 `#34D399`（正面情绪）、珊瑚红 `#F87171`（负面情绪）、淡紫色 `#A78BFA`（中性情绪）
- 整体风格：暗色科研仪表盘风格，玻璃态卡片，发光动效，波形元素贯穿全局
- 按钮风格：圆角矩形，微妙内阴影，hover时有发光描边
- 字体：标题使用Space Grotesk，正文使用Inter，数字使用等宽字体
- 图标：线性简约图标，配合情绪色使用
- 空间布局：左侧导航 + 右侧内容区，卡片式模块化布局

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 声纹分析 | 音频输入区 | 大尺寸拖拽区域，波形动画背景，录制按钮脉冲动效 |
| 声纹分析 | 情绪结果区 | 横向置信度条形图，数值动画递增，Top1情绪发光卡片 |
| 声纹分析 | 波形可视化 | Canvas频谱图，时间轴可拖动，双视图（时域+频域）切换 |
| 语音合成 | 指令输入 | 标签云式预设指令，输入框带猫咪图标 |
| 语音合成 | 合成结果 | 音频播放器，波形随播放律动，概率分布环形图 |
| 声纹特征库 | 情绪卡片 | 六边形情绪色卡，hover时3D翻转展示详情 |
| 科普知识 | 参考文献 | 时间轴式论文列表，展开/收起动画 |
| 科普知识 | 生理图谱 | SVG示意图，悬停高亮标注点 |
| 实验日志 | 统计看板 | 数据卡片带数字滚动动效，图表入场动画 |

### 4.3 响应式

- 桌面端优先设计（≥1280px），左侧固定导航，内容区网格布局
- 平板端（768px-1279px）：导航收窄为图标模式，内容区自适应
- 移动端（<768px）：底部导航栏，卡片单列布局，触控优化
- 波形可视化组件在移动端简化为单视图

### 4.4 动效设计

- 页面入场：元素错落淡入（staggered fade-in），导航从左滑入
- 音频录制：按钮脉冲呼吸动效，波形实时律动
- 情绪分析中：加载动画为声波扩散效果
- 数据展示：数字从0滚动到目标值，条形图从左向右生长
- 卡片hover：轻微上浮 + 阴影加深 + 边框发光
