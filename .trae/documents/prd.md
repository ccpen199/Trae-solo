## 1. 产品概述

人社中台——面向个人与企业的一站式人力资源和社会保障综合服务平台，提供就业、社保、劳动关系、人才服务等核心业务的全流程在线办理，同时为监管部门提供效能监测与风险预警能力。

- 目标用户：个人参保人员、企业HR/经办人、人社部门监管人员
- 核心价值：打通参保查询→失业申领→职称申报→合同签署→监察投诉的全链路办事闭环，实现政策智能问答、材料跨事项复用、效能监测大屏等中台能力

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 身份证号注册 | 参保查询、失业金申领、职称申报、劳动合同签署、监察投诉 |
| 企业用户 | 统一社会信用代码注册 | 批量参保操作、劳动合同管理、社保缴费、人才招聘 |
| 监管人员 | 内部授权分配 | 效能监测大屏、超时预警、退件归因、热点问题聚类 |

### 2.2 功能模块

1. **首页门户**：个人/企业模式切换、业务导航入口、待办提醒、通知公告
2. **社保服务**：参保状态查询、社保缴费记录、医保账户查询
3. **就业服务**：失业金申领、就业登记、创业补贴申请
4. **人才服务**：职称申报、技能鉴定、人才政策匹配
5. **劳动关系**：劳动合同电子签署、劳动监察投诉、仲裁申请
6. **政策问答**：智能政策检索、材料识别、跨事项材料复用
7. **效能监测大屏**：超时预警、退件归因分析、热点问题聚类、业务办理统计

## 3. 核心流程

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 #1a365d（政务稳重感）+ 琥珀橙 #dd6b20（行动号召/警示）
- 辅助色：石板灰 #4a5568（正文）、翠绿 #2f855a（成功/在线）、珊瑚红 #c53030（错误/超时）
- 按钮风格：圆角8px，主按钮实心填充，次按钮描边
- 字体：Noto Sans SC（中文UI），font-size阶梯：14/16/20/28/36px
- 布局风格：左侧固定导航 + 顶部工具栏 + 主内容区卡片式布局
- 图标：lucide-react线性图标，统一24px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 首页门户 | 模式切换 | 顶部Tab切换，个人蓝色调/企业绿色调，渐变背景卡片 |
| 首页门户 | 业务导航 | 2×2网格卡片，图标+标题+描述，悬浮提升阴影 |
| 首页门户 | 待办提醒 | 右侧悬浮面板，数字徽标+列表 |
| 参保状态查询 | 参保信息 | 五险分卡片展示，状态圆点（绿色参保/灰色停保） |
| 失业金申领 | 申领表单 | 分步表单（3步），进度指示器，字段校验高亮 |
| 职称申报 | 申报表单 | 手风琴展开式区域，材料上传拖拽区 |
| 劳动合同签署 | 电子签署 | 合同预览PDF风格，签名板手写区域，时间戳 |
| 劳动监察投诉 | 投诉表单 | 表单+证据上传多文件区，提交确认弹窗 |
| 政策问答 | 智能检索 | 对话式界面，关键词高亮匹配结果 |
| 效能监测大屏 | 业务统计 | 数据卡片+折线图+柱状图，深色背景大屏风格 |
| 效能监测大屏 | 超时预警 | 红色闪烁圆点+倒计时数字，表格列表 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1200px完整展示
- 平板端（768-1200px）侧边栏折叠为图标导航
- 移动端（<768px）底部Tab导航，卡片单列堆叠，触摸优化

### 4.4 动效设计

- 页面切换：淡入淡出200ms
- 卡片悬浮：translateY(-4px) + box-shadow增强
- 表单提交：按钮loading旋转动画
- 状态变更：脉冲圆点动画（待审核橙色/已通过绿色/已退回红色）
- 大屏数据：数字滚动计数器动画，图表渐入绘制
