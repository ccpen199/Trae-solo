## 1. 产品概述

融合直播、社交与装修服务的房产垂直平台——为购房者、装修需求者提供从选房到入住的一站式服务。平台核心连接房产专家/置业顾问/设计师（直播间端）与购房者/装修需求者（用户端），通过低延迟直播互动、智能内容分发、专业身份认证、装修服务闭环、VR样板间体验和报价对比工具，实现房产交易与装修服务的全流程线上化。

- 目标用户：购房者、二手房买家、租房者、装修需求者、房产经纪人、置业顾问、室内设计师、装修公司、建材品牌商
- 核心价值：直播看房+装修一站式闭环，降低信息差，提升决策效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户（购房者/装修需求者） | 手机号/邮箱注册 | 浏览直播、房源、内容；参与互动；提交装修需求 |
| 房产专家/置业顾问 | 注册+专业认证 | 开设直播间、发布房源、连麦答疑 |
| 设计师 | 注册+资质认证 | 开设直播间、发布案例、提供设计方案 |
| 装修公司 | 注册+企业认证 | 入驻平台、发布案例/报价、接单 |
| 建材品牌商 | 注册+企业认证 | 发布样品库、经销商地图、报价 |
| 律师/估价师/监理 | 注册+持证认证 | 提供专业服务、参与直播答疑 |
| 平台管理员 | 后台指派 | 内容审核、KOL管理、装修公司年审、数据看板 |

### 2.2 功能模块

1. **首页**：直播推荐、热门房源、装修案例、建材推荐、用户入口
2. **直播中心**：直播列表、直播分类、正在直播/预告、直播回放
3. **直播间**：视频流、弹幕互动、连麦答疑、红包抽奖、房源挂载
4. **房源中心**：新房/二手房/公寓列表、筛选搜索、地图模式
5. **房源详情**：房源信息、VR样板间、周边配套、专家咨询
6. **装修服务**：方案设计、建材选购、施工监理、验收交付全流程
7. **装修报价对比**：多公司报价上传、自动解析、差异项标注
8. **内容中心**：短视频/图文推荐、关注动态、收藏点赞
9. **个人中心**：用户信息、认证状态、我的收藏、浏览历史、装修订单
10. **后台管理**：内容审核工作流、KOL合作管理、装修公司年审、数据看板

## 3. 核心流程

### 3.1 用户看房直播流程
用户进入首页 → 看到推荐直播 → 进入直播间 → 弹幕提问 → 连麦答疑 → 查看关联房源 → 进入房源详情 → VR看房 → 预约实地看房

### 3.2 装修服务闭环流程
用户提交装修需求 → 平台推荐装修公司/设计师 → 方案设计对比 → 建材选购（品牌样品+经销商） → 报价对比工具 → 确认签约 → 施工监理（监理持证上岗） → 验收交付

### 3.3 内容审核流程
用户/主播发布内容 → 系统敏感词过滤 → 通过则发布/疑似则进入人工复审 → 审核员复审 → 发布或驳回

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深青色(#0D9488) + 金色点缀(#F59E0B)，传达专业与信赖感
- 辅助色：暖白(#FEFCE8)背景、深灰(#1E293B)文字
- 按钮风格：圆角(8px)、微阴影、hover渐变效果
- 字体：思源黑体(Noto Sans SC)为主，Playfair Display为装饰标题字体
- 布局风格：顶部导航+侧边分类、卡片式内容展示、网格+列表双视图
- 图标风格：线性图标(Stroke 1.5px)、圆角方形图标容器

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 直播推荐区 | 横向滚动卡片、直播脉冲动画、观看人数标签 |
| 首页 | 热门房源 | 大图轮播+价格标签、渐变遮罩 |
| 首页 | 装修案例 | 瀑布流卡片、风格标签、报价区间 |
| 直播间 | 视频区 | 16:9视频、弹幕覆盖层、全屏按钮 |
| 直播间 | 互动栏 | 底部弹幕输入、连麦按钮、红包按钮 |
| 房源详情 | VR样板间 | 全屏360°视图、家具拖拽面板、材质切换按钮 |
| 装修服务 | 流程导航 | 步骤条、当前步骤高亮、连接线动画 |
| 装修服务 | 报价对比 | 表格视图、差异项红色标注、图表对比 |

### 4.3 响应式设计
- 桌面优先设计（1440px基准）
- 平板适配（768px-1024px）：侧边栏折叠、卡片2列
- 移动端适配（< 768px）：单列布局、底部导航、触摸优化

### 4.4 VR场景指引
- 环境氛围：明亮现代室内、自然光照射
- 相机设置：初始位置客厅中心、0°-360°水平旋转、俯仰角限制±45°
- 交互：点击家具高亮→弹出更换面板、材质球拖拽替换
- 性能：懒加载全景图、低分辨率预览+高清替换
