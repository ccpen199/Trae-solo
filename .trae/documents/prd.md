## 1. 产品概述

面向医疗行业的垂直招聘服务平台，连接医疗机构与持证医疗人才（医生、护士、医技、药师等），实现精准双向匹配、投递全链路追踪、在线沟通、医疗人社区及后台合规管理。解决传统医疗招聘信息分散、资质审核难、匹配效率低的问题。

- 目标用户：医院/诊所/医疗集团等用人单位，以及持证医疗从业者
- 核心价值：执业资质精准匹配、岗位审核合规保障、投递全流程透明追踪

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 医疗人才（求职者） | 手机号/邮箱注册 + 执业资质认证 | 浏览职位、投递简历、在线沟通、社区互动、电子简历管理 |
| 医疗机构（招聘方） | 机构账号注册 + 资质审核 | 发布/管理职位、查看简历、邀约面试、在线沟通 |
| 平台管理员 | 后台分配账号 | 机构年审、岗位审核、数据看板、AI复核、脱敏归档 |

### 2.2 功能模块

1. **首页**：搜索栏、热门科室推荐、最新职位、行业资讯入口、平台数据概览
2. **注册认证页**：双向注册（人才/机构）、资质上传与审核状态跟踪
3. **职位中心**：职位列表/详情、筛选（科室/地域/职称/薪资）、职位发布/审核/下架
4. **简历中心**：智能简历解析、结构化存储、电子简历编辑、PDF导出、隐私字段分级授权
5. **双向匹配推荐**：基于执业资质/科室/地域/职称的智能推荐
6. **投递追踪**：已读/邀约/面试/录用全链路状态追踪
7. **在线沟通**：机构与人才实时消息
8. **医疗人社区**：行业资讯、政策解读、继续教育话题标签
9. **后台管理**：机构资质年审、虚假岗位AI识别+人工复核、简历脱敏归档、统计看板

## 3. 核心流程

### 3.1 医疗人才注册认证流程

1. 人才选择"医疗人才"角色注册账号
2. 填写基本信息并上传执业资质证书
3. 平台审核资质（自动校验+人工复核）
4. 审核通过后可浏览职位、投递简历

```mermaid
flowchart TD
    "选择医疗人才角色" --> "填写基本信息"
    "填写基本信息" --> "上传执业资质证书"
    "上传执业资质证书" --> "平台自动校验"
    "平台自动校验" --> "校验通过？"
    "校验通过？" --> "是：人工复核"
    "校验通过？" --> "否：退回补充材料"
    "退回补充材料" --> "上传执业资质证书"
    "人工复核" --> "审核通过"
    "人工复核" --> "审核拒绝"
```

### 3.2 职位发布与审核流程

1. 机构登录后发布职位，填写岗位信息和资质要求
2. 系统AI初步审核（检测虚假岗位风险标记）
3. 平台管理员人工复核
4. 审核通过后职位上架，审核不通过则退回修改

```mermaid
flowchart TD
    "机构发布职位" --> "AI初步审核"
    "AI初步审核" --> "AI风险评分"
    "AI风险评分" --> "低风险：自动通过"
    "AI风险评分" --> "中风险：标记待人工复核"
    "AI风险评分" --> "高风险：标记待人工复核"
    "中风险：标记待人工复核" --> "管理员人工复核"
    "高风险：标记待人工复核" --> "管理员人工复核"
    "管理员人工复核" --> "通过：职位上架"
    "管理员人工复核" --> "不通过：退回修改"
```

### 3.3 投递全链路追踪流程

1. 人才浏览职位并投递简历
2. 机构查看投递 → 状态变为"已读"
3. 机构发起邀约 → 状态变为"邀约"
4. 双方确认面试时间 → 状态变为"面试"
5. 面试通过 → 状态变为"录用"

```mermaid

    "投递" --> "已读"
    "已读" --> "邀约"
    "邀约" --> "面试"
    "面试" --> "录用"
    "邀约" --> "不合适"
    "面试" --> "不合适"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色（#0F766E）象征医疗专业与信任，辅以暖白（#FAFAF9）营造洁净感
- **辅助色**：琥珀色（#D97706）用于CTA按钮与重要状态标记，浅薄荷（#CCFBF1）用于背景点缀
- **按钮风格**：圆角（8px），主按钮实心深青色，次按钮描边风格
- **字体**：标题使用 Noto Serif SC（衬线体传递专业权威），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：卡片式布局，顶部导航栏，侧边筛选面板
- **图标风格**：线性图标（Lucide），线条细腻，风格统一

### 4.3 响应式设计

- 桌面优先设计，断点：768px（平板）、480px（手机）
- 移动端：筛选面板折叠为顶部筛选按钮，卡片单列排列，底部Tab导航
- 触摸优化：按钮最小点击区域44px，滑动操作支持
