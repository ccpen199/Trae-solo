## 1. 产品概述

杭州市总工会数字化职工服务平台，以市-区-基层工会三级组织架构为底座，构建集文体活动、普惠商城、法律咨询、帮扶救助、心理测评于一体的服务中台。平台面向全市职工提供实名认证、在线服务办理与电子票券核销，面向工会管理员提供职工数字档案、标签化精准推送与治理指标数据大屏，实现工会服务数字化、精准化、智能化。

- 目标用户：杭州市在职职工、各级工会管理员、商家核销员
- 核心价值：将分散的工会服务线上化，沉淀服务行为数据，支撑精准服务与科学治理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 职工 | 实名注册+工会绑定 | 浏览服务、在线报名/下单、查看数字档案 |
| 工会管理员 | 后台授权 | 组织管理、服务配置、职工标签推送、数据大屏 |
| 商家核销员 | 商家授权 | 券码核销、核销记录查询 |

### 2.2 功能模块

1. **登录注册页**：手机号+验证码登录、实名认证（姓名+身份证）、工会关系绑定（选择区/基层工会）
2. **职工首页**：服务入口聚合、活动推荐、消息通知、快捷功能
3. **文体活动**：活动列表、活动详情、在线报名、电子票生成与核销
4. **普惠商城**：商品分类浏览、下单购买、券码生成、商家核销
5. **法律咨询**：在线排队取号、律师信息展示、文书模板库下载
6. **帮扶救助**：救助申请表单、家庭经济状况AI初筛、申请进度追踪
7. **心理测评**：心理测评量表（SCL-90等）、测评报告、预约转介
8. **个人中心**：数字档案、我的服务记录、我的标签、消息中心
9. **管理后台-数据大屏**：服务覆盖率、响应时效、职工满意度NPS、实时热力图
10. **管理后台-组织管理**：三级组织树CRUD、职工工会关系管理
11. **管理后台-服务管理**：活动/商品/咨询/帮扶/测评配置
12. **管理后台-精准推送**：按产业/年龄/需求标签筛选、消息推送

## 3. 核心流程

### 3.1 职工实名认证与工会绑定流程

用户打开平台 → 手机号验证码登录 → 判断是否已实名 → 未实名则进入实名认证页（姓名+身份证）→ 认证通过后进入工会绑定页 → 选择所属区工会 → 选择基层工会 → 提交绑定申请 → 管理员审核通过 → 进入首页

```mermaid
flowchart TD
    "打开平台" --> "手机号登录"
    "手机号登录" --> "已实名?"
    "已实名?" -- 否 --> "实名认证页"
    "已实名?" -- 是 --> "已绑定工会?"
    "实名认证页" --> "认证通过"
    "认证通过" --> "工会绑定页"
    "工会绑定页" --> "选择区工会"
    "选择区工会" --> "选择基层工会"
    "选择基层工会" --> "提交绑定申请"
    "提交绑定申请" --> "管理员审核"
    "管理员审核" --> "审核通过"
    "审核通过" --> "进入首页"
    "已绑定工会?" -- 是 --> "进入首页"
    "已绑定工会?" -- 否 --> "工会绑定页"
```

### 3.2 文体活动报名与电子票核销流程

职工浏览活动 → 查看活动详情 → 点击报名 → 填写报名信息 → 报名成功生成电子票（二维码）→ 活动当天出示电子票 → 工作人员扫码核销 → 核销完成

```mermaid

    "查看活动详情" --> "点击报名"
    "点击报名" --> "填写报名信息"
    "填写报名信息" --> "报名成功"
    "报名成功" --> "生成电子票二维码"
    "生成电子票二维码" --> "活动当天出示"
    "活动当天出示" --> "工作人员扫码"
    "工作人员扫码" --> "核销完成"
```

### 3.3 帮扶救助申请流程

职工进入帮扶救助 → 填写申请表单 → 上传证明材料 → AI初筛家庭经济状况 → 给出建议等级 → 提交申请 → 初审 → 复核 → 公示 → 发放救助金

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：工会红 (#C41D2E) + 金色点缀 (#D4A843)，体现工会庄重与温暖
- **辅助色**：暖灰底色 (#F5F3EF) + 深灰文字 (#2D2D2D)
- **按钮风格**：圆角8px，主按钮红色渐变，次按钮金色描边
- **字体**：标题用思源黑体（Noto Sans SC），正文用系统默认
- **布局风格**：H5端底部Tab导航 + 顶部搜索栏；管理后台左侧菜单 + 顶部面包屑
- **图标风格**：线性图标 + 圆角底色块，每个服务模块独立配色
- **装饰元素**：杭州地标剪影水印、钱塘江波浪纹理分隔线

### 4.3 响应式设计

- **职工端（H5）**：移动优先，375px基础宽度，适配至428px
- **管理后台**：桌面优先，1280px最小宽度，侧边栏可折叠
- **数据大屏**：固定1920×1080分辨率，全屏展示模式

### 4.4 动效设计

- 页面切换：右滑进入/左滑退出
- 列表加载：交错渐入动画
- 数字指标：翻牌计数动效
- 按钮反馈：按压缩放+涟漪效果
- 数据大屏：数据实时刷新闪烁效果
