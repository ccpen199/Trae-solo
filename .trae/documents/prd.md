## 1. 产品概述

公路物流信息协同中枢是一个面向货主、司机和专线承运商的 B2B 物流撮合平台，聚焦货主找车、司机找货、专线资源匹配三大核心路径，通过结构化数据发布、智能推荐算法和信用评价体系降低空驶率、提升撮合效率、保障运输合规。

- 解决公路物流中信息不对称、车货匹配效率低、专线资源分散等核心痛点
- 面向中小物流企业、个体货车司机、专线运营商及地方交通监管部门

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 货主 | 手机号/邮箱注册 | 发布货源、查找车源、签订合同、跟踪运输、评价 |
| 司机 | 手机号/邮箱注册 | 发布车源、查找货源、接受运输任务、节点打卡、接受评价 |
| 专线承运商 | 手机号/邮箱注册 + 资质审核 | 管理专线资源、维护时效承诺、处理投诉 |
| 平台管理员 | 后台分配账号 | 用户审核、数据看板、合规校验、系统配置 |

### 2.2 功能模块

1. **工作台首页**：数据概览、待办事项、最新匹配推荐、物流成本指数
2. **货源管理**：多维货源发布、货源列表、货源详情、状态流转
3. **车源管理**：多维车源发布、车源列表、车源详情、状态流转
4. **专线资源库**：专线数据库、承运资质、时效承诺、投诉率统计
5. **智能匹配**：基于地理围栏+历史成交的货-车匹配推荐
6. **运输跟踪**：运输任务管理、关键节点打卡（装货/在途/卸货）
7. **合同管理**：合同生成、电子签章、合同归档
8. **信用评价**：信用分体系、履约率、纠纷率、评价加权
9. **数据看板**：区域物流成本指数、运力供需趋势预测
10. **系统管理**：用户管理、角色权限、合规校验接口、系统配置

## 3. 核心流程

### 货主找车流程
货主发布货源 → 系统智能匹配推荐车源 → 货主浏览匹配结果 → 选定车源发起洽谈 → 生成运输合同 → 双方电子签章 → 司机装货打卡 → 在途打卡 → 卸货打卡 → 双方互评 → 信用分更新

### 司机找货流程
司机发布车源/空驶位置 → 系统智能匹配推荐货源 → 司机浏览匹配结果 → 选定货源申请接单 → 生成运输合同 → 双方电子签章 → 装货/在途/卸货打卡 → 双方互评 → 信用分更新

### 专线匹配流程
货主搜索专线 → 查看承运商资质/时效/投诉率 → 选择专线承运 → 生成合同 → 运输跟踪 → 评价

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1B2A4A）+ 橙色强调色（#E8722A），体现物流行业专业感与活力
- 辅助色：浅灰底（#F5F6FA）、白色卡片、绿色成功态、红色警告态
- 按钮风格：圆角 8px，主按钮填充色，次按钮描边
- 字体：思源黑体/Source Han Sans，标题 20-28px，正文 14px，辅助 12px
- 布局：左侧导航栏 + 顶部工具栏 + 主内容区卡片式布局
- 图标风格：线性图标（Lucide），简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台首页 | 数据概览 | 4 个统计卡片（渐变背景+图标+数字），横向排列 |
| 工作台首页 | 匹配推荐 | 紧凑列表卡片，匹配度进度条，快捷操作按钮 |
| 货源/车源发布 | 表单区域 | 分步表单，下拉选择+标签选择+输入框组合 |
| 货源/车源列表 | 列表区域 | 表格+筛选面板，支持多条件组合筛选 |
| 智能匹配 | 匹配面板 | 左侧列表+右侧地图/详情，匹配度环形进度 |
| 运输跟踪 | 任务看板 | 看板式布局（待装/在途/已卸/完成四列） |
| 数据看板 | 图表区域 | ECharts 图表，热力图+折线图+柱状图 |

### 4.3 响应式设计

- 桌面优先设计，主要服务于 PC 端办公场景
- 最小支持 1280px 宽度，关键页面在 1024px 可用
- 侧边栏可折叠，表格支持横向滚动
