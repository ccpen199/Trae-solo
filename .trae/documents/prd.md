## 1. 产品概述

交互方案评审平台——服务交互设计师、产品经理、研发和用户研究员，实现方案档案、流程评审、决策记录、变更管理和复盘看板的全链路闭环。流程、状态、场景和评审结论连续可查，所有核心动作落库可复查。

- 解决交互方案评审过程中信息散落、决策无追溯、变更难同步的痛点
- 目标用户：交互设计师、产品经理、研发工程师、用户研究员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 交互设计师 | 注册/登录 | 创建/编辑方案、发起评审、回复评论 |
| 产品经理 | 注册/登录 | 评审方案、标注问题、发起决策、查看复盘 |
| 研发工程师 | 注册/登录 | 评审技术可行性、标注研发成本、确认变更 |
| 用户研究员 | 注册/登录 | 评审用户体验、提交验证结论、反馈上线数据 |

### 2.2 功能模块

1. **方案档案**：业务目标、用户角色、关键流程、原型链接、状态图、评审范围
2. **流程评审**：按步骤评论，标注入口不清、状态缺失、异常未覆盖、文案风险、研发成本
3. **决策记录**：争议点、备选方案、选择理由、影响页面、后续验证方式
4. **变更管理**：方案版本、修改说明、关联需求、待同步的设计稿/接口文档
5. **复盘看板**：高频交互问题、评审轮次、未关闭风险、上线后反馈

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

用户创建方案档案 → 定义评审范围和流程步骤 → 参与者按步骤评审并标注问题 → 对争议点发起决策记录 → 方案变更后版本管理 → 同步设计稿和接口文档 → 评审通过后复盘总结

```mermaid

    "创建方案档案" --> "定义流程步骤"
    "定义流程步骤" --> "发起评审"
    "发起评审" --> "按步骤评审"
    "按步骤评审" --> "有问题?"
    "有问题?" --> "是" --> "标注问题"
    "标注问题" --> "有争议?"
    "有问题?" --> "否" --> "评审通过"
    "有争议?" --> "是" --> "发起决策记录"
    "发起决策记录" --> "记录备选方案和选择理由"
    "记录备选方案和选择理由" --> "方案变更"
    "有争议?" --> "否" --> "方案变更"
    "方案变更" --> "版本管理和同步"
    "版本管理和同步" --> "评审通过"
    "评审通过" --> "复盘总结"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e3a5f) + 橙色强调 (#e8723a)，专业且醒目
- 辅助色：浅灰背景 (#f5f6fa)、白色卡片、浅蓝标签 (#dbeafe)
- 按钮风格：圆角 (rounded-lg)，主按钮实色填充，次按钮描边
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- 布局风格：左侧导航 + 右侧内容区，卡片式布局
- 图标风格：使用 Lucide 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 登录表单 | 居中卡片、深色背景、品牌 Logo、输入框、登录按钮 |
| 首页看板 | 统计概览 | 4 列统计卡片（图标+数字+标签）、渐变背景 |
| 首页看板 | 最近活动 | 时间线列表、头像、操作描述、时间戳 |
| 方案列表 | 方案卡片 | 网格布局、状态标签、标题、角色标签、进度条 |
| 方案详情 | 基本信息面板 | 顶部状态栏、分区卡片（目标/角色/流程/链接/状态图） |
| 流程评审 | 步骤列表 | 竖向步骤条、展开/折叠、步骤状态图标 |
| 流程评审 | 评论区 | 气泡评论、问题类型标签（颜色区分）、回复嵌套 |
| 决策记录 | 决策卡片 | 对比式布局（备选方案 vs 选中方案）、影响范围标签 |
| 变更管理 | 版本时间线 | 左侧时间线、版本号、变更摘要、差异数量 |
| 复盘看板 | 问题热力图 | 柱状图/饼图、分类标签、数量气泡 |
| 复盘看板 | 风险追踪 | 表格布局、风险等级标签、责任人头像 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px，1280px 以上充分利用空间。平板端折叠侧边栏，移动端暂不特殊适配。
