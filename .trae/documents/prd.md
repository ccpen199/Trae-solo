## 1. 产品概述

云南省人力资源和社会保障公共服务数字底座，以电子社保卡为统一身份认证载体，集成五险数据，提供个人权益查询、劳动合同管理、待遇资格认证、劳动维权、招考匹配、机构检索等全链条人社公共服务。

面向全省参保群众、用人单位、人社经办机构三类用户，打造线上线下一体化的人社服务生态，实现"一网通办、跨省通办、全程网办"。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 参保个人 | 电子社保卡实名认证 | 查询个人权益、办理业务、维权举证、资格认证 |
| 用人单位 | 营业执照+法人认证 | 劳动合同管理、员工参保、招考发布 |
| 经办机构 | 内部账号+UKey认证 | 业务督办、数据审计、政策管理、知识图谱维护 |
| 系统管理员 | 超管账号 | 地市接入配置、系统监控、安全审计 |

### 2.2 功能模块

1. **首页服务大厅**：服务导航、政策轮播、待办提醒、快捷入口
2. **电子社保卡登录**：扫码登录、人脸登录、账号密码登录
3. **个人权益中心**：五险总览、缴费明细、账户余额、转移接续
4. **劳动合同管理**：在线签署、合同变更、合同终止、存证查询
5. **待遇资格认证**：人脸活体检测、背景比对、认证记录
6. **劳动维权服务**：在线举证、材料上传、进度查询、时间戳存证
7. **招考招聘平台**：岗位发布、智能匹配、简历投递、进度追踪
8. **服务机构地图**：GIS定位、机构检索、导航指引、窗口预约
9. **政策法规库**：政策查询、智能标签、关联推送、收藏管理
10. **咨询问答中心**：智能客服、高频问题、语义搜索、在线咨询
11. **后台管理系统**：数据安全、地市接入、业务督办、知识图谱

## 3. 核心流程

### 3.1 个人权益查询流程

用户通过电子社保卡登录系统，进入个人权益中心，选择险种查看缴费明细、账户余额、转移接续记录。

```mermaid
flowchart LR
    A["电子社保卡登录"] --> B["身份认证"]
    B --> C["进入个人中心"]
    C --> D["选择险种"]
    D --> E["查询数据"]
    E --> F["展示明细"]
    F --> G["下载/打印凭证"]
```

### 3.2 劳动合同在线签署流程

用人单位发起合同签署，员工收到通知，通过电子签名完成在线签署，合同自动存证上链，双方可随时查询验证。

```mermaid
flowchart LR
    A["用人单位发起合同"] --> B["填写合同信息"]
    B --> C["发送给员工"]
    C --> D["员工收到通知"]
    D --> E["在线查看合同"]
    E --> F["电子签名确认"]
    F --> G["存证上链固化"]
    G --> H["通知双方完成"]
```

### 3.3 待遇资格认证流程

用户发起资格认证，系统进行人脸活体检测，完成背景信息比对，认证结果实时同步，认证周期自动记录。

```mermaid
flowchart LR
    A["发起资格认证"] --> B["活体检测"]
    B --> C["人脸比对"]
    C --> D["背景信息校验"]
    D --> E["认证通过"]
    E --> F["生成认证记录"]
    F --> G["同步待遇发放系统"]
```

### 3.4 劳动维权举证流程

用户提交维权申请，上传图片/音视频证据，系统自动加盖时间戳固化证据，转办至经办机构，用户可实时追踪办理进度。

```mermaid
flowchart LR
    A["发起维权申请"] --> B["填写投诉信息"]
    B --> C["上传证据材料"]
    C --> D["时间戳固化存证"]
    D --> E["分派经办机构"]
    E --> F["调查处理"]
    F --> G["反馈处理结果"]
    G --> H["用户评价"]
```

## 4. 用户界面设计

### 4.1 设计风格

**政务服务高端典雅风格**：
- **主色调**：政务蓝 `#1E40AF`、保障金 `#0D9488`
- **辅助色**：警示红 `#DC2626`、成功绿 `#16A34A`、提醒橙 `#F59E0B`
- **中性色**：以 slate 为基础，从 50 到 900 构建完整灰度体系
- **按钮风格**：圆角 8px，轻微阴影，hover 时上移 1px + 阴影加深
- **字体**：正文使用 "Noto Sans SC"，标题使用 "Noto Serif SC" 衬线字体凸显庄重感
- **布局风格**：卡片式布局，清晰的信息层级，充足的留白，政府门户网站风格
- **图标风格**：使用 lucide-react 线性图标，保持简洁统一

### 4.3 响应式设计

- **桌面端优先**：1440px 及以上为主要设计尺寸，采用 12 列栅格系统
- **平板适配**：1024px-1439px，侧边栏可收起，卡片自适应排列
- **移动适配**：768px-1023px，底部导航栏，单列布局，触控优化
- **触控优化**：按钮最小尺寸 44x44px，列表项最小高度 56px，避免误触

### 4.4 动效与交互

- **页面加载**：骨架屏占位 + 淡入动画，内容按区块错落出现
- **数据更新**：数字滚动动效，图表渐入动画
- **操作反馈**：按钮点击缩放效果，表单提交加载状态
- **导航切换**：平滑过渡动画，Tab 切换内容淡入
- **认证流程**：人脸识别扫描线动画，认证通过成功动效
- **上传进度**：文件上传进度条，时间戳盖戳动画
