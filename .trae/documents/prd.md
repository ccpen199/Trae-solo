## 1. 产品概述

法智云（LegalCloud）是面向法律从业者的垂直领域SaaS服务平台，通过整合法律大数据、案源交易、协作办案和智能工具四大核心能力，为律师、律所和法律机构提供一站式数字化解决方案。

- 核心价值：打破法律行业信息壁垒，提升律师办案效率，降低案源获取成本，规范法律服务流程
- 目标用户：执业律师、律所合伙人、企业法务、法律从业者
- 市场定位：中国法律科技领域的全栈式SaaS服务平台

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通律师 | 手机号+实名认证+执业证OCR | 大数据检索、案源竞标、协作办案、智能工具使用 |

### 2.2 功能模块

1. **法律大数据引擎**：多源数据检索、企业全景画像、报告自动生成、开放API
2. **案源交易市场**：案源发布、智能匹配、在线竞标、电子签约、资金托管
3. **协作办案中台**：任务分派、进度看板、证据管理、节点提醒
4. **智能工具集**：7类法律计算器、法条解释模型、文书模板库
5. **个人工作台**：消息中心、待办提醒、数据看板、个人档案

## 3. 核心流程

### 3.1 律师入驻流程

律师通过手机号注册后，需完成实名认证（身份证OCR+人脸识别）和执业证核验（执业证OCR+司法厅数据校验），系统自动计算初始信用分，审核通过后解锁全部功能。

```mermaid
flowchart LR
    A["手机号注册"] --> B["身份证OCR识别"]
    B --> C["人脸识别核验"]
    C --> D["执业证OCR上传"]
    D --> E["司法厅数据校验"]
    E --> F["信用分计算"]
    F --> G["审核通过"]
```

### 3.2 案源交易流程

企业客户发布案源并缴纳履约保证金至平台托管账户，系统根据律师专长/地域/信用分智能匹配，律师提交竞标方案，客户择优录取后在线签署电子委托协议，案件完成后平台释放托管资金。

```mermaid
flowchart LR
    A["企业发布案源"] --> B["缴纳保证金托管"]
    B --> C["系统智能匹配律师"]
    C --> D["律师提交竞标方案"]
    D --> E["客户评估选定"]
    E --> F["签署电子委托协议"]
    F --> G["律师开始办案"]
    G --> H["案件完成验收"]
    H --> I["平台释放托管资金"]
```

### 3.3 协作办案流程

主办律师创建案件并设置办案节点，将任务分派给团队成员，系统自动生成进度看板，证据材料统一归集至证据库，关键诉讼节点自动推送提醒。

```mermaid
flowchart LR
    A["创建案件档案"] --> B["设置诉讼节点"]
    B --> C["任务分派成员"]
    C --> D["生成协作看板"]
    D --> E["证据材料归集"]
    E --> F["节点自动提醒"]
    F --> G["进度实时更新"]
    G --> H["案件结案归档"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深邃藏蓝 `#0A1628` — 传递专业、权威、可信赖的法律气质
- **辅助色**：鎏金黄 `#C9A962` — 彰显高端品质感，用于关键操作和数据高亮
- **强调色**：朱砂红 `#B23A48` — 用于风险提示、警示信息和重要状态
- **中性色**：象牙白 `#F5F1E8`、墨玉灰 `#6B7280`、玄铁黑 `#111827`
- **按钮风格**：微立体方形按钮，4px圆角，悬停有细腻的光泽渐变过渡
- **字体体系**：标题使用"思源宋体 SemiBold"传递法律文书的庄重感，正文使用"PingFang SC"保证阅读舒适度，数字和英文使用"JetBrains Mono"体现精确感
- **布局风格**：左导航+顶部状态栏的经典企业级布局，卡片式内容容器，8px栅格系统
- **图标风格**：线性图标配合微量面性填充，统一2px描边，圆角处理
- **动效原则**：克制而专业，过渡动画200ms ease-out，数据看板采用渐进式加载动效

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|

### 4.3 响应式设计

- **设计策略**：桌面端优先（1440px基准），平板端（1024px）自适应，移动端（375px）精简核心功能
- **桌面端**：左导航240px固定宽度，主内容区最大宽度1400px居中，侧边栏可折叠至64px图标模式
- **平板端**：左导航改为顶部折叠菜单，卡片改为双列或三列布局
- **移动端**：仅保留核心功能（工作台、检索、消息、我的），底部Tab导航，复杂表格改为卡片列表

### 4.4 数据可视化设计

- **企业关系图谱**：力导向图，节点按类型着色（企业-藏蓝、自然人-墨灰、法院-朱砂），连线粗细代表关联强度
- **涉诉时间轴**：垂直时间轴，节点图标区分案件类型，悬停展开案件摘要
- **风险雷达图**：六维度（涉诉风险/执行风险/经营风险/舆情风险/合规风险/信用风险），实时计算评分
- **数据看板**：数字滚动动效，进度条渐变填充，迷你趋势图嵌入卡片标题右侧
