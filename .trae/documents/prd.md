## 1. 产品概述

川渝城市会员权益融合平台是一个以地域联盟商户网络为核心资产的城市级会员权益操作系统，覆盖成都、宜宾、绵阳等10+地市，支持独立运营与跨城互通。平台为消费者提供一码通城的会员权益体验，为商户提供跨城流量导入与统一结算能力，为运营方提供地市维度的经营数据看板与规则治理引擎。

- 目标用户：川渝地区消费者（C端会员）、联盟商户（B端）、平台运营方（G端）
- 核心价值：打破城市会员体系壁垒，实现"一城入会、十城通行"的权益互认，构建川渝消费生态联盟

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| C端会员 | 手机号注册登录 | 浏览权益、领取优惠券、积分兑换、跨城消费、电影选座、电商跳转 |
| B端商户 | 资质审核入驻 | 管理店铺/商品、查看结算、配置优惠活动、核销扫码 |

### 2.2 功能模块

1. **平台首页**：城市切换器、联盟数据动态、核心业务入口（会员/商户/场景/看板）、城市特色推荐
2. **数据运营看板**：地市维度GMV趋势、复购率分析、券核销率监控、跨城消费流向热力图
3. **会员权益中心**：会员画像（手机号+LBS+消费等级标签）、积分总览、跨城权益互认状态、个性化推荐
4. **商户治理中心**：商户入驻审核流（营业执照OCR+人工复核+保证金管理）、跨城权益互认规则引擎、结算周期配置
5. **消费场景广场**：电影选座嵌入式体验、电商CPS分佣跳转、本地生活SKU、线下核销扫码

## 3. 核心流程

### 3.1 会员跨城消费流程

用户在A城注册成为会员，前往B城消费时，系统自动识别LBS定位，调用跨城权益互认规则引擎计算积分兑换比例与可用权益，用户以B城等效权益完成消费，积分按比例从A城账户扣除。

```mermaid
flowchart TD
    "A城会员登录" --> "LBS自动定位B城"
    "LBS自动定位B城" --> "调用跨城规则引擎"
    "调用跨城规则引擎" --> "计算积分兑换比例"
    "计算积分兑换比例" --> "展示B城可用权益"
    "展示B城可用权益" --> "用户选择消费场景"
    "用户选择消费场景" --> "完成消费核销"
    "完成消费核销" --> "A城积分按比例扣除"
```

### 3.2 商户入驻审核流程

商户提交入驻申请，系统通过OCR识别营业执照信息，进入人工复核环节，审核通过后缴纳保证金，配置结算周期，正式上线运营。

```mermaid
flowchart TD
    "商户提交入驻申请" --> "营业执照OCR识别"
    "营业执照OCR识别" --> "信息校验通过?"
    "信息校验通过?" --> "是: 进入人工复核"
    "信息校验通过?" --> "否: 退回补充材料"
    "退回补充材料" --> "商户提交入驻申请"
    "进入人工复核" --> "复核通过?"
    "复核通过?" --> "是: 缴纳保证金"
    "复核通过?" --> "否: 驳回申请"
    "缴纳保证金" --> "配置结算周期"
    "配置结算周期" --> "商户正式上线"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题色**：以川渝地域文化为灵感，主色采用"蜀锦红"（#C41230）搭配"锦官金"（#D4A843），辅以"雾都灰"（#2D2D3A）深色背景，营造高端地域联盟质感
- **按钮风格**：圆角微凸3D按钮，主按钮蜀锦红渐变，次按钮金色描边
- **字体**：标题使用思源宋体（Noto Serif SC）彰显文化底蕴，正文使用HarmonyOS Sans保证可读性
- **布局风格**：左侧导航+右侧内容区，卡片式布局，数据看板采用深色主题
- **图标风格**：线性+面性混合图标，金色点缀，川渝文化元素（竹编纹理、蜀锦纹样）作为装饰
- **动效**：城市切换时地图涟漪动画，数据加载时水墨晕染效果，卡片入场使用阶梯式渐显
