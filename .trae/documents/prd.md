## 1. 产品概述

北京市燃气用户数字化服务中台——面向北京市燃气居民及工商业用户的全生命周期数字化管理平台，覆盖抄表、缴费、报修、巡检、安全预警五大核心业务场景，同时为运营管理人员提供账单引擎、智能排程、工单闭环及城市运行指标报送能力。

- 核心目标：将传统线下燃气服务流程全面数字化，实现"用户自助 + AI 主动预警 + 网格化闭环"的智慧燃气服务模式
- 目标用户：北京市燃气居民用户、工商业用户、片区网格员、运营管理人员、城市运行管理平台对接

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |

### 2.2 功能模块

1. **总控仪表盘**：全局运营指标、实时告警、业务概览、快捷入口

3. **智能抄表**：OCR表具照片识别录入、手动录入、抄表记录管理
4. **缴费中心**：账单查看、在线支付、阶梯计价展示、缴费历史
5. **报修工单**：一键报修、AI异常自动生成工单、工单派发与跟踪、闭环评价
6. **巡检管理**：巡检计划、巡检任务分配、现场记录、问题上报
7. **安全预警中心**：AI异常用量预警（零用气、突增）、预警规则配置、主动外呼记录
8. **GIS服务网点**：地图定位附近网点、实时排队人数、导航路线
9. **后台管理**：阶梯计价规则配置、停气计划排程与影响范围模拟、账单生成引擎、城市运行指标报送

## 3. 核心流程

### 3.1 智能抄表与缴费流程

用户打开智能抄表页面，拍摄表具照片，OCR引擎识别表盘读数并自动填入，用户确认后提交。系统根据本期读数与上期读数计算用气量，应用阶梯计价规则生成账单，用户在缴费中心查看账单并完成在线支付。

```mermaid
flowchart TD
    "用户打开抄表页面" --> "拍摄/上传表具照片"
    "拍摄/上传表具照片" --> "OCR引擎识别读数"
    "OCR引擎识别读数" --> "用户确认读数"
    "用户确认读数" --> "计算本期用气量"
    "计算本期用气量" --> "应用阶梯计价规则"
    "应用阶梯计价规则" --> "生成气费账单"
    "生成气费账单" --> "用户在线支付"
    "用户在线支付" --> "缴费完成"
```

### 3.2 AI异常预警与工单闭环流程

AI引擎实时监控用气数据，当检测到连续7日零用气或用量突增等异常模式时，自动生成预警事件。系统根据预警级别决定是否触发主动外呼通知用户，同时自动生成报修工单并派发至对应片区网格员。网格员现场处理后更新工单状态，用户收到完成通知并进行满意度评价。

```mermaid
flowchart TD
    "AI引擎实时监控" --> "检测异常用气模式"
    "检测异常用气模式" --> "生成预警事件"
    "生成预警事件" --> "触发主动外呼"
    "生成预警事件" --> "自动生成报修工单"
    "自动生成报修工单" --> "派发至片区网格员"
    "派发至片区网格员" --> "网格员现场处理"
    "网格员现场处理" --> "更新工单状态"
    "更新工单状态" --> "用户收到完成通知"
    "用户收到完成通知" --> "满意度评价闭环"
```

### 3.3 停气计划排程流程

运营管理员创建停气计划，选择影响区域与时间段，系统自动模拟影响范围（户数、地图展示），确认后发布停气通知，同步推送至受影响用户。

```mermaid
    "系统模拟影响范围" --> "确认发布"
    "确认发布" --> "推送停气通知"
    "推送停气通知" --> "同步至城市运行平台"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：燃气蓝 `#0052CC` + 火焰橙 `#FF6B35` 作为强调色，传达安全可靠与能源活力
- **辅助色**：中性灰 `#F8F9FA`（背景）、`#1A1A2E`（深色文字）、`#E8F4FD`（信息卡片背景）
- **按钮风格**：圆角6px，主按钮为实色填充，次按钮为描边样式，危险操作用火焰橙警示
- **字体**：思源黑体（Noto Sans SC）作为正文字体，数据展示使用等宽字体 JetBrains Mono
- **布局风格**：左侧导航栏 + 主内容区域，卡片式布局，信息密度适中
- **图标风格**：线性图标（Lucide），2px描边，与文字对齐

### 4.3 响应式设计

- 桌面优先设计，主要适配1920px和1440px宽度
- 平板端（768px-1024px）：左侧导航折叠为图标模式，卡片从4列变为2列
- 移动端（<768px）：底部Tab导航，卡片单列堆叠，地图全屏展示

### 4.4 动效设计

- 页面切换：淡入淡出 200ms
- 卡片悬停：上移2px + 阴影扩展，150ms ease-out
- 数据加载：骨架屏占位，脉冲动画
- 告警新增：从右侧滑入 + 闪烁高亮
- 工单状态变更：对应节点缩放弹跳动画
