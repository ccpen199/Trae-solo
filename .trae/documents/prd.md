## 1. 产品概述

红河州本地化生活协同平台是一款面向云南省红河哈尼族彝族自治州居民的一站式生活服务平台，聚焦信息聚合、社交连接与在地交易三重目标。平台通过结构化本地资讯流、基于地理与兴趣的"生活圈"社区、轻量级本地电商模块、婚恋匹配子系统及数据看板，打造红河州专属的数字生活基础设施。

- **核心问题**：红河州缺乏统一的本地生活数字平台，居民需在多个分散渠道获取资讯、社交与交易服务
- **目标用户**：红河州常住居民（18-60岁），包括普通居民、商户经营者、政务信息发布者
- **市场价值**：构建红河州本地生活服务生态闭环，提升居民生活便利度与社区凝聚力

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 手机号注册 | 浏览资讯、发帖互动、购物下单、参与活动、婚恋匹配 |
| 商户 | 手机号注册+资质核验 | 商品上架、订单管理、活动发布 |
| 圈主 | 申请+管理员审核 | 圈子管理、内容审核、成员管理 |
| 管理员 | 后台授权 | 全局内容审核、用户管理、数据看板 |

### 2.2 功能模块

1. **首页**：资讯流聚合、热点话题、搜索入口、模块导航
2. **资讯中心**：热点话题标签流、UGC爆料审核流、政务公示专栏
3. **生活圈**：圈子列表与发现、圈子详情与动态、同城活动
4. **本地商城**：商户入驻与商品浏览、商品详情与下单、订单履约跟踪
5. **婚恋匹配**：实名认证与资料填写、智能筛选与推荐、双向意向机制
6. **数据看板**：各模块活跃度监测、地域热力分布图
7. **个人中心**：个人资料、我的圈子、我的订单、我的活动、设置

## 3. 核心流程

### 3.1 UGC爆料审核流

用户提交爆料内容 → 系统自动标记待审核状态 → 管理员审核（通过/驳回） → 通过后发布至资讯流 / 驳回后通知用户并说明原因

### 3.2 圈子创建审核流

用户提交圈子创建申请 → 管理员审核（通过/驳回） → 通过后创建圈子并设置申请者为圈主 / 驳回后通知用户

### 3.3 商户入驻核验

商户提交资质信息 → 管理员核验（通过/驳回） → 通过后开通商户后台 / 驳回后通知补充材料

### 3.3 订单履约跟踪

用户下单支付 → 商户确认订单 → 履约中（含预约上门时间轴） → 服务完成 → 用户确认/自动确认

### 3.4 婚恋匹配流程

用户完成实名认证 → 填写个人资料与择偶偏好 → 系统智能推荐 → 用户表达意向 → 对方亦表达意向则匹配成功 → 双方获得联系方式（隐私保护式）

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：红河梯田红棕色（#C4533A）为主色，搭配哈尼族靛蓝（#2D5A7B）为辅助色，体现红河州地域文化
- **辅助色**：梯田金黄（#E8B44D）用于强调与高亮，自然绿（#5A8F5A）用于状态指示
- **中性色**：暖灰色系（#F5F0EB 浅底、#3D3532 深文字），营造温暖在地感
- **按钮风格**：圆角8px，主按钮填充红棕色，次按钮描边风格，hover带微缩放动效
- **字体**：标题使用"思源宋体"风格衬线体，正文使用"思源黑体"无衬线体
- **布局风格**：卡片式布局，顶部固定导航，侧边栏可收缩，内容区最大宽度1200px居中
- **图标风格**：线性图标（lucide-react），2px描边，与文字同色
- **装饰元素**：梯田等高线纹理作为背景装饰，民族纹样用于分隔线与徽标

### 4.3 响应式设计

- 桌面优先设计，最大内容宽度1200px
- 平板（768-1024px）：网格列数减少，侧边栏收缩为图标模式
- 手机（<768px）：单列布局，底部Tab导航，卡片全宽，浮动按钮适配小屏

### 4.4 动效设计

- 页面切换：淡入淡出过渡
- 卡片悬停：translateY(-4px) + box-shadow加深
- 列表加载：交错淡入（stagger fade-in），每项延迟80ms
- 数据看板：数字滚动动画（count-up）
- 婚恋匹配卡片：滑动动效，左滑跳过/右滑意向
