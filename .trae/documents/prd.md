## 1. 产品概述

面向中高端人才市场的智能职业匹配平台，连接候选人、企业与猎头顾问三方，通过结构化简历与JD语义向量的双向深度匹配、猎头服务全流程数字化、招聘效能漏斗归因分析，实现从职位发布到Offer转化的全链路智能化。同时覆盖大学生校招专项通道，提供校招日程同步、实习转正率预测和校园大使任务分发。

- 目标用户：中高端职场人才、招聘企业HR/用人部门、猎头顾问、在校大学生
- 核心价值：降低中高端人才匹配摩擦成本，提升猎头服务效率，量化招聘全流程效能

## 2. 核心功能

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|

| 猎头顾问 | 审核注册 | 管理候选人档案、沟通记录、跟进计划、服务过程数字化 |

### 2.2 功能模块

1. **仪表盘首页**：全局数据概览、待办提醒、快捷操作入口
2. **候选人管理**：结构化简历CRUD、项目成果量化、隐私脱敏沙箱
3. **职位管理**：企业JD发布与编辑、语义向量标注、职位状态流转

5. **猎头工作台**：客户管理、沟通记录自动摘要、跟进计划智能提醒
6. **面试评估**：面试安排、结构化评估表单、评分汇总
7. **招聘分析**：漏斗归因、转化率、效能看板
8. **校招通道**：校招日程、实习转正率预测、校园大使任务分发
9. **后台管理**：企业信用评级、AI面试官数据集、薪酬基准动态更新

## 3. 核心流程

### 3.1 简历-岗位匹配流程
候选人在平台创建结构化简历，企业发布JD并标注语义向量，系统基于技术栈权重、行业经验年限、职级跃迁逻辑计算双向匹配度，生成推荐列表供猎头/HR参考。

```mermaid
flowchart TD
    "候选人创建简历" --> "系统提取结构化字段"
    "企业发布JD" --> "系统生成语义向量"
    "系统提取结构化字段" --> "匹配引擎计算"
    "系统生成语义向量" --> "匹配引擎计算"
    "匹配引擎计算" --> "技术栈匹配度"
    "匹配引擎计算" --> "行业经验匹配度"
    "匹配引擎计算" --> "职级跃迁逻辑"
    "技术栈匹配度" --> "综合匹配评分"
    "行业经验匹配度" --> "综合匹配评分"
    "职级跃迁逻辑" --> "综合匹配评分"
    "综合匹配评分" --> "推荐列表"
    "推荐列表" --> "猎头/HR审核"
    "猎头/HR审核" --> "发起面试"
```

### 3.2 猎头服务流程
猎头接收匹配推荐后，与候选人沟通，记录沟通内容（系统自动摘要），制定跟进计划，系统到期提醒，推动候选人进入面试流程。

```mermaid
flowchart TD
    "猎头查看推荐" --> "联系候选人"
    "联系候选人" --> "记录沟通内容"
    "记录沟通内容" --> "自动生成摘要"
    "自动生成摘要" --> "制定跟进计划"
    "制定跟进计划" --> "到期智能提醒"
    "到期智能提醒" --> "安排面试"
    "安排面试" --> "结构化评估"
    "结构化评估" --> "Offer决策"
```

### 3.3 招聘效能分析流程
从职位发布开始，系统自动追踪每个阶段的转化数据，构建漏斗模型，归因分析识别瓶颈。

```mermaid
flowchart TD
    "职位发布" --> "简历收取"
    "简历收取" --> "简历筛选"
    "简历筛选" --> "面试邀约"
    "面试邀约" --> "面试进行"
    "面试进行" --> "Offer发放"
    "Offer发放" --> "入职确认"
    "入职确认" --> "漏斗归因分析"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝灰 (#1a2332) 为底，科技蓝 (#3b82f6) 为强调色，配合琥珀色 (#f59e0b) 作为行动点
- 辅助色：翡翠绿 (#10b981) 表示成功/在线，玫红 (#ef4444) 表示警告/紧急
- 按钮风格：圆角 8px，主按钮有微妙渐变和悬浮阴影效果
- 字体：标题用 DM Sans，正文用 Inter，数据用 JetBrains Mono
- 布局：左侧固定导航栏 + 顶部面包屑 + 主内容区，卡片式内容组织
- 图标：Lucide React 图标库，线条风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 数据概览 | 4个指标卡片（渐变背景）、折线趋势图、饼图分布 |
| 仪表盘 | 待办提醒 | 时间线样式，带优先级色标 |
| 候选人列表 | 筛选栏 | 多选标签组、搜索框、排序下拉 |
| 候选人列表 | 卡片网格 | 头像+姓名+标签+匹配度进度条 |
| 候选人详情 | 能力图谱 | 雷达图展示技术栈分布 |
| 匹配中心 | 双列对比 | 左右分栏，中间匹配度环形进度 |
| 招聘分析 | 漏斗图 | 横向漏斗，各阶段宽度按比例 |
| 校招通道 | 日程卡片 | 日历视图+列表切换 |

### 4.3 响应式
桌面优先设计，最小宽度 1280px，平板 1024px 适度适配，核心功能不依赖移动端

### 4.4 动效
- 页面切换：淡入淡出 200ms
- 卡片悬浮：上移 2px + 阴影增强
- 数据加载：骨架屏 pulse 动画
- 匹配度分数：数字滚动动画
