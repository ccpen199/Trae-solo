# 省级 ETC 角色工作台 - PRD 产品需求文档

## 1. 项目概述

### 1.1 项目背景
省级高速公路 ETC 收费系统需要面向不同角色提供差异化的业务工作台，解决目前单一后台台账无法覆盖车主、车队、运营、运维多角色业务场景的问题。

### 1.2 项目目标
- 实现 5 种角色权限分层承接（车主/车队管理员/运营/运维/系统管理员）
- 通行记录形成完整业务闭环（月结单→轨迹核验→费用拆分→异常申诉）
- 用户与车辆、OBU、ETC 账户、车队的业务绑定
- OBU 设备全生命周期管理（采购→入库→激活→升级→报废→审计）

### 1.3 核心对象
| 对象 | 说明 |
|------|------|
| 用户 | 车主/车队管理员/运营/运维/系统管理员，5 种角色 |
| 车队 | 企业/物流车队，包含多辆车和多个车主 |
| 车辆 | 车牌号、车型、车种、所属车队/车主 |
| OBU 设备 | 设备序列号、型号、固件版本、状态（库存/已激活/已停用/已报废） |
| ETC 账户 | 账户余额、账单、充值记录、扣费记录 |
| 通行记录 | 门架/收费站、时间、费用、车型、交易状态 |
| 月结单 | 每月汇总账单、通行次数、总费用、优惠金额 |
| 通行轨迹 | 多门架记录串联形成完整行驶路径 |
| 异常扣费 | 费用异常、路径异常、车牌不符等 |
| 申诉工单 | 用户提交申诉、运营审核、处理结果 |
| 升级任务 | OBU 固件批量升级、任务进度、结果回执 |
| 审计日志 | 所有操作留痕（操作人、IP、时间、内容） |

## 3. 核心业务流程

### 3.1 通行记录闭环流程
```
车辆通过门架/收费站 → 生成通行记录 → 费用计算拆分
        ↓
日终汇总 → 生成月结单（次月 3 日）
        ↓
用户查看月结单 → 查看通行轨迹 → 查看费用明细拆分
        ↓
有疑问？→ 选择异常记录 → 提交申诉工单
        ↓
运营人员审核 → 核实通行轨迹 → 确认/驳回 → 费用退补
        ↓
用户查看处理结果 → 确认结案
```

### 3.2 车主/车队绑定流程
```
用户注册/登录 → 实名认证 → 添加车辆信息
        ↓
上传行驶证 → 系统校验车牌有效性 → 绑定 OBU 设备（扫码输入序列号）
        ↓
ETC 账户开户 → 绑定支付方式 → 激活设备
        ↓
车队管理员可批量导入车辆 → 批量绑定 OBU → 分配车主归属
```

### 3.3 OBU 设备生命周期流程
```
设备采购入库 → 录入系统（序列号/型号/批次号/固件版本）→ 库存状态
        ↓
车主/车队申请 → 设备出库 → 绑定车辆 → 远程激活
        ↓
激活结果回执 → 成功/失败 → 失败重试
        ↓
固件升级任务 → 批量推送 → 升级结果上报 → 审计记录
        ↓
设备故障 → 报修/更换 → 旧设备报废 → 生命周期结束
```

## 4. 功能模块与页面详情

### 4.1 工作台总览（按角色差异化）

#### 系统管理员工作台
- 全站核心指标：用户总数、车辆总数、OBU 总数、今日通行量、今日通行费
- 近 30 天通行趋势图（车辆数/费用）
- 异常告警：待处理申诉、升级任务进度、设备故障率
- 快捷入口：用户管理、设备管理、系统设置

#### 运营工作台
- 今日运营指标：通行车次、总费用、待处理申诉、异常扣费数
- 近 7 天申诉处理趋势
- 待办事项：待审核申诉、待确认月结单、异常交易提醒
- 热门路段 TOP10

#### 运维工作台
- 设备健康指标：在线率、升级成功率、故障率
- 待执行升级任务列表
- 最近 24 小时设备异常告警
- OBU 激活失败 TOP10

#### 车队管理员工作台
- 本车队指标：车辆数、月通行费、月通行次数、待申诉数
- 本车队月度费用趋势
- 车辆通行排名 TOP10
- 待办：待确认月结单、待处理异常

#### 车主工作台
- 个人指标：绑定车辆数、月通行费、ETC 账户余额
- 最近 7 天通行记录
- 未读月结单提醒
- ETC 账户充值入口

### 4.2 用户管理
- 用户列表：支持按角色、车队、状态筛选
- 新增用户表单：
  - 基础信息：姓名、手机号、邮箱、身份证号
  - 角色选择：车主/车队管理员/运营/运维/系统管理员
  - 业务绑定：所属车队（可选）、关联车辆（可选）
  - 权限边界：可查看的车队/车辆范围
- 编辑用户：支持修改角色、重置密码、调整权限范围
- 用户详情：个人信息、绑定车辆、申诉历史、操作记录

### 4.3 车辆管理
- 车辆列表：车牌号、车型、车种、所属车队、绑定 OBU、状态
- 新增车辆表单：
  - 车牌号、车型（客车/货车）、车种（1 类-6 类）、颜色
  - 车架号、发动机号、注册日期
  - 行驶证照片上传
  - 所属车队、绑定车主
  - 绑定 OBU 设备（序列号扫码输入）
- 车辆详情：基础信息、通行记录、月结单、绑定 OBU、变更记录

### 4.4 OBU 设备管理
- 设备列表：序列号、型号、固件版本、批次号、状态、绑定车辆、激活时间
- 筛选：状态（库存/已激活/已停用/已报废）、型号、批次
- 批量操作：批量激活、批量升级、批量导出
- 新增设备表单（单台/批量导入）：
  - 序列号、型号、固件版本、批次号、采购日期
  - 批量导入支持 Excel 模板
- 设备详情：
  - 基础信息、绑定关系、激活日志
  - 升级历史记录（版本、时间、结果、操作人）
  - 全生命周期审计记录（入库→出库→激活→升级→报废）

### 4.5 通行记录查询
- 查询条件：车牌号、时间段、门架/收费站、费用范围、交易状态
- 列表展示：通行时间、出入口、门架、车牌号、车型、费用、交易状态
- 详情页：
  - 基础信息
  - **通行轨迹**：按时间顺序串联所有门架记录，地图可视化展示
  - **费用明细拆分**：基础路费、桥隧费、叠加费、优惠金额、实付金额
  - 关联 OBU、关联 ETC 账户、扣费流水号
- 操作：导出 Excel、发起申诉

### 4.6 月结单管理
- 月结单列表：月份、用户/车队、车辆数、通行次数、总金额、优惠金额、实付金额、状态
- 月结单详情：
  - 汇总信息
  - **费用明细**：按车辆分组、按路段分组
  - **关联通行记录**：可跳转查看每条记录详情
  - 批量申诉入口

### 4.7 异常扣费与申诉
- 异常扣费列表：车牌号、通行时间、异常类型、异常金额、申诉状态
- 异常类型：路径异常、费用异常、车牌不符、重复扣费、设备故障
- 申诉工单：
  - 用户提交：选择异常记录、填写申诉原因、上传凭证
  - 运营审核：查看通行轨迹、核实费用、给出处理结果（确认退费/驳回）
  - 处理结果：退费金额、处理说明、到账时间
- 申诉详情：申诉流转记录、审核日志、处理结果

### 4.8 OBU 固件升级
- 升级任务列表：任务名称、固件版本、设备数量、成功数、失败数、进度、状态
- 创建升级任务：
  - 任务名称、选择固件版本、选择目标设备（按车型/车队/状态筛选）
  - 推送策略：立即推送/定时推送
- 任务详情：
  - 设备升级结果列表（成功/失败/进行中）
  - 失败设备原因统计
  - 升级日志审计（操作人、开始时间、结束时间）

### 4.9 车队管理
- 车队列表：车队名称、企业类型、联系人、车辆数、月通行费
- 车队详情：基本信息、车辆列表、车队管理员、月度费用趋势
- 车队管理员可：管理本车队车辆、查看本车队所有通行记录和月结单

### 4.10 ETC 账户管理
- 账户列表：用户、账户余额、冻结金额、状态
- 充值记录：金额、支付方式、时间、交易流水号
- 扣费记录：关联通行记录、金额、时间、状态

### 4.11 审计日志
- 操作日志：操作人、角色、IP 地址、操作时间、操作类型、操作内容
- 筛选：操作人、时间段、操作类型、模块
- 导出 CSV

## 5. 技术与设计规范

### 5.1 设计风格
- **主题色**：交通蓝 (#1E6FDD)、警示橙 (#FF8A00)、成功绿 (#10B981)、危险红 (#EF4444)
- **背景**：深蓝灰暗色主题，适配 7×24 小时运营场景
- **字体**：JetBrains Mono（等宽数据展示）、Noto Sans SC（正文）
- **布局**：左侧可折叠导航栏 + 顶部面包屑 + 主内容区
- **表格**：斑马纹、行悬停高亮、支持固定列

### 5.2 数据展示规范
- 金额统一保留 2 位小数，单位：元
- 时间统一格式：YYYY-MM-DD HH:mm:ss
- 车牌号大写展示：京 A·12345
- 敏感信息脱敏：手机号 138****8888、身份证号 110101********1234

### 5.3 业务规则
- 月结单生成时间：每月 3 日凌晨 2:00 生成上月账单
- 申诉有效期：月结单生成后 30 天内可申诉
- OBU 激活超时：300 秒未收到激活回执视为失败
- 费用计算精度：计算时保留 6 位小数，展示时保留 2 位
