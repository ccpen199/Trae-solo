## 1. 产品概述

电池全生命周期管理系统——从入库、使用、维护到退役的资产追踪平台，服务设备资产、运维、安全和财务四条业务线，确保每块电池拥有完整履历。

- 面向运营、维保、安全和财务人员，提供一站式电池资产数字化管理
- 目标：消除电池资产盲区、降低安全风险、延长电池经济寿命、提升退役决策效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统预设 | 全部模块读写、系统配置、用户管理 |
| 运维人员 | 管理员创建 | 电池档案、使用记录、维护计划读写 |
| 安全员 | 管理员创建 | 安全告警读写、高风险电池限制操作 |
| 财务人员 | 管理员创建 | 资产报表只读、导出 |

### 2.2 功能模块

1. **仪表盘**：关键指标卡片、近期告警、待办任务、资产概览图表
2. **电池档案**：电池编码、型号、供应商、采购批次、容量、质保期、初始检测结果
3. **使用记录**：关联车辆/站点/订单、充放电次数、温度、SOC/SOH、异常事件
4. **维护计划**：按循环次数/健康度/故障码/时间触发，生成检测/维修/报废/梯次利用任务
5. **安全告警**：鼓包、高温、绝缘异常、容量衰减、召回批次，限制高风险电池流转
6. **资产报表**：库存价值、折旧、健康分布、退役预测、供应商质量表现

## 3. 核心流程

**电池入库流程**：录入档案 → 初始检测 → 结果落库 → 电池状态变为"在库"

**电池使用流程**：分配至车辆/站点 → 记录充放电数据 → 定期更新SOC/SOH → 异常事件自动触发告警

**维护触发流程**：系统按循环次数/健康度/故障码/时间条件扫描 → 生成维护任务 → 运维人员执行 → 结果落库 → 更新电池状态

**安全告警流程**：异常事件/阈值触发告警 → 安全员确认 → 限制高风险电池流转 → 处理结果落库

**退役决策流程**：健康度低于阈值/质保到期 → 系统建议退役/梯次利用 → 审批 → 状态更新

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰蓝（#1E293B）+ 电力蓝（#0EA5E9）强调色
- 辅助色：琥珀色（#F59E0B）告警、红色（#EF4444）危险、翠绿（#10B981）健康
- 按钮风格：圆角矩形，悬停加深 + 微动效
- 字体：DM Sans（标题）+ Source Sans 3（正文）
- 布局：左侧导航栏 + 顶部面包屑 + 内容区卡片式布局
- 图标风格：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 指标卡片 | 四列卡片，深色背景白色数字，底部微型趋势线 |
| 仪表盘 | 近期告警 | 列表卡片，左侧色条标识严重程度 |
| 仪表盘 | 资产概览 | 饼图 + 折线图，深色面板 |
| 电池档案列表 | 筛选栏 | 顶部搜索框 + 下拉筛选，行内布局 |
| 电池档案列表 | 表格 | 斑马纹表格，状态标签彩色圆点 |
| 电池档案详情 | 标签页 | 基础信息/使用历史/维护记录三栏切换 |
| 安全告警列表 | 表格 | 红色/琥珀色行背景标识严重程度 |
| 资产报表 | 图表组 | 卡片内嵌图表，2x2 网格布局 |

### 4.3 响应式设计

- 桌面优先设计，1280px+ 最佳体验
- 1024px-1280px：侧边栏折叠为图标
- 768px 以下：表格切换为卡片列表
