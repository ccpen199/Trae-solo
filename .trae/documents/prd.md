## 1. 产品概述

共享充电站运营系统，为充电站运营商、运维人员、用户客服和财务提供一站式管理平台。系统覆盖站点档案管理、充电设备监控、用户订单跟踪、运维工单处理和财务收益分成五大核心模块，所有核心动作落库可复查。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 系统管理员 | 全部功能，站点/设备/用户管理 |
| 运营人员 | 站点管理、设备监控、订单查看 |
| 运维人员 | 设备状态监控、工单处理、维修记录 |
| 财务人员 | 财务报表、收益分成、退款审核 |

### 2.2 功能模块

1. **仪表盘**：站点概览、设备在线率、今日订单、收入统计、待处理工单
2. **站点管理**：站点档案CRUD、设备数量、电价/服务费/分成规则、营业时间
3. **设备管理**：设备列表、端口状态、在线/离线、功率、故障码、心跳时间、离线自动生成运维工单
4. **订单管理**：订单列表、扫码启动、充电时长/电量/费用、停止原因、退款状态
5. **运维工单**：工单列表、离线/端口损坏/充电中断/用户投诉类型、维修照片、处理时间
6. **财务报表**：按站点/设备/订单/合作方统计收入、电费、退款、分账

## 3. 核心流程

### 3.1 充电订单流程

用户扫码 → 系统创建订单 → 启动充电 → 实时记录电量/时长 → 用户停止/充满自动停 → 计算费用 → 生成账单 → 如需退款则走退款流程

```mermaid
flowchart TD
    "用户扫码" --> "创建订单"
    "创建订单" --> "启动充电"
    "启动充电" --> "记录电量/时长"
    "记录电量/时长" --> "充电完成"
    "充电完成" --> "计算费用"
    "计算费用" --> "生成账单"
    "生成账单" --> "支付完成"
    "支付完成" --> "订单关闭"
    "充电完成" --> "申请退款"
    "申请退款" --> "退款审核"
    "退款审核" --> "退款完成"
```

### 3.2 运维工单流程

设备离线/故障 → 自动/手动创建工单 → 分配运维人员 → 现场维修 → 上传照片 → 填写处理结果 → 关闭工单

```mermaid
flowchart TD
    "设备离线/故障" --> "自动/手动创建工单"
    "自动/手动创建工单" --> "分配运维人员"
    "分配运维人员" --> "现场维修"
    "现场维修" --> "上传照片+填写结果"
    "上传照片+填写结果" --> "关闭工单"
```

### 3.3 财务分账流程

订单完成 → 计算电费成本 → 按分成规则计算各方收入 → 生成分账记录 → 合作方报表可查

```mermaid
flowchart TD
    "订单完成" --> "计算电费成本"
    "计算电费成本" --> "按分成规则分账"
    "按分成规则分账" --> "生成分账记录"
    "生成分账记录" --> "合作方报表"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1e40af + 青绿 #06b6d4 作为科技能源感配色
- 辅助色：琥珀 #f59e0b 用于告警、翡翠绿 #10b981 用于正常状态
- 按钮风格：圆角8px，主操作实色填充，次操作描边
- 字体：系统字体栈，标题加粗
- 布局：左侧导航栏 + 右侧内容区，卡片式信息展示
- 图标：lucide-react 图标库

### 4.2 页面设计概览
