## 1. 产品概述

专业护理服务调度平台，连接持证护士、患者与医疗机构，实现护士执业资格核验、服务项目结构化发布、智能派单、服务全程留痕、保险自动投保、家属端查看及监管合规审计的闭环业务系统。

- 解决居家护理服务中护士资质核验难、派单效率低、服务留痕缺失、监管合规难等痛点
- 面向护士、患者/家属、医疗机构运营人员、卫健监管部门四类用户

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 护士 | 执业资格注册，需提交护士证+卫健委比对 | 接单、执行服务、上传留痕、查看排班 |
| 患者/家属 | 手机号注册 | 发布需求、查看服务计划/实时位置/服务报告/电子病历摘要、确认服务 |
| 机构运营 | 后台创建账号 | 发布服务项目、管理护士、派单、查看统计 |
| 监管人员 | 后台创建账号 | 审计日志、不良事件上报、质量统计看板、继续教育管理 |

### 2.2 功能模块

1. **护士端**：执业资格核验（护士证OCR+卫健委注册信息比对+继续教育学分验证）、接单、服务执行、GPS打卡、照片上传、电子签名
2. **患者/家属端**：发布护理需求、查看服务计划、实时位置追踪、服务报告查看、电子病历摘要、家属确认弹窗
3. **机构运营端**：服务项目结构化发布（含SOP与禁忌症提醒）、护士管理、智能派单引擎、服务监控
4. **监管端**：合规性审计日志、不良事件上报通道、护士继续教育课程管理、区域护理质量统计看板

## 3. 核心流程

护士注册核验流程：护士提交注册信息 → 上传护士证照片 → OCR识别护士证信息 → 与卫健委注册信息比对 → 验证继续教育学分 → 核验通过/驳回 → 激活账号

服务派单流程：患者/家属发布需求 → 系统匹配服务项目 → 智能派单引擎计算（资质匹配+距离+评价+负荷） → 推荐护士列表 → 运营确认派单 → 护士接单 → 服务执行 → 留痕上传 → 家属确认 → 保险自动投保 → 服务完成

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：医疗蓝 #0F6CBD + 安心绿 #108043，辅以暖灰中性色
- 按钮风格：圆角8px，主要操作蓝色实心，次要操作灰色描边，危险操作红色
- 字体：思源黑体/Noto Sans SC，标题18px/16px，正文14px，辅助12px
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局
- 图标风格：线性图标，24px，lucide-react图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 登录/注册页 | 用户认证 | 居中卡片式表单、角色选择标签页、步骤条指示核验进度 |
| 护士仪表盘 | 护士工作台 | 统计卡片行、今日任务列表、地图定位组件、快速操作按钮 |
| 资格核验页 | 执业资格核验 | 步骤式表单、照片上传区、比对结果展示、学分进度条 |
| 服务市场页 | 服务项目浏览 | 网格卡片列表、SOP折叠面板、禁忌症标签 |
| 智能派单页 | 派单引擎 | 地图模式+列表模式切换、护士推荐评分雷达图、批量派单 |
| 家属仪表盘 | 家属工作台 | 服务时间线、实时地图、报告卡片、病历摘要折叠区 |
| 质量看板页 | 统计看板 | 多维度图表（折线/柱状/饼图）、区域热力图、预警卡片 |
