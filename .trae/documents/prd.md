## 1. 产品概述
快递物流全生命周期服务中台，面向C端用户提供运单实时追踪、自助下单、派件范围智能识别、运费试算等核心功能；同时为后台运营提供异常件预警、网点围栏管理、客户咨询知识库、寄件行为画像等智能运营能力，实现从下单到签收的全链路数字化闭环。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| C端用户 | 手机号注册/登录 | 运单查询、自助下单、运费试算、个人地址簿管理 |
| 运营人员 | 内部账号分配 | 异常件处理、网点围栏管理、知识库维护、优惠券推送 |
| 系统管理员 | 内部账号分配 | 全部权限、用户管理、系统配置 |

### 2.2 功能模块

1. **首页**: 品牌展示、快捷入口（查件/下单/试算）、运单动态流、营销横幅
2. **运单追踪页**: 多入口查询、物流时间轴、实时状态地图、异常提示
3. **自助下单页**: 地址簿选择、物品信息填写、电子面单预览、运费估算
4. **派件范围识别页**: GPS定位/手动输入、网点匹配结果、服务半径可视化
5. **运费试算页**: 重量/体积/距离输入、三级计价结果、时效对比
6. **个人中心页**: 地址簿管理、历史订单、优惠券、行为画像概览
7. **后台异常预警页**: 滞留件列表、预警等级标记、人工介入操作
8. **后台网点围栏页**: 地图围栏绘制、网点列表、服务半径编辑
9. **后台知识库页**: 高频问题管理、自动回复规则、转人工工单列表
10. **后台行为画像页**: 用户聚类看板、频次/区域/品类图表、优惠券精准推送

## 3. 核心流程

### 运单查询流程
用户打开首页 → 选择查询方式（手机号/单号/扫码）→ 输入查询信息 → 系统调用圆通API获取物流数据 → 展示物流时间轴与实时地图 → 如有异常则高亮提示

### 自助下单流程
用户进入下单页 → 选择/输入寄件人信息 → 选择/输入收件人信息 → 填写物品信息 → 系统自动计算运费 → 确认并生成电子面单 → 下单成功

### 异常预警流程
系统定时扫描运单状态 → 检测到滞留超24h → 自动生成预警记录 → 通知运营人员 → 运营人员人工介入处理 → 更新处理结果

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深蓝色 (#0F2B46) 搭配亮橙色 (#FF6B35) 作为品牌强调色，体现物流行业的专业感与速度感
- **辅助色**: 浅灰 (#F5F7FA) 背景、深灰 (#2D3748) 文字、绿色 (#38A169) 成功状态、红色 (#E53E3E) 异常/预警
- **按钮风格**: 圆角矩形 (8px)、主按钮使用亮橙色填充、次按钮使用描边
- **字体**: 标题使用 DIN Alternate (力量感、工业风)，正文使用 Noto Sans SC (中文可读性)
- **布局风格**: 顶部导航栏 + 侧边栏(后台) / 底部Tab栏(C端)、卡片式内容组织
- **图标风格**: 线性图标 (Lucide)，统一2px描边，搭配圆形/方形底色块

- 桌面端优先设计，C端页面适配移动端（底部Tab导航、触摸优化）

- 地图类组件在移动端全屏展示，桌面端内嵌展示
