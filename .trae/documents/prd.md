## 1. 产品概述

面向全国纳税人的Web端+移动端一体化电子税务服务平台，提供从纳税人注册、税种申报、税款缴纳、发票管理、涉税证明开具到政策精准推送的全链路数字化办税体验。系统支持纳税人、税务管理员、第三方代理三种角色，覆盖增值税、个人所得税、附加税等主流税种的定期申报、零申报与更正申报场景，并通过智能预填、风险校验、电子签章等技术手段提升办税效率与合规性。

- 目标用户：全国企业/个体户/自然人纳税人、税务管理机关工作人员、税务代理机构
- 核心价值：一站式全流程电子办税、智能风险防控、政策精准触达

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 纳税人 | 实名注册（企业统一社会信用代码/个人身份证号） | 申报、缴款、发票管理、证明申请、政策查阅、工单提交 |
| 税务管理员 | 后台分配账号 | 申报审核、发票审核、证明开具、工单处理、政策发布、数据统计 |
| 第三方代理 | 代理注册+纳税人授权 | 代办申报、代开发票、代申请证明、工单代提交 |

### 2.2 功能模块

1. **登录认证页**：多角色登录/注册、数字证书绑定、统一身份认证
2. **首页/工作台**：待办事项、申报提醒、政策推送、快捷入口
3. **纳税人中心**：纳税人主体管理（企业/个体户/自然人）、信息维护、关联企业
4. **税种管理**：增值税/个税/附加税等税种配置、税率表、征收范围
5. **申报管理**：定期申报/零申报/更正申报、智能表单预填、风险实时校验、电子签章
6. **缴款中心**：税款计算、直连国库支付、缴款记录查询、电子缴款凭证
7. **发票管理**：代开发票申请、红冲发票、发票查验、OCR识别上传
8. **涉税证明**：完税证明申请/下载、无欠税证明申请/下载
9. **政策中心**：政策文件库、标签引擎（行业/规模/地域）、精准推送、奖补申报入口
10. **征纳互动**：工单提交/流转、附件上传、进度追踪、消息通知
11. **账户中心**：身份认证管理、数字证书绑定、操作日志、安全设置

## 3. 核心流程

### 3.1 申报缴款流程

用户登录 → 选择纳税人主体 → 选择税种与申报期间 → 智能预填表单 → 用户补充/修改 → 风险实时校验（逻辑冲突/税率误用/临界值提醒）→ 确认申报 → 电子签章 → 生成应缴税款 → 在线缴款（国库支付网关）→ 缴款成功 → 生成缴款凭证

```mermaid
    "选择纳税人主体" --> "选择税种与申报期间"

    "智能预填表单" --> "用户补充/修改"
    "用户补充/修改" --> "风险实时校验"
    "风险实时校验" --> "校验通过?"
    "校验通过?" --> "否: 显示风险提示"
    "校验通过?" --> "是: 确认申报"
    "显示风险提示" --> "用户补充/修改"
    "确认申报" --> "电子签章"
    "电子签章" --> "生成应缴税款"

    "在线缴款" --> "缴款成功"
    "缴款成功" --> "生成缴款凭证"
```

### 3.2 发票代开流程

用户申请代开 → 上传附件(OCR识别) → 填写发票信息 → 提交审核 → 管理员审核 → 审核通过开具发票

### 3.3 工单流转流程

用户提交工单 → 附加附件 → 管理员受理 → 处理/回复 → 用户确认 → 工单关闭

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1E3A5F（政府公信力/专业感）、辅色 #2E7D32（税务绿色通道）
- 强调色：#E65100（橙红，重要操作/提醒）
- 按钮风格：圆角4px、主按钮实色填充、次按钮描边
- 字体：思源黑体/Noto Sans SC，标题18-24px，正文14px，辅助12px
- 布局：左侧固定导航栏 + 顶部操作栏 + 主内容区，卡片式信息组织
- 图标：线性图标（Lucide），统一24px

- 桌面优先设计，最小宽度1280px

- 触摸优化：按钮最小点击区域44px、滑动操作支持
