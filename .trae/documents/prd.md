## 1. 产品概述

农村宅基地管理平台，服务于农户、村委、乡镇审批和自然资源监管，实现宅基地申请、确权、流转和监管全流程数字化管理，核心防控资格重复、面积超标、证据链断裂和审批脱节问题。

- 目标用户：农户（申请与查询）、村委（初审与公示）、乡镇（复核与审批）、自然资源监管部门（备案与检查）
- 核心价值：杜绝一户多宅、面积超标，确保审批链路可追溯，宅基地存量与流转透明可控

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 农户 | 注册/登录 | 提交申请、查看个人档案与申请进度 |
| 村委 | 注册/登录+角色分配 | 初审申请、公示管理、农户档案查看 |
| 乡镇审批员 | 注册/登录+角色分配 | 复核申请、审批决策、异常处理 |
| 监管人员 | 注册/登录+角色分配 | 监管备案、异常督查、报表查看 |

### 2.2 功能模块

1. **农户档案管理**：家庭成员、户籍信息、现有宅基地、历史申请、资格状态维护，防止重复申请
2. **宅基地地块管理**：坐标、面积、用途、权属证书、房屋照片、四至信息、历史变更记录
3. **申请流程管理**：新建/翻建/扩建/退出/流转五类申请，村级初审→乡镇复核→监管备案三级审批链路
4. **异常队列管理**：超面积、一户多宅、材料缺失、争议地块、违规建设五类异常，记录整改要求
5. **公示与报表**：申请进度、审批时长、宅基地存量、退出补偿、监管检查结果

## 3. 核心流程

农户提交宅基地申请后，系统自动校验资格状态（是否已有宅基地、是否符合一户一宅），校验通过后进入村级初审，村委审核材料完整性与资格合规性；初审通过后流转至乡镇复核，乡镇审批员核实面积标准与规划符合性；复核通过后监管备案，自然资源部门完成最终备案。任一环节退回，需补充材料后重新提交。审批过程中若触发异常规则（超面积、一户多宅等），自动进入异常队列。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色(#0F766E)搭配暖琥珀色(#D97706)点缀，体现土地与自然的关联
- 辅助色：浅灰底(#F8FAFC)、白色卡片、深灰文字(#1E293B)
- 按钮风格：圆角8px，主按钮实色填充，次按钮描边
- 字体：思源黑体/Noto Sans SC为主，标题加粗，正文14px
- 布局：左侧导航栏+右侧内容区，顶部面包屑导航
- 图标：lucide-react图标库，统一线条风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 用户认证 | 居中卡片式登录表单，背景渐变，角色选择下拉 |
| 首页仪表盘 | 数据概览 | 4个统计卡片(申请数/存量/异常/审批率)，待办列表，快捷入口网格 |
| 农户档案列表 | 农户档案 | 搜索栏+筛选下拉+数据表格，资格状态彩色标签 |
| 农户档案详情 | 农户档案 | 信息卡片组+成员表格+申请时间线+资格状态徽章 |
| 地块详情 | 地块管理 | 双栏布局：左栏信息表格，右栏坐标示意图+照片缩略图 |
| 申请提交 | 申请流程 | 步骤条(填表→上传→确认→提交)，表单分步，材料拖拽上传区 |
| 审批工作台 | 申请流程 | 左侧待审列表+右侧审批表单，审批意见富文本，通过/退回按钮组 |
| 异常队列 | 异常管理 | 紧急度色带+表格，筛选标签组，整改操作抽屉面板 |
| 报表中心 | 公示与报表 | 日期范围选择器+图表(柱状图/饼图)+数据导出按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px完整展示
- 1024-1280px内容区压缩，侧边栏折叠为图标模式
- 768px以下切换为顶部导航+单列内容

### 4.4 设计特点

- 审批时间线采用竖向节点连线设计，节点颜色表示状态
- 异常队列使用左侧色带标识紧急程度（红/橙/黄）
- 地块坐标区域使用简化的方格示意图标注四至方位
- 统计卡片带微动画数字滚动效果
