## 1. 产品概述

南京市级城市公共服务聚合平台，作为政务与民生服务统一入口，聚合卫健委、交通局、文旅局、人社局、公安等部门服务，为南京市民提供一站式身份核验、服务订阅、事项申办、诉求反馈等全流程在线服务，同时为政府部门提供服务治理、监控运维、工单分拨等后台运营能力。

- 目标用户：南京市常住市民（个人用户）、政府部门运营人员（后台用户）
- 核心价值：消除政务多头入口，实现"一网通办、一码通行、一键诉求"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 市民用户 | 手机号+身份证实名注册 | 浏览服务、身份核验、服务订阅、事项申办、诉求提交 |
| 部门运营员 | 后台账号分配 | 服务接入治理、工单处理、知识库维护 |
| 平台管理员 | 后台账号分配 | 全部权限，含用户管理、监控大屏、系统配置 |

### 2.2 功能模块

1. **市民门户首页**：服务分类导航、热门服务推荐、公告轮播、快捷入口
2. **身份核验页**：苏康码展示、身份证OCR识别、实名认证状态
3. **卫健委挂号服务**：医院列表、科室选择、医生排班、在线挂号
4. **交通出行服务**：公交实时到站、地铁线路查询、站点信息
5. **文旅预约服务**：景区列表、预约日期选择、预约记录
6. **社保查询服务**：社保账户信息、缴费记录、医保余额
7. **公安户政服务**：办事指南分类、办事材料清单、在线咨询
8. **服务订阅中心**：订阅管理（学区预警、医保变动等）、通知列表
9. **事项申办页**：申办事项列表、材料OCR上传、电子签名、申办进度
10. **市民诉求页**：诉求提交（按街道/部门路由）、诉求跟踪、评价反馈
11. **部门服务治理中心**：API注册、限流配置、熔断规则、服务列表
12. **监控大屏**：服务可用率、调用统计、异常告警、实时数据
13. **工单分拨引擎**：自动路由规则、工单列表、处理流程
14. **知识库管理**：知识条目增删改、语义检索、分类管理
15. **个人中心**：个人信息、安全设置、一键注销

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：南京城市品牌色——深蓝(#1A365D)为主色，金陵红(#C53030)为强调色，辅以暖灰(#F7FAFC)底色
- **按钮风格**：圆角6px，主按钮深蓝实底，次按钮描边，危险操作金陵红
- **字体**：标题用思源宋体风格衬线体，正文用苹方/思源黑体无衬线体
- **布局风格**：顶部导航+左侧菜单(后台)，卡片式内容区，栅格12列
- **图标风格**：线性图标，2px描边，搭配城市文化元素点缀

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 门户首页 | Hero轮播 | 全宽渐变背景，白字标题，底部圆角卡片层叠 |
| 门户首页 | 服务分类 | 5列图标卡片，悬浮上移+阴影动效 |
| 门户首页 | 热门服务 | 列表式，左侧图标+右侧箭头，点击涟漪效果 |
| 身份核验 | 苏康码 | 居中大码，绿/黄/红色边框+背景渐变 |
| 身份核验 | OCR区域 | 虚线框上传区，识别后字段高亮填充 |
| 挂号服务 | 医院列表 | 筛选栏+卡片列表，标签标等级 |
| 挂号服务 | 预约流程 | 步骤条(1-2-3-4)，表单分步填写 |
| 交通出行 | 实时公交 | 搜索框+结果列表，到站时间倒计时高亮 |
| 监控大屏 | 数据概览 | 深色背景，数字翻牌动效，环形图+折线图 |
| 工单分拨 | 路由规则 | 表格+标签，拖拽排序优先级 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 平板适配（768-1279px）：侧边栏折叠为汉堡菜单
- 移动端适配（<768px）：单列布局，底部导航

### 4.4 无障碍设计

- 所有交互元素支持键盘操作
- 图标配有文字标签
- 表单提供明确的错误提示
- 颜色对比度满足WCAG 2.1 AA标准
