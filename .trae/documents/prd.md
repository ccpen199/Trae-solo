## 1. 产品概述

面向工会组织的职工普惠服务运营平台，以会员实名制为基础，构建覆盖省总→市总→基层工会的三级组织管理体系，为工会会员提供福利发放、便捷支付、出行服务、品质生活等一站式普惠服务，同时为工会管理者提供预算审批、供应商管理、数据分析与个性化推荐等运营工具。

- 核心价值：打通工会组织管理与服务交付的全链路，提升职工权益获得感与工会运营效率
- 目标用户：各级工会管理员（省/市/基层）、工会会员（职工）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册/登录方式 | 核心权限 |
|------|--------------|----------|
| 省级工会管理员 | 后台分配账号 | 全省数据查看、预算审批、供应商准入、组织架构管理 |
| 市级工会管理员 | 后台分配账号 | 本市数据查看、预算申请与执行、会员管理 |
| 基层工会管理员 | 后台分配账号 | 本单位会员管理、福利发放执行、服务预约审核 |
| 工会会员 | 身份证+单位工号双重核验入会 | 查看权益、领取福利、积分商城、出行预约、体检团购 |

### 2.2 功能模块

1. **首页仪表盘**：数据概览、快捷入口、待办事项、权益推荐
2. **组织管理页**：工会树形架构、分级管理、会员入会审核
3. **福利中心页**：电子券发放与核销、积分商城、福利预算管理
4. **便捷支付页**：银联云闪付对接、工会卡管理、支付记录
5. **出行服务页**：机场贵宾厅预约、火车票优先购票
6. **品质生活页**：体检套餐团购、法律咨询预约
7. **后台运营页**：供应商管理、审批工作流、数据分析看板、权益推荐配置

## 3. 核心流程

### 3.1 会员入会流程
用户填写身份证号与单位工号 → 系统校验身份信息 → 匹配所属基层工会 → 基层工会管理员审核 → 审核通过激活会员身份 → 同步至全国工会数据库

### 3.2 福利发放流程
基层工会创建福利发放计划 → 提交预算审批 → 上级工会审批通过 → 系统生成电子券/积分 → 推送通知会员 → 会员领取使用 → 核销完成核减预算

### 3.3 供应商准入流程
供应商提交准入申请 → 资质材料审核 → 服务试用评估 → 准入审批通过 → 纳入供应商目录 → 定期考核评分 → 考核不合格移出

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深红色（#C41E3A，代表工会的庄重与温暖）+ 金色点缀（#D4A843，象征权益与荣耀）
- 辅助色：深灰色（#1F2937）、浅灰色（#F3F4F6）、白色
- 按钮风格：圆角8px，主按钮深红色填充，次按钮深红色描边，悬停态加深+微升阴影
- 字体：标题使用 Noto Serif SC（衬线体，庄重感），正文使用 Noto Sans SC（无衬线，清晰易读）
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局，顶部面包屑导航
- 图标风格：线性图标（lucide-react），与文字搭配使用
- 装饰元素：国徽/工会徽章等纹样作为背景水印，渐变色块分隔不同功能区域

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 首页仪表盘 | 数据概览 | 4列统计卡片（深红色图标+数字+趋势箭头），下方折线图区域 |
| 首页仪表盘 | 快捷入口 | 2行4列功能图标网格，图标带圆形深红色背景，悬停放大+阴影 |
| 首页仪表盘 | 待办事项 | 列表卡片，左侧状态标签（红/橙/绿），右侧操作按钮 |
| 首页仪表盘 | 个性化推荐 | 横向滚动卡片组，每张卡片含图片+标题+标签+领取按钮 |
| 组织管理 | 工会树形架构 | 左侧树形面板（可折叠节点），右侧详情面板，节点带层级图标 |
| 组织管理 | 会员入会审核 | 表格列表，操作列含审核按钮，点击弹出审核弹窗 |
| 福利中心 | 电子券管理 | 顶部操作栏+表格，电子券为卡片式展示，含二维码区域 |
| 福利中心 | 积分商城 | 瀑布流商品卡片，积分价格标签，兑换按钮 |
| 福利中心 | 福利预算管理 | 进度条展示预算执行率，审批状态标签，审批流程时间线 |
| 后台运营 | 数据分析看板 | 漏斗图、柱状图、饼图组合，支持时间范围筛选器 |
| 后台运营 | 供应商管理 | 表格+详情抽屉，评分星级，状态标签 |

### 4.3 响应式设计

- 桌面优先设计，最小支持1280px宽度
- 内容区使用弹性布局，统计卡片在小屏幕下自动折行
- 表格在窄屏下支持横向滚动
- 移动端适配：底部Tab导航替代侧边栏，卡片单列布局
