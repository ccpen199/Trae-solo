## 1. 产品概述

云南区域化B2B招聘管理系统，专为云南地区企业HR与招聘负责人打造，连接企业端与应聘者端，提供从企业认证、职位发布、简历智能匹配、面试邀约到录用闭环的一站式招聘解决方案，同时内置风控机制（黑名单、虚假职位识别）保障平台安全可信。

- 核心目标：提升云南区域企业招聘效率与匹配精度，构建可信赖的区域人才生态
- 目标用户：云南地区企业HR、招聘负责人、求职应聘者、平台管理员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 企业HR | 营业执照OCR核验+法人手机号实名绑定 | 发布职位、查看简历、邀约面试、面试管理 |
| 应聘者 | 手机号注册 | 浏览职位、投递简历、查看面试邀约、评价企业 |
| 平台管理员 | 后台授权 | 黑名单管理、虚假职位审核、数据看板、系统配置 |

### 2.2 功能模块

1. **企业认证页面**：营业执照OCR识别上传、法人手机号验证、认证状态展示
2. **职位管理页面**：职位发布（岗位JD、薪资范围、到岗时间、用工性质）、职位列表、职位编辑/关闭
3. **简历匹配页面**：NLP关键词解析、匹配度评分展示、简历筛选列表
4. **面试邀约页面**：一键邀约、日历占位选择、短信提醒配置、邀约记录
5. **应聘者求职页面**：企业认证标识展示、响应率与员工评价、职位搜索与投递
6. **后台风控页面**：黑名单库管理、虚假职位识别审核、面试反馈闭环跟踪
7. **数据看板页面**：人均招聘周期、职位关闭原因分布、地域人才供需热力图

## 3. 核心流程

**企业招聘主流程**：企业HR完成认证 → 发布职位 → 系统自动匹配简历 → HR查看匹配结果 → 一键邀约面试 → 面试反馈评分 → 录用/淘汰 → 职位关闭

**应聘者求职流程**：注册登录 → 完善简历 → 浏览职位（查看企业认证/评价） → 投递简历 → 接收面试邀约 → 确认面试 → 参加面试 → 反馈评价

**后台风控流程**：系统自动扫描 → 虚假职位标记 → 人工复核 → 加入黑名单/下架职位

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：以云南高原的自然色彩为灵感——赤陶红（#C8553D）为主色，搭配云杉绿（#2D6A4F）为辅助色，传达地域特色与专业可信
- **辅色调**：暖沙金（#D4A843）用于认证标识和高亮，苍石灰（#4A4E53）用于文字
- **按钮风格**：圆角矩形（8px），主要操作使用实色填充，次要操作使用描边风格
- **字体**：标题使用 Noto Serif SC 衬线体（传达专业与文化感），正文使用 Noto Sans SC
- **布局风格**：左侧固定导航 + 右侧内容区，卡片式内容组织，表格数据区域适当使用条纹背景
- **图标风格**：线性图标，2px线宽，与整体简洁专业的风格统一
- **动效**：页面切换淡入、数据加载骨架屏、匹配度环形进度动画、热力图渐变过渡

### 4.3 响应式设计

- 桌面端优先（1920px/1440px/1280px）
- 平板端自适应：侧边导航收缩为图标模式，表格横向滚动
- 移动端适配：底部Tab导航，卡片单列布局，表单分步展示

### 4.4 3D场景指引

不适用，本项目为2D管理系统界面。
