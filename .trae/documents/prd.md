## 1. 产品概述

高校全域生活服务中台——面向在校大学生的校园生活一站式数字平台，整合餐饮预订与配送、校园超市零售、社交互动与求职匹配三大核心场景，并为校方提供统一管理控制台，所有服务严格遵循教育行业数据安全规范。

- 目标用户：在校大学生（C端）、校园商家/骑手（B端）、校方管理者（G端）
- 核心价值：消除校园生活服务碎片化，实现"预订-配送-交付-社交-管理"全链路闭环

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生 | 学号+学信网核验 | 浏览预订、下单支付、社交互动、二手交易、求职匹配 |
| 商家/档口 | 校方审核入驻 | 商品管理、订单处理、促销设置 |
| 配送员（西游侠/筋斗云） | 实名认证注册 | 接单、配送、扫码交付 |
| 校方管理员 | 内部授权 | 组织架构管理、围栏配置、数据分析、舆情监测、工单转办 |

### 2.2 功能模块

1. **餐饮板块**：食堂档口线上预订、宿舍楼精准配送路径规划、西游侠骑手接单调度、到寝扫码交付
2. **校园超市板块**：商品SKU与实体货架绑定、筋斗云配送员任务池动态派单、临期商品自动降价促销引擎
3. **校园社交板块**：基于班级/院系/兴趣标签的轻量级动态圈、二手教材交易担保支付、实习岗位智能匹配（对接教务课表与学分进度）
4. **校方管理控制台**：院系组织架构维护、服务区域电子围栏配置、学生身份核验（对接学信网API）、消费行为分析（早餐时段下单热力、零食复购率）、舆情关键词监测与工单转办

## 3. 核心流程

### 3.1 餐饮预订配送闭环

用户打开餐饮板块 → 浏览食堂档口 → 选择菜品加入购物车 → 选择配送时段与宿舍楼 → 提交订单支付 → 系统分配西游侠骑手 → 骑手到档口取餐 → 按最优路径配送 → 到达宿舍扫码交付 → 订单完成评价

```mermaid
flowchart TD
    "浏览档口菜品" --> "加入购物车"
    "加入购物车" --> "选择配送时段与宿舍"
    "选择配送时段与宿舍" --> "提交订单支付"
    "提交订单支付" --> "系统分配骑手"
    "系统分配骑手" --> "骑手取餐"
    "骑手取餐" --> "按路径配送"
    "按路径配送" --> "扫码交付"
    "扫码交付" --> "订单完成评价"
```

### 3.2 超市临期降价引擎

系统定时扫描商品保质期 → 临期商品自动标记 → 按到期时间阶梯降价 → 推送到临期专区 → 用户下单 → 筋斗云配送员接单派送

```mermaid
flowchart TD
    "定时扫描保质期" --> "临期自动标记"
    "临期自动标记" --> "阶梯降价计算"
    "阶梯降价计算" --> "推送到临期专区"
    "推送到临期专区" --> "用户下单"
    "用户下单" --> "筋斗云派单配送"
```

### 3.3 实习岗位智能匹配

学生授权课表与学分数据 → 系统分析空闲时段 → 匹配岗位时间要求 → 匹配专业/技能标签 → 生成推荐列表 → 一键投递

```mermaid

    "授权课表与学分" --> "分析空闲时段"
    "分析空闲时段" --> "匹配岗位要求"
    "匹配岗位要求" --> "匹配专业技能"
    "匹配专业技能" --> "生成推荐列表"
    "生成推荐列表" --> "一键投递"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：校园活力橙（#FF6B35）+ 科技靛蓝（#1B3A5C）
- 辅助色：暖黄（#FFC857）、薄荷绿（#2EC4B6）、珊瑚红（#E63946）
- 按钮风格：圆角8px、微阴影悬浮效果、渐变填充
- 字体：思源黑体（标题）/ HarmonyOS Sans（正文）
- 布局风格：左侧导航栏 + 右侧内容区、卡片式模块布局
- 图标风格：线性图标（Lucide）配合品牌色填充

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 首页仪表盘 | 服务导航 | 四宫格图标入口、轮播推荐、数据卡片、渐变背景 |
| 餐饮-档口列表 | 档口卡片 | 横向滚动分类、档口封面图、评分标签、浮动购物车 |
| 餐饮-订单详情 | 配送地图 | 实时地图、骑手头像标注、路径线条、状态时间轴 |
| 超市-临期专区 | 倒计时卡片 | 红色倒计时徽章、原价划线、折扣气泡、进度条 |
| 社交-动态圈 | 信息流 | 瀑布流卡片、标签云、互动按钮、发帖浮动按钮 |
| 社交-二手交易 | 商品列表 | 教材封面、新旧程度标签、担保支付徽章、状态胶囊 |
| 社交-实习匹配 | 匹配卡片 | 匹配度环形图、课表时间线、技能标签、投递按钮 |
| 管理控制台 | 数据看板 | 热力地图、折线图、柱状图、数据表格、筛选面板 |

### 4.3 响应式设计

- 桌面端优先设计（1440px基准）
- 平板端适配（768px-1024px）：侧边栏收缩为汉堡菜单
- 移动端适配（<768px）：底部Tab导航、卡片纵向堆叠、触控优化
