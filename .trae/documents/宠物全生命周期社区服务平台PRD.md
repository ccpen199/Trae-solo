## 1. 产品概述

宠物全生命周期社区服务平台——为宠物主人、领养人、兽医及宠物服务商家提供一站式数字化服务。平台以宠物电子档案为核心，串联领养、配种、健康管理和社区互动全链路，同时通过活体交易禁止、农业部门备案接入及内容安全审查，确保所有涉宠操作合法合规。

- **核心价值**：用数字化手段保障宠物福利，让领养/配种流程透明可追溯，构建健康安全的宠物社区生态
- **目标用户**：宠物主人（25-45岁城市养宠人群）、准领养人、专业繁殖者、执业兽医、宠物用品商家、平台管理员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 宠物主人 | 手机号+实名认证 | 创建宠物档案、发布领养/配种、社区互动、购买用品 |
| 领养人 | 手机号+资质评估 | 浏览领养信息、提交领养申请、参与社区 |
| 兽医 | 手机号+执业资格认证 | 回答问诊、认证答案打标、疫苗记录审核 |
| 管理员 | 内部账号 | 内容审核、交易监管、备案管理、用户管理 |
| 审核员 | 内部账号 | 领养/配种资质审核、内容安全审核 |

### 2.2 功能模块

1. **首页**：平台入口、快捷导航、热门推荐、社区精华、公告横幅
2. **宠物档案**：电子档案创建/编辑、疫苗驱虫记录管理、OCR识别上传、健康提醒
3. **领养中心**：领养列表、送养发布、领养申请、流程追踪、线下交接确认
4. **配种广场**：配种需求发布、血统证书上传、智能撮合、费用托管、配种协议
5. **问答社区**：提问/回答、兽医认证答案、知识图谱、热度排序
6. **宠物商城**：用品分类浏览、合规商品展示、购物车、订单管理
7. **社区动态**：动态发布/浏览、互动（点赞/评论/分享）、违规内容举报
8. **个人中心**：实名认证、我的宠物、领养/配种记录、消息通知、设置

## 3. 核心流程

### 3.1 领养流程

送养人发布领养信息 → 平台审核送养人资质（实名+宠物所有权） → 领养人浏览并提交申请 → 领养人资质评估（实名+居住条件+养宠经验） → 双方线上沟通 → 线下交接（扫码确认+电子签名） → 平台确认完成 → 农业部门备案同步

```mermaid
flowchart TD
    "A[送养人发布领养信息]" --> "B[平台审核送养人资质]"
    "B" --> "C[审核通过，信息上架"]
    "B" --> "D[审核不通过，退回修改]"
    "C" --> "E[领养人浏览并提交申请]"
    "E" --> "F[领养人资质评估"
    "F" --> "G[评估通过，双方沟通"]
    "F" --> "H[评估不通过，通知领养人"
    "G" --> "I[线下交接确认"
    "I" --> "J[农业部门备案同步"
    "J" --> "K[领养完成"
```

### 3.2 配种撮合流程

配种需求方发布需求+上传血统证书 → 平台验证血统证书 → 智能匹配推荐 → 双方协商 → 签署配种协议 → 费用托管 → 配种执行 → 确认完成 → 费用划转 → 农业部门备案

```mermaid
flowchart TD
    "A[发布配种需求+血统证书" --> "B[平台验证血统证书"
    "B" --> "C[智能撮合匹配推荐"
    "C" --> "D[双方协商沟通"
    "D" --> "E[签署配种协议"
    "E" --> "F[配种费用托管"
    "F" --> "G[配种执行"
    "G" --> "H[双方确认完成"
    "H" --> "I[费用自动划转"
    "I" --> "J[农业部门备案"
```

### 3.3 内容安全流程

用户发布内容 → AI实时识别违规 → 标记风险等级 → 低风险：自动过滤/警告 → 高风险：进入人工审核队列 → 审核员判定 → 通过/删除/封禁 → 记录日志

```mermaid

    "A[用户发布内容" --> "B[AI实时识别违规"
    "B" --> "C{风险等级判定"
    "C" --> "|低风险| D[自动过滤/警告发布"
    "C" --> "|高风险| E[进入人工审核队列"
    "E" --> "F[审核员判定"
    "F" --> "|通过| G[内容正常展示"
    "F" --> "|删除| H[内容下架+通知用户"
    "F" --> "|封禁| I[用户封禁+内容下架"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橘色 `#F97316`（温暖、活力、宠物友好） + 深墨绿 `#065F46`（专业、信任、健康）
- **辅助色**：奶油白 `#FFF8F0`（背景）、暖灰 `#78716C`（文字）、珊瑚红 `#EF4444`（警示/重要）
- **按钮风格**：圆角按钮（rounded-xl），主按钮实心橘色，次按钮描边墨绿，hover带微弹动画
- **字体**：标题使用 `Noto Serif SC`（优雅中文衬线），正文使用 `Noto Sans SC`（清晰无衬线）
- **布局风格**：卡片式布局，顶部导航栏+侧边快捷菜单，大量留白，圆角卡片阴影
- **图标风格**：Lucide线性图标，线条粗细适中，橘色/墨绿色双色系
- **插画风格**：扁平化宠物插画，暖色调，圆润造型

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 平板适配：768-1279px，侧边栏折叠为汉堡菜单，网格列数减少
- 移动适配：< 768px，单列布局，底部Tab导航，卡片全宽
- 触摸优化：按钮最小44px触摸区域，滑动操作支持

### 4.4 动效设计

- 页面加载：卡片交错淡入（stagger 100ms）
- 卡片悬停：微上浮 + 阴影加深（translate-y -4px, shadow-lg）
- 按钮点击：缩放弹回（scale 0.95 → 1）
- 流程步骤：完成时打勾动画
- 宠物卡片：图片轻微呼吸动画
- 社区动态：新内容滑入动画
