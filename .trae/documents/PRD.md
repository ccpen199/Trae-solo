## 1. 产品概述

无锡市城市级政务民生融合服务平台——全市统一身份认证与服务聚合中枢，面向无锡市民提供政务办事、城市服务、公共服务三大能力域的一站式数字化入口，实现"一网通办、一码通行、一键直达"的智慧城市服务体验。

- 解决市民多平台切换、重复认证、办事流程不清等痛点，构建从查询到办结的闭环服务链路
- 目标用户：无锡市860万常住人口，重点覆盖中老年群体、上班族、家庭用户

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册/登录方式 | 核心权限 |
|------|---------------|----------|
| 普通市民 | 实名认证（身份证+人脸识别） | 浏览与使用所有公共服务、城市服务 |
| 认证市民 | 市级人口库SSO单点登录 | 政务办事、证照调取、事项申报 |
| 代办人 | 子女账号绑定+被代办人授权 | 远程代办老人事项、查看办事进度 |
| 管理员 | 后台授权登录 | 服务效能监测、数据分析、内容管理 |

### 2.2 功能模块

1. **首页门户**：城市形象展示、服务搜索、快捷入口、公告轮播、智能导办入口
2. **政务办事**：社保查询、公积金提取、户籍登记、证照自动填充、办事进度追踪
3. **城市服务**：公交地铁扫码乘车、景点预约、医院挂号、教育缴费
4. **公共服务**：政策解读推送、社区公告、应急广播
5. **智能导办**：自然语言问答、流程图解、材料预审
6. **适老化模式**：字体无级缩放、语音导航、子女远程代办绑定、高频事项一键直达
7. **个人中心**：实名认证、证照库、办事记录、满意度评价、代办管理
8. **服务效能监测后台**：办结时效统计、满意度评价分析、异常中断归因分析

## 3. 核心流程

### 3.1 单点登录与证照自动填充流程

市民首次通过市级人口库完成实名认证后，获取统一身份令牌。后续访问任意服务事项时，系统自动调取电子证照库，将身份证、户口簿、结婚证等证照信息自动填充到申报表单，市民仅需确认提交。

```mermaid
flowchart TD
    "市民访问平台" --> "统一认证入口"
    "统一认证入口" --> "市级人口库验证"
    "市级人口库验证" --> "验证成功"
    "市级人口库验证" --> "验证失败"
    "验证失败" --> "重新认证"
    "验证成功" --> "发放SSO令牌"
    "发放SSO令牌" --> "选择服务事项"
    "选择服务事项" --> "调取电子证照库"
    "调取电子证照库" --> "自动填充表单"
    "自动填充表单" --> "市民确认提交"
    "市民确认提交" --> "事项受理"
```

### 3.2 智能导办流程

市民通过自然语言描述办事需求（如"我想提取公积金"），系统解析意图后展示流程图解、所需材料清单，支持材料拍照上传预审，预审通过后直接进入申报流程。

```mermaid
flowchart TD
    "输入自然语言问题" --> "意图识别与解析"
    "意图识别与解析" --> "匹配服务事项"
    "匹配服务事项" --> "展示流程图解"
    "展示流程图解" --> "展示材料清单"
    "展示材料清单" --> "上传材料照片"
    "上传材料照片" --> "AI材料预审"
    "AI材料预审" --> "预审通过"
    "AI材料预审" --> "预审不通过"
    "预审不通过" --> "反馈补正意见"
    "反馈补正意见" --> "重新上传"
    "预审通过" --> "进入申报流程"
```

### 3.3 适老化代办流程

老年用户切换适老化模式后，可通过语音指令或大图标直达高频服务。子女通过扫码绑定代办权限后，可远程为老人提交办事申请，老人端实时查看代办进度。

```mermaid

    "语音/大图标操作" --> "直达高频服务"
    "子女扫码绑定" --> "授权代办范围"
    "授权代办范围" --> "子女远程提交申请"
    "子女远程提交申请" --> "老人端查看代办进度"
    "老人端查看代办进度" --> "事项办结通知"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深邃蓝 `#0A2E5C`（政务权威感）+ 温暖金 `#D4A843`（民生温度感）
- **辅助色**：天际蓝 `#3B82F6`（交互高亮）、应急红 `#DC2626`（紧急通知）、生态绿 `#16A34A`（成功/完成状态）
- **按钮风格**：圆角矩形（8px），主按钮为蓝底白字，次要按钮为白底蓝框，适老模式按钮加大加粗
- **字体**：标题使用思源宋体（Source Han Serif）传达政务庄重感，正文使用思源黑体（Source Han Sans）保证可读性
- **布局**：顶部导航栏 + 侧边服务分类 + 卡片式内容区，响应式适配桌面与移动端
- **图标风格**：线性图标+微渐变填充，政务类使用盾牌/公文意象，民生类使用生活化意象

### 4.3 响应式设计

- 桌面优先设计，断点：1440px（大屏）、1024px（标准）、768px（平板）、375px（手机）
- 移动端采用底部Tab导航替代侧边栏，卡片单列堆叠
- 适老模式在移动端自动全屏化，去除非必要装饰元素
- 扫码乘车页面针对移动端优化，一键亮码

### 4.4 动效设计

- 页面加载：首屏内容交错渐入（stagger fade-in），搜索框光标闪烁引导
- 卡片交互：悬停微上浮+阴影加深，点击涟漪效果
- 流程图：步骤切换时连线流动动画，当前节点脉冲高亮
- 适老模式切换：全局字体平滑缩放过渡，配色方案渐变切换
- 应急广播：红色边框呼吸灯效果，紧急标签抖动提醒
- 智能导办：对话气泡逐字打出效果，流程图步骤依次展开
