## 1. 产品概述

邮政EMS官方寄递业务中台系统，服务寄件人、揽收员、分拣中心、收件人四方角色，提供多场景下单、智能路由、面单防伪、异常预警等核心能力，支持3D轨迹追踪、企业月结账单、绿色碳足迹计算等增值服务，后台集成全网运能看板，全链路符合邮政业安全传输规范。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|--------|----------|----------|
| 寄件人 | 手机号/企业认证 | 下单、轨迹查询、碳足迹查看、账单管理 |
| 揽收员 | 员工工号认证 | 扫码揽收、面单打印、异常上报 |
| 分拣中心 | 机构账号 | 分拣操作、异常件处理、影像上传 |
| 收件人 | 手机号授权 | 轨迹查询、签收确认 |
| 系统管理员 | 管理员账号 | 运能看板、系统配置、数据监控 |

### 2.2 功能模块

1. **寄件人端 (enterprise-web)
   - 首页工作台：快捷下单、批量导入、订单列表
   - 订单管理：多场景下单（批量导入/扫码面单/微信预填）
   - 轨迹追踪：3D地图轨迹、分拣影像查看
   - 账单中心：月结账单、多维度导出
   - 绿色环保：碳足迹计算、减排统计

2. **管理后台 (admin-web)**
   - 运能看板：全网枢纽吞吐量、车辆在途监控
   - 异常预警中枢：滞留件监控、人工干预调度
   - 路由引擎配置：线路规则、时效配置
   - 面单防伪管理：区块链存证、二维码管理

## 3. 核心流程

### 3.1 下单流程

寄件人选择下单方式（批量导入/扫码面单/微信预填）→ 系统调用智能路由引擎匹配最优线路 → 生成动态二维码面单 → 电子运单号上链存证 → 揽收员扫码揽收 → 分拣中心扫码分拣并上传操作影像 → 收件人签收确认

```mermaid
flowchart LR
    A["寄件人下单"] --> B["智能路由匹配"]
    B --> C["生成防伪面单"]
    C --> D["区块链存证"]
    D --> E["揽收员揽收"]
    E --> F["分拣中心处理"]
    F --> G["运输配送"]
    G --> H["收件人签收"]
```

### 3.2 异常件处理流程

包裹滞留超24小时 → 系统自动触发预警 → 推送至异常中枢 → 人工干预分派 → 处理结果反馈 → 状态更新

```mermaid
flowchart LR
    A["包裹滞留超24小时"] --> B["自动触发预警"]
    B --> C["异常中枢展示"]
    C --> D["人工干预分派"]
    D --> E["处理结果反馈"]
    E --> F["状态更新通知"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：邮政绿 `#006F3C`，辅助色：EMS橙 `#FF6B00`
- 中性色：深灰 `#1F2937`、中灰 `#4B5563`、浅灰 `#F3F4F6`
- 按钮风格：圆角 6px，主按钮绿色渐变，悬停微动效
- 字体：标题使用「思源黑体 Bold」，正文使用「思源黑体 Regular」
- 布局：卡片式布局，顶部导航 + 侧边栏菜单
- 图标：线性图标风格，统一 16px/20px/24px 三档尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 寄件首页 | 快捷下单 | 渐变背景Hero区、大尺寸CTA按钮、卡片式快捷入口、交互动效 |
| 3D轨迹页 | 地图展示 | 深色地图背景、3D路径动画、时间轴悬浮卡片、影像弹窗 |
| 运能看板 | 数据大屏 | 深色主题、实时数据刷新动画、热力图、预警红黄灯 |
| 碳足迹页 | 环保数据 | 绿色渐变、树木图标、进度条动画、减排数据可视化 |
| 异常预警页 | 异常列表 | 红色预警标签、优先级排序、处理状态流转 |

### 4.3 响应式

- 桌面端优先设计，适配 1440px 及以上
- 平板端自适应网格布局
- 移动端单列布局，侧边栏转为底部Tab
- 触摸交互优化，手势滑动支持

### 4.4 3D场景指引

- 环境：深色科技感地图背景，柔和环境光
- 光照：方向光 + 环境光，突出包裹和路径
- 相机：3D透视视角，可拖拽旋转、缩放
- 动画：包裹沿路径移动动画，分拣节点脉冲光效
- 交互：点击节点查看分拣影像，时间轴控制播放
- 后处理：辉光效果、抗锯齿
