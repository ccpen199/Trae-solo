## 1. 产品概述

医生跨机构出诊管理平台，服务于医生多点执业场景，覆盖医生、合作机构、运营排班和合规审核四方角色。系统实现医生资质管理、机构需求对接、智能排班校验、号源预约管理和财务结算全链路闭环。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|---------|
| 运营管理员 | 系统创建 | 全功能访问、合规审核、结算管理 |
| 医生 | 运营创建 | 查看个人排班、出诊记录、收入明细 |
| 机构管理员 | 运营创建 | 提交出诊需求、查看号源、预约管理 |

### 2.2 功能模块

1. **运营仪表盘**：数据总览、快捷操作、合规预警
2. **医生档案管理**：执业资质、专业领域、服务机构、出诊时段、协议价格、合规状态
3. **机构需求管理**：科室配置、号源需求、诊室管理、时段设置、资质要求
4. **智能排班计划**：冲突检测、日历视图、排班生成、状态跟踪
5. **号源与预约**：号源展示、预约记录、停诊改期、患者通知
6. **结算报表**：收入核算、违约统计、报表导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 运营仪表盘 | 数据概览 | 今日出诊、待审核、收入总览、合规预警卡片 |
| 医生档案 | 列表页 | 医生列表、资质状态筛选、搜索、新增/编辑 |
| 医生档案 | 详情页 | 执业证信息、可服务机构、出诊时段、协议价格、合规记录 |
| 机构管理 | 列表页 | 机构列表、科室配置、号源需求 |
| 排班计划 | 日历视图 | 月/周视图、拖拽排班、冲突检测高亮、排班生成 |
| 排班计划 | 排班详情 | 排班校验结果、本院班次、跨机构冲突、休息时间校验 |
| 号源管理 | 号源列表 | 已约/剩余号源、停诊改期操作、患者通知记录 |
| 结算报表 | 报表中心 | 按医生/机构维度统计、出诊次数、收入明细、违约情况 |

## 3. 核心流程

    A["医生资质录入"] --> B["合规审核"]

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：医疗蓝 `#165DFF`
- **辅助色**：成功绿 `#00B42A`、告警橙 `#FF7D00`、危险红 `#F53F3F`
- **中性色**：深灰 `#1D2129`、中灰 `#4E5969`、浅灰 `#C9CDD4`
- **按钮风格**：圆角 6px，悬停阴影过渡
- **布局风格**：左侧导航 + 顶部操作区 + 内容卡片区

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 数据概览 | 渐变统计卡片、折线图趋势、数据表格、状态标签 |
| 医生档案 | 列表页 | 搜索栏、筛选器、数据表格、操作按钮组 |
| 排班计划 | 日历视图 | 月历网格、时间段块、冲突红色高亮 |
| 号源管理 | 号源列表 | 号源卡片、状态徽章、操作下拉菜单 |

### 4.3 响应式
- 桌面优先设计，支持 1280px 及以上最优显示
- 表格支持横向滚动适配小屏
