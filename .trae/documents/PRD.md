## 1. 产品概述

全国性数字货运基础设施平台——货达通，核心聚焦货主与司机间的高效直连，消除信息不对称与中间环节，实现运力资源的最优配置。
- 面向货主（制造业/商贸/生鲜冷链企业）、司机（个体/车队）、平台运营方三类角色，提供从智能撮合、运输监控到结算分账的全链路数字化解决方案
- 目标将传统货运匹配效率从小时级提升至秒级，降低空驶率15%以上，缩短结算周期至T+1

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |

### 2.2 功能模块

1. **首页/仪表盘**: 平台核心数据概览、实时运力地图、快捷入口
2. **运力池地图**: 350万司机GPS实时位置、车型/载重/空闲状态筛选

4. **智能撮合引擎**: AI货源-运力秒级匹配（整车/拼车/零担多模式）
5. **运价博弈界面**: 线路热力图驱动的报价/还价交互
6. **货源管理**: 货源智能分级标签（建材/生鲜/冷链/大件）、发布与追踪
7. **司机工作台**: 离线接单、电子运单生成、运程管理
8. **全程监控中心**: 货物轨迹追踪、温湿度监控（冷链专用）
9. **结算中心**: 运费自动分账、T+1结算通道、账单管理
10. **运营后台**: 线路供需失衡预警、司机准入风控、货主信用额度授信、区域波峰波谷预测看板

## 3. 核心流程

### 3.1 货源发布与撮合流程

货主登录后发布货源（填写货类、起止地、重量、时效、报价），系统根据货源信息自动匹配运力池中符合条件的司机，AI撮合引擎在秒级内返回推荐司机列表及匹配度评分。货主选择司机后进入运价博弈环节，双方达成一致后确认订单，系统自动生成电子运单，司机开始运输。

```mermaid
flowchart TD
    "A[货主登录]" --> "B[发布货源]"
    "B" --> "C[填写货源信息]"
    "C" --> "D[AI撮合引擎匹配]"
    "D" --> "E{匹配模式}"
    "E" --> "F[整车匹配]"
    "E" --> "G[拼车匹配]"
    "E" --> "H[零担匹配]"
    "F" --> "I[返回推荐司机列表]"
    "G" --> "I"
    "H" --> "I"
    "I" --> "J[货主选择司机]"
    "J" --> "K[运价博弈]"
    "K" --> "L{达成一致?}"
    "L" --> "是" --> "M[确认订单]"
    "L" --> "否" --> "K"
    "M" --> "N[生成电子运单]"
    "N" --> "O[司机开始运输]"
```

### 3.2 司机接单流程

司机登录后查看匹配货源列表，选择心仪订单进行报价/接单。离线时本地缓存可接订单，网络恢复后自动同步。接单后系统生成电子运单，司机在运输过程中更新运单状态（已装货→运输中→已到达→已签收），全程温湿度数据（冷链）实时上报。

```mermaid
flowchart TD
    "A[司机登录]" --> "B[查看匹配货源]"
    "B" --> "C{在线?}"
    "C" --> "是" --> "D[实时获取货源]"
    "C" --> "否" --> "E[离线缓存货源]"
    "D" --> "F[选择订单]"
    "E" --> "F"
    "F" --> "G[报价/接单]"
    "G" --> "H[运价博弈]"
    "H" --> "I[确认接单]"
    "I" --> "J[生成电子运单]"
    "J" --> "K[运输过程状态更新]"
    "K" --> "L[签收确认]"
    "L" --> "M[运费结算]"
```

### 3.3 结算流程

运单签收后，系统自动计算运费分配（司机运费、平台服务费），进入T+1结算队列，次日自动打款至司机账户，货主账单同步更新。

```mermaid
flowchart TD
    "A[运单签收]" --> "B[系统计算分账]"
    "B" --> "C[生成分账明细]"
    "C" --> "D[进入T+1结算队列]"
    "D" --> "E[次日自动结算]"
    "E" --> "F[司机收到运费]"
    "E" --> "G[平台收取服务费]"
    "E" --> "H[货主账单更新]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深靛蓝(#1B2A4A) + 琥珀橙(#F59E0B) 双色系，深蓝代表专业与信任，琥珀橙代表活力与效率
- **辅助色**: 薄荷绿(#10B981)表示正向状态/增长，珊瑚红(#EF4444)表示警告/异常
- **按钮风格**: 圆角6px，主按钮深靛蓝底白字，次按钮白底靛蓝边框，悬停时微阴影
- **字体**: 标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据/数字使用 JetBrains Mono
- **布局风格**: 左侧固定导航栏(64px) + 顶部操作栏 + 主内容区，卡片式布局，间距16px/24px
- **图标风格**: Lucide Icons 线性图标，2px描边，与文字大小对齐
- **地图/图表**: 深色底图，热力渐变叠加，数据点脉冲动画

### 4.3 响应式设计

- 桌面优先设计，最小支持1280px宽度
- 1024-1280px：侧边栏折叠为图标模式
- 768-1024px：双列布局变单列，地图全宽
- 触控优化：按钮最小44px触控区域，地图手势缩放
