## 1. 产品概述

渔船出海作业监管系统是一套面向渔政监管、船东、船员、港口和值班人员的综合监管平台。系统实现渔船档案管理、出海申报审批、实时轨迹与围栏监管、事件处置和统计报表五大核心能力，确保船、人、海域、作业和告警全程可追踪。

- 目标用户：渔政监管人员、船东、船员、港口管理人员、值班人员
- 核心价值：杜绝未审批出海、实时掌控渔船动态、快速响应违规与突发事件、形成完整监管台账

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 渔政监管 | 管理员分配 | 全局监管、审批、事件处置、报表查看 |
| 船东 | 管理员分配 | 管理自有渔船档案、提交出海申报、查看自有船只状态 |
| 船员 | 管理员分配 | 查看个人出海记录、当前任务状态 |
| 港口人员 | 管理员分配 | 出海申报核验、进出港登记 |
| 值班人员 | 管理员分配 | 实时监控看板、告警处置、事件上报 |

### 2.2 功能模块

1. **渔船档案页**：渔船列表、新增/编辑渔船、证书管理、设备状态查看
2. **出海申报页**：申报列表、新建申报、核验审批、申报详情与状态跟踪
3. **实时监管页**：轨迹地图展示、电子围栏、禁渔区预警、超时未返告警、设备离线告警
4. **事件处置页**：事件列表、事件详情、处置流程、通知与回执记录
5. **统计报表页**：船队统计、海域统计、出海次数、违规类型分布、安全风险评分
6. **首页仪表盘**：关键指标概览、近期告警、待办事项

## 3. 核心流程

### 3.1 出海申报审批流程

船东或船长提交出海申报 → 系统自动核验（证书有效期、保险状态、作业许可）→ 港口人员人工核验 → 审批通过/驳回 → 通过后渔船可出海 → 实时监管自动跟踪

```mermaid
flowchart TD
    "A[船东提交出海申报]" --> "B[系统自动核验]"
    "B" --> "C{核验结果}"
    "C" -->|"通过"| "D[港口人员人工核验]"
    "C" -->|"未通过"| "E[驳回申报，记录原因]"
    "D" --> "F{人工核验结果}"
    "F" -->|"通过"| "G[申报通过，渔船可出海]"
    "F" -->|"驳回"| "E"
    "G" --> "H[进入实时监管]"
    "H" --> "I[正常返港/触发告警]"
    "I" --> "J[完成出海记录]"
```

### 3.2 事件处置流程

告警触发/人工上报 → 创建事件 → 通知相关人员 → 接收回执 → 处置决策 → 记录结论

```mermaid
flowchart TD
    "A[告警触发/人工上报]" --> "B[创建事件记录]"
    "B" --> "C[通知相关人员]"
    "C" --> "D[接收回执]"
    "D" --> "E[处置决策]"
    "E" --> "F[记录处理结论]"
    "F" --> "G[事件关闭]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 (#0C4A6E) 搭配海洋青 (#0891B2)，传递专业、严谨的监管氛围
- 辅助色：告警橙 (#F59E0B)、危险红 (#EF4444)、安全绿 (#10B981)
- 按钮风格：圆角按钮，主要操作使用实心填充，次要操作使用描边
- 字体：Noto Sans SC（中文），配合系统字体回退
- 布局风格：左侧导航栏 + 顶部面包屑 + 主内容区，卡片式布局
- 图标：使用 lucide-react 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页仪表盘 | 关键指标 | 四宫格统计卡片，图标+数字+趋势 |
| 首页仪表盘 | 近期告警 | 紧凑列表，颜色编码严重程度 |
| 渔船档案 | 渔船列表 | 搜索栏+筛选器+表格，状态徽章 |

| 出海申报 | 核验审批 | 详情卡片+核验检查项+审批按钮 |

### 4.3 响应式设计

- 桌面端优先（1440px+），适配1280px+
- 平板端（768px-1280px）布局适度收缩
- 移动端（<768px）仅保留核心查看功能，管理操作引导至桌面端

## 5. 数据模型

### 5.1 核心实体

- 渔船（Vessel）：船名、船号、船东、作业类型、定位设备、安全设备
- 证书（Certificate）：类型、编号、有效期、所属渔船
- 出海申报（Declaration）：关联渔船、船员名单、计划海域、预计返港、状态
- 轨迹点（TrackPoint）：渔船ID、经纬度、速度、时间戳
- 电子围栏（Fence）：名称、区域坐标、类型（禁渔区/限制作业区）
- 告警（Alert）：类型、关联渔船、触发条件、时间、状态
- 事件（Event）：类型、关联渔船、描述、处置状态、通知记录、回执、结论
- 人员（Person）：姓名、角色、联系方式、关联渔船
