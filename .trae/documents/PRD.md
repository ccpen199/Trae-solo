## 1. 产品概述

房地产垂直领域交易赋能平台，聚焦新房交易全链路数字化，通过结构化楼盘信息、智能找房引擎、购房金融工具与投诉维权通道，为购房人提供从信息获取到签约入住的一站式服务闭环。核心解决新房市场信息不对称、五证真实性难验证、购房决策工具缺失等痛点，面向购房人、经纪人与楼盘顾问三类核心用户群体。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 购房人 | 手机号注册 | 浏览楼盘/房源、使用计算器、摇号选房、提交投诉、订阅动态 |
| 经纪人 | 实名认证注册 | 录入带看记录、管理客户、查看购房人资质预审结果 |
| 楼盘顾问 | 开发商授权注册 | 更新楼盘/房源信息、发布探盘动态、管理摇号公示 |
| 乐居号创作者 | 申请入驻 | 发布图文/图集内容、查看阅读量统计 |

### 2.2 功能模块

1. **首页**：平台入口、热门楼盘推荐、快速找房入口、购房工具快捷入口、探盘动态流
2. **楼盘详情页**：楼盘信息结构化展示、VR/航拍视频嵌入、价格走势图表、五证信息核验、在售房源一房一价
3. **地图找房页**：地图引擎、热力图叠加（房价/成交量/学区划片）、筛选器、房源标注聚合
4. **购房计算器页**：组合贷试算、税费明细分解、月供还款计划表
5. **摇号选房页**：摇号模拟器、公证摇号算法演示、选房顺序公示、结果查询
6. **黑猫投诉页**：投诉工单提交、工单状态追踪、自动同步开发商售后系统
7. **乐居号后台页**：图文/图集内容发布、阅读量统计面板、粉丝管理
8. **探盘动态页**：顾问动态流、动态订阅与推送、楼盘关联更新
9. **五证校验页**：OCR识别上传、住建局接口核验结果、证照状态展示

## 3. 核心流程

### 购房人核心流程
购房人从浏览楼盘到完成选房的完整链路：首页浏览 → 地图找房/楼盘详情 → 贷款预审/计算器 → 摇号报名 → 摇号选房 → 投诉维权/动态订阅

```mermaid
flowchart TD
    "首页浏览" --> "地图找房"
    "首页浏览" --> "楼盘详情"
    "地图找房" --> "楼盘详情"
    "楼盘详情" --> "五证核验"
    "楼盘详情" --> "一房一价"
    "楼盘详情" --> "购房计算器"
    "购房计算器" --> "组合贷试算"
    "购房计算器" --> "税费明细"
    "楼盘详情" --> "摇号报名"
    "摇号报名" --> "摇号选房"
    "摇号选房" --> "结果公示"
    "楼盘详情" --> "黑猫投诉"
    "楼盘详情" --> "探盘订阅"
```

### 经纪人核心流程
经纪人管理客户与带看记录：查看购房人资质 → 预约带看 → 录入带看记录 → 推荐房源

```mermaid

    "购房人资质预审" --> "预约带看"
    "预约带看" --> "录入带看记录"
    "录入带看记录" --> "推荐房源"
    "推荐房源" --> "购房计算器"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿（#1A3C34）为品牌色，搭配暖金色（#C9A96E）作为强调色，传达地产行业的稳重与品质感
- **辅助色**：浅米白（#F5F0E8）背景，深炭灰（#2D2D2D）文字，淡绿（#E8F0EC）卡片底色
- **按钮风格**：圆角8px，主按钮深墨绿实底白字，次按钮墨绿描边，金色悬浮按钮用于快捷操作
- **字体**：标题使用 Noto Serif SC（衬线体，传达高端品质），正文使用 Noto Sans SC（无衬线，清晰易读）
- **布局风格**：顶部固定导航栏，左侧主内容区+右侧信息栏双栏布局，卡片式模块化组合
- **图标风格**：线性图标（Lucide），2px描边，与整体精致风格统一
- **视觉细节**：卡片微阴影+细边框，价格数字加粗放大，地图全屏沉浸式，表格斑马纹

### 4.3 响应式设计

- 桌面优先设计，断点：1280px（桌面）、1024px（平板横屏）、768px（平板竖屏）、480px（手机）
- 桌面端：双栏/三栏布局，地图全屏，表格完整展示
- 平板端：单栏布局，侧边栏折叠为抽屉，卡片2列
- 手机端：底部Tab导航，卡片单列，地图全屏手势操作

### 4.4 无3D场景
本平台不涉及3D场景渲染需求。
