## 1. 产品概述

家庭维修服务产业互联网平台，连接用户、工程师与供应商三方，打造透明、高效、可信的家政维修服务闭环。用户通过AI图像诊断快速识别家电故障并预约服务，工程师通过智能派单与电子工单高效履约，供应商提供配件扫码验真与供应链支撑，后台对接厂商知识库并建立信用评级与合规存证体系。

- 解决传统家庭维修行业信息不透明、服务标准化程度低、配件真伪难辨、合同合规存证缺失等痛点
- 目标用户：家庭用户（C端）、维修工程师（B端独立从业者）、配件供应商、平台运营方

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 家庭用户 | 手机号注册/微信授权 | AI诊断、预约服务、直播观看、比价、电子签约、评价 |
| 维修工程师 | 实名认证+技能审核 | 接单派单、直播检修、配件扫码入库、电子工单、信用评级查看 |
| 供应商 | 企业资质认证 | 配件上架、库存管理、扫码验真、订单履约 |
| 平台管理员 | 内部授权 | 派单引擎配置、AI质检、信用评级管理、知识库维护、合规存证 |

### 2.2 功能模块

1. **首页**: 平台入口、服务品类导航、AI诊断入口、热门服务推荐、工程师推荐
2. **AI诊断页**: 上传故障照片、AI识别家电品类与故障类型、推荐服务方案与报价
3. **服务比价页**: 电子价目表、多家服务商透明比价、服务详情对比
4. **服务直播页**: 工程师实时检修直播、互动弹幕、检修步骤展示
5. **工程师工作台**: 智能派单看板、配件扫码验真、电子工单管理（含前后对比图+用户签字）
6. **供应商管理页**: 配件上架、库存管理、验真溯源
7. **后台管理页**: 派单引擎配置、工程师信用评级、AI质检、厂商知识库对接、电子合同存证

## 3. 核心流程

### 3.1 用户服务预约流程

用户打开平台 → 选择AI诊断或手动选择品类 → 上传故障照片/描述问题 → AI识别品类与故障类型 → 展示诊断结果与推荐服务 → 用户查看电子价目表比价 → 选择服务方案 → 系统智能派单 → 工程师接单 → 工程师开启直播检修 → 用户实时观看 → 检修完成上传前后对比图 → 用户签字确认 → 电子合同存证 → 评价完成

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深海蓝(#0A2647) + 科技青(#2EF2A5) 搭配，传达专业可信与科技感
- **辅助色**: 暖橙(#FF6B35)用于行动号召，浅灰蓝(#E8EDF2)用于背景层次
- **按钮风格**: 圆角8px、微阴影悬浮效果、主按钮渐变填充
- **字体**: 标题使用"钉钉进步体"风格的无衬线粗体，正文使用系统默认字体栈
- **布局风格**: 侧边导航+主内容区，卡片式模块布局，大量留白保证信息层次
- **图标风格**: 线性图标+微渐变填充，2px描边，圆角端点
- **整体调性**: 工业科技风，专业可信赖，数据可视化丰富

### 4.3 响应式策略

- 桌面优先设计，核心操作针对1280px+屏幕优化
- 平板适配：工作台看板从三列变两列，直播页视频区缩小
- 移动端适配：导航变为底部Tab，卡片单列，直播页全屏视频

### 4.4 无3D场景

本平台为2D Web应用，不涉及3D场景。
