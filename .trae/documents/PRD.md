## 1. 产品概述

全域缴费+普惠金融融合服务平台，面向C端用户与B端商户，接入水、电、气、暖、通讯、社保等万余项缴费项目，同时嵌入理财、保险、贷款等普惠金融产品。平台以缴费为高频入口、金融为增值引擎，构建"缴费+金融"一站式闭环服务体系。

- 核心目标：让用户在一个平台上完成所有生活缴费，并基于缴费数据获得精准金融产品推荐
- 目标用户：C端个人用户（日常缴费+金融服务）、B端商户（入驻缴费项目+分润结算）、运营人员（活动配置+数据运营）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| C端用户 | 手机号注册/登录 | 缴费、代扣签约、金融产品购买、发票管理 |
| B端商户 | 企业资质审核入驻 | 项目接入、分润查询、对账结算 |
| 运营人员 | 内部账号分配 | 活动配置、数据看板、知识库维护、差错仲裁 |

### 2.2 功能模块

1. **平台首页**：缴费项目快捷入口、金融产品推荐、优惠活动Banner、缴费提醒摘要
2. **缴费中心**：水电气暖通讯社保分类导航、账单查询、在线缴费、代扣签约管理
3. **代扣签约**：银行Ⅱ类户绑定、签约协议签署、代扣记录查询、签约解约管理
4. **缴费提醒**：多通道提醒配置（短信/系统通知/公众号）、提醒规则设置、提醒历史
5. **电子发票**：发票自动生成、发票归集管理、发票下载/推送、开票记录
6. **错缴冲正**：错缴申报、冲正申请、差错仲裁流程、退款进度追踪
7. **金融超市**：理财/保险/贷款产品货架、分类筛选、产品详情
8. **风险测评**：风险等级评测问卷、风险偏好画像、产品匹配推荐
9. **额度试算**：贷款额度计算器、还款计划模拟、利率对比
10. **合同签署**：电子合同生成、在线签署、合同存档查看
11. **资金监管**：资金划转记录、监管账户状态、交易流水
12. **数据资产中心**：缴费数据总览、地域维度分析、时段趋势分析、品类聚合报表
13. **商户分润**：分润规则配置、分润计算引擎、光大银行清算对接、结算对账
14. **优惠活动中心**：满减规则编排、红包发放配置、抽奖活动配置、活动效果追踪
15. **缴费诊断**：失败根因诊断、知识库检索、常见问题解答、诊断报告生成

## 3. 核心流程

### 3.1 缴费核心流程

用户选择缴费品类 → 输入户号查询账单 → 确认账单信息 → 选择支付方式（即时缴费/代扣签约）→ 完成支付 → 自动生成电子发票 → 缴费提醒更新

```mermaid
flowchart TD
    "选择缴费品类" --> "输入户号查询"
    "输入户号查询" --> "确认账单信息"
    "确认账单信息" --> "选择支付方式"
    "选择支付方式" --> "即时缴费"
    "选择支付方式" --> "代扣签约"
    "即时缴费" --> "完成支付"
    "代扣签约" --> "绑定Ⅱ类户"
    "绑定Ⅱ类户" --> "签约协议"
    "签约协议" --> "完成支付"
    "完成支付" --> "生成电子发票"
    "生成电子发票" --> "推送缴费提醒"
```

### 3.2 金融产品购买流程

浏览产品货架 → 风险测评（首次）→ 选择产品 → 额度试算（贷款类）→ 合同签署 → 资金划转 → 完成购买

```mermaid

    "浏览产品货架" --> "风险测评检查"
    "风险测评检查" --> "已完成测评"
    "风险测评检查" --> "未完成测评"
    "未完成测评" --> "风险测评问卷"
    "风险测评问卷" --> "测评结果与产品匹配"
    "已完成测评" --> "选择产品"
    "测评结果与产品匹配" --> "选择产品"
    "选择产品" --> "额度试算"
    "额度试算" --> "确认购买"
    "确认购买" --> "合同在线签署"
    "合同在线签署" --> "资金划转监管"
    "资金划转监管" --> "完成购买"
```

发现错缴 → 提交冲正申请 → 系统自动审核 → 通过则直接退款 / 不通过则进入仲裁 → 仲裁员审核 → 仲裁裁决 → 执行退款

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝 #1B3A5C（金融可信感）+ 金色 #D4A843（高端品质感）
- **辅助色**：翠绿 #2ECC71（缴费成功）、橙红 #E74C3C（提醒/警告）、冰蓝 #E8F4FD（背景色）
- **按钮风格**：圆角6px，主按钮深蓝实底，次按钮白底蓝边，危险操作橙红实底
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- **布局风格**：左侧导航栏 + 顶部标签栏，内容区卡片式布局
- **图标风格**：线性图标（Lucide），2px描边，统一尺寸
- **数据可视化**：使用渐变色图表，深色背景下高对比度
