## 1. 产品概述

面向房产经纪人的SaaS化移动工作台系统，为经纪公司提供从经纪人认证、房源客源管理、带看调度到交易闭环、佣金结算的全链路数字化工作平台。目标用户为房产经纪公司（总监/店长/经纪人三级角色），核心价值在于提升经纪人工作效率、规范交易流程、实现佣金透明分账。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 总监 | 管理员创建 | 全公司数据查看、组织架构管理、角色权限分配、审计日志查看 |
| 店长 | 总监/管理员创建 | 本门店数据查看、经纪人管理、带看审核、佣金审批 |
| 经纪人 | 店长创建/自主注册 | 房源/客源管理、带看日程、交易录入、佣金查看 |

### 2.2 功能模块

1. **登录与认证页**：登录、注册、实名认证
2. **工作台首页**：数据概览、待办事项、就近楼盘推送
3. **房源管理**：房源列表、房源详情、新增/编辑房源、图片上传、住建委备案校验
4. **客源管理**：客源列表、客源详情、新增/编辑客源、跟进记录
5. **带看日程**：日程日历、新增带看、智能调度、带看记录
6. **交易看板**：可视化看板（签约→贷款→过户→完成）、交易详情
7. **佣金管理**：分账规则、结算台账、佣金明细
8. **组织管理**：公司/门店/团队管理、成员管理
9. **系统设置**：角色权限、操作审计、系统配置

## 3. 核心流程

### 3.1 经纪人工作主流程

经纪人登录→实名认证→录入/查看房源→录入/查看客源→创建带看日程→带看完成→录入交易→交易推进（签约→贷款→过户）→交易完成→佣金结算

```mermaid
flowchart TD
    "登录系统" --> "实名认证"
    "实名认证" --> "管理房源"
    "实名认证" --> "管理客源"
    "管理房源" --> "创建带看"
    "管理客源" --> "创建带看"
    "创建带看" --> "带看完成"
    "带看完成" --> "录入交易"
    "录入交易" --> "签约"
    "签约" --> "贷款"
    "贷款" --> "过户"
    "过户" --> "交易完成"
    "交易完成" --> "佣金结算"
```

### 3.2 管理流程

总监创建公司→创建门店→分配店长→店长管理经纪人→权限分配→审计监控

```mermaid
flowchart TD
    "总监登录" --> "创建门店"
    "创建门店" --> "分配店长"
    "店长登录" --> "管理经纪人"
    "管理经纪人" --> "审核认证"
    "审核认证" --> "分配权限"
    "分配权限" --> "业务操作"
    "业务操作" --> "审计留痕"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1E3A5F + 金色 #D4A843（房产高端专业感）
- 辅助色：浅灰背景 #F5F6FA、成功绿 #10B981、警告橙 #F59E0B、错误红 #EF4444
- 按钮风格：圆角8px、主按钮实心深蓝、次按钮描边、危险按钮红色
- 字体：标题使用思源黑体/Noto Sans SC，正文使用系统默认
- 布局风格：左侧导航栏 + 顶部面包屑 + 右侧内容区
- 图标：Lucide图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 登录表单 | 居中卡片、深蓝渐变背景、金色Logo、圆角输入框 |
| 工作台首页 | 数据概览 | 4个统计卡片（带看/成交/客源/待办）、图表区、就近楼盘横向滚动 |
| 房源列表 | 筛选与列表 | 顶部筛选栏、网格/列表切换、卡片式房源展示 |
| 交易看板 | 看板视图 | 四列横向看板、卡片拖拽、节点颜色标记 |
| 带看日程 | 日历视图 | 左侧日历、右侧带看列表、时间轴展示 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1024px
- 平板适配：768px-1024px 侧边栏折叠
- 移动端适配：＜768px 底部导航栏、单列布局
- 触摸优化：按钮最小44px、滑动操作支持
