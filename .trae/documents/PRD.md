## 1. 产品概述

面向省级人社系统的养老待遇资格自助认证SaaS平台，为全省领取养老金的退休人员提供极简流程的身份核验服务，通过人脸识别活体检测自动完成资格认证，认证结果实时同步至省级核心业务系统并生成电子凭证。后台提供数据看板、异常预警、人工复核与全链路审计能力，确保社保基金安全与审计合规。

- 核心目标：让退休人员"一次刷脸、全程自助"完成年度养老待遇资格认证，消除跑腿与纸质证明
- 市场价值：降低基层窗口人力成本、杜绝冒领骗领、实现全省认证数据实时汇聚与精准监管

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 退休人员（认证用户） | 身份证号+社保卡号自动关联 | 自助认证、查看认证记录、一键呼入客服 |
| 审核人员 | 后台账号分配 | 人工复核工单、异常处理、日志审计查询 |
| 管理员 | 后台账号分配 | 数据看板、预警规则配置、系统参数管理 |

### 2.2 功能模块

1. **认证首页**：极简入口、语音引导开始认证、一键呼入客服、认证状态展示
2. **人脸认证页**：活体检测交互、实时人脸框引导、弱网状态提示、认证进度反馈
3. **认证结果页**：认证成功/失败结果展示、电子凭证生成与下载、失败原因说明与重试引导
4. **后台数据看板**：认证量趋势图、地区分布热力图、失败原因分类饼图、时段统计柱状图
5. **异常预警页**：高频重复认证预警列表、异地集中认证预警列表、预警详情与处置
6. **人工复核工单池**：待复核工单列表、工单详情（含截图存证）、复核操作（通过/驳回/转办）
7. **认证日志审计**：全链路日志查询、摄像头帧截图存证查看、日志导出

## 3. 核心流程

### 3.1 自助认证主流程

用户打开认证首页 → 语音引导提示"请点击开始认证" → 用户点击"开始认证" → 系统调用人脸识别活体检测 → 用户按提示完成动作（眨眼/摇头）→ 活体检测通过 → 系统自动关联社保库身份信息比对 → 比对成功 → 生成带时间戳与设备指纹的电子凭证 → 认证结果实时同步至省级核心业务系统 → 展示认证成功页面与电子凭证

### 3.2 弱网重试流程

认证过程中检测到网络中断 → 本地缓存认证数据（含活体检测帧截图）→ 网络恢复后自动重试提交 → 重试成功则正常完成认证 → 超过重试上限则提示用户稍后重试

### 3.3 异常预警流程

系统实时监测认证行为 → 触发预警规则（高频重复/异地集中等）→ 生成预警记录 → 推送至审核人员 → 审核人员查看预警详情并处置

### 3.4 人工复核流程

系统将可疑认证自动生成复核工单 → 工单进入复核池 → 审核人员领取工单 → 查看认证截图存证与日志 → 作出通过/驳回/转办决定 → 复核结果同步更新认证状态

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：温暖稳重的深靛蓝 #1B3A5C（政府公信力感）+ 暖橙 #E8763A（亲和力与引导感）
- **辅助色**：成功绿 #2EAD6B、警告黄 #F5A623、错误红 #D94452、浅灰背景 #F5F6FA
- **按钮风格**：大尺寸圆角按钮（最小触控区域 48px），主操作按钮带微阴影，3D凸起质感
- **字体与尺寸**：标题 28-36px、正文 20-24px、辅助文字 18px，全部使用无衬线粗体，行距 1.6 倍
- **布局风格**：卡片式布局、顶部大标题导航、底部固定操作栏、单列垂直流式布局
- **图标风格**：线条粗实、尺寸 32-48px、高对比度填充图标，配合文字标签

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|

### 4.3 响应式设计

- **桌面优先**：后台管理系统采用 1280px+ 桌面端优先设计，侧边栏导航+内容区布局
- **移动端适配**：前端认证界面以移动端为主（375px-428px），采用大字体、大按钮、单列布局
- **触控优化**：所有可交互元素最小触控区域 48×48px，按钮间距不小于 16px
- **横屏兼容**：认证页面锁定竖屏方向，后台管理支持横屏自适应

### 4.4 无障碍与适老化

- 所有文字最小 18px，关键信息 24px 以上
- 语音引导覆盖每个操作步骤，支持语音开关
- 页面无跳转，单页内完成全流程
- 色彩对比度不低于 4.5:1
- 支持系统字体缩放
