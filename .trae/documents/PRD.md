## 1. 产品概述

区域性房产信息服务平台，覆盖新房、二手房、租房、家居全链条，为购房者、业主、经纪人提供一站式房产服务。核心解决房产信息不对称、虚假房源泛滥、购房决策难等行业痛点。

- 目标用户：购房者、租房者、业主、房产经纪人、中介机构
- 核心价值：真实房源保障、智能搜索匹配、专业购房工具、高效经纪人协同
- 市场定位：区域性权威房产信息平台，合规监管对接住建局

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 手机号注册 | 浏览房源、使用购房工具、收藏对比、预约看房 |
| 业主 | 手机号实名验证 | 发布房源、管理房源、查看带看记录 |
| 经纪人 | 身份备案+机构认证 | 房源管理、客户管理、带看登记、成交登记 |
| 管理员 | 后台账号 | 房源审核、用户管理、数据统计、监管上报 |

### 2.2 功能模块

1. **首页**：房源分类导航、热门推荐、搜索入口、价格走势、工具箱入口
2. **多维房源库**：新房列表、二手房列表、租房列表、房源详情（VR、产权、学区、地铁）
3. **智能搜索中枢**：地图搜索、地铁站半径检索、学区划片匹配、价格筛选、价格走势图表
4. **购房者工具箱**：房贷试算器、税费估算器、楼盘对比矩阵
5. **经纪人工作台**：带看记录、客户分级、成交闭环
6. **房源核验**：业主验证、中介备案、挂牌时效、防虚假算法
7. **监管上报**：住建局数据接口、房源合规校验

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色 #1E40AF（专业、可信赖）
- **辅助色**：橙色 #F97316（活力、行动指引）、绿色 #10B981（核验通过）、红色 #EF4444（警告）
- **中性色**：锌灰色系（Zinc）#18181B 至 #FAFAFA
- **字体**：
  - 标题：Noto Serif SC（优雅、权威感的衬线字体）
  - 正文：Inter（清晰易读的无衬线字体）
- **按钮风格**：圆角 8px，悬停有微缩放和阴影变化，主按钮渐变背景
- **布局风格**：卡片式布局，大量留白，栅格系统，层次分明
- **图标风格**：Lucide 线性图标，统一 24px 尺寸

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|----------|
| 首页 | Hero 区 | 全屏背景图+渐变遮罩，大标题搜索框，分类导航卡片悬浮 |
| 首页 | 价格走势 | 交互式折线图，悬停显示具体数值，区域切换标签 |
| 房源列表 | 筛选栏 | 固定顶部，下拉筛选器，标签式快捷筛选 |
| 房源列表 | 房源卡片 | 图片悬浮放大效果，价格角标，核验标签徽标 |
| 房源详情 | 图片轮播 | VR 全景入口，缩略图导航，图片放大预览 |
| 房源详情 | 信息区块 | 分组卡片，可折叠展开，关键信息高亮 |
| 房源详情 | 地图区块 | 内嵌地图，周边配套标记，距离计算 |
| 工具箱 | 计算器 | 表单式布局，滑块输入，实时计算，结果可视化 |
| 经纪人工作台 | 仪表盘 | 数据卡片网格，图表可视化，进度条展示 |

### 4.3 响应式设计

- **桌面端优先**：1200px 以上为主设计尺寸，栅格 12 列
- **平板适配**：768px-1199px，双列布局，侧边栏收起
- **移动端**：375px-767px，单列布局，底部导航，简化筛选
- **交互优化**：移动端手势操作，触摸目标 ≥ 44px，按钮间距 ≥ 8px

### 4.4 动效设计

- **页面加载**：骨架屏先出，内容渐入，列表项错开动画
- **卡片悬停**：上浮 4px，阴影加深，图片微放大
- **按钮点击**：缩放 0.97，背景色过渡
- **表单交互**：输入框聚焦时边框高亮，错误提示抖动
- **图表动画**：数据从 0 增长到目标值，折线绘制动画
- **滚动效果**：导航栏背景渐变，元素视差滚动
