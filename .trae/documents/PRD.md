## 1. 产品概述

灵活用工众包服务平台，面向学生、宝妈、退休人员等非全日制群体，提供分级任务接单与佣金结算服务；同时为雇主提供企业认证、保证金托管、合规审核一体化发布通道，构建安全可信的零工经济生态。

- 解决零工群体找活难、收入不透明、权益无保障的痛点
- 目标成为国内领先的灵活用工合规众包平台，连接千万灵活就业者与合规雇主

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 接单者（自由职业者） | 手机号注册 + 实名认证 | 浏览/接取任务、提交交付物、提现佣金 |
| 雇主（企业/个体工商户） | 手机号注册 + 企业认证 | 发布任务、审核交付、缴纳保证金 |
| 平台管理员 | 后台账号分配 | 合规审核、风控监控、热度预测管理 |

### 2.2 功能模块

1. **接单者首页**：Hero 区展示平台价值、今日推荐任务池、实时收益播报
2. **任务大厅**：按难度分级（L1-L5）浏览、筛选、搜索任务，查看交付标准与佣金
3. **任务详情页**：任务描述、交付标准、验收时效、佣金阶梯、提交入口
4. **我的任务**：进行中/待验收/已完成/已弃单任务列表
5. **个人中心**：收益统计、佣金阶梯进度、提现记录、实名信息
6. **雇主工作台**：任务发布、交付审核、保证金余额、企业认证状态
7. **管理后台**：合规审核队列、风控看板（设备审计+资金监控）、热度预测看板

## 3. 核心流程

### 3.1 接单者流程

接单者从浏览任务到提现佣金的完整流程：

1. 注册并完成实名认证
2. 在任务大厅按难度/类别浏览任务
3. 查看任务详情，了解交付标准与佣金
4. 点击"接单"锁定任务名额
5. 完成任务并上传交付物
6. 等待雇主在验收时效内审核
7. 审核通过后佣金入账
8. 完成累计10单后触发佣金阶梯上浮
9. 在个人中心发起提现

```mermaid

    "注册+实名认证" --> "浏览任务大厅"
    "浏览任务大厅" --> "查看任务详情"
    "查看任务详情" --> "点击接单"
    "点击接单" --> "完成交付+上传"
    "完成交付+上传" --> "雇主审核"
    "雇主审核" --> "审核通过"
    "雇主审核" --> "审核驳回"
    "审核驳回" --> "重新提交"
    "重新提交" --> "雇主审核"
    "审核通过" --> "佣金入账"
    "佣金入账" --> "累计10单?"
    "累计10单?" --> "是：单价上浮15%"
    "累计10单?" --> "否：继续接单"
    "是：单价上浮15%" --> "发起提现"
    "否：继续接单" --> "浏览任务大厅"
    "发起提现" --> "超5000元?"
    "超5000元?" --> "是：人工复核"
    "超5000元?" --> "否：自动到账"
    "是：人工复核" --> "复核通过→到账"
```

### 3.2 雇主发布流程

1. 注册并完成企业认证（营业执照+银行账户实名）
2. 缴纳保证金
3. 填写任务发布表单
4. 平台合规审核（排除刷单/传销/非法集资类）
5. 审核通过后任务上架
6. 接单者提交交付物后进行审核
7. 确认通过后佣金从保证金中释放

```mermaid

    "注册+企业认证" --> "缴纳保证金"
    "缴纳保证金" --> "填写任务表单"
    "填写任务表单" --> "平台合规审核"
    "平台合规审核" --> "审核通过→上架"
    "平台合规审核" --> "审核驳回→修改重提"
    "审核驳回→修改重提" --> "填写任务表单"
    "审核通过→上架" --> "接单者接单交付"
    "接单者接单交付" --> "雇主审核交付物"
    "雇主审核交付物" --> "通过→佣金释放"
    "雇主审核交付物" --> "驳回→接单者重做"
    "驳回→接单者重做" --> "接单者接单交付"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙色 #FF6B35（象征活力与收益），辅助色深青 #1A535C（象征信任与稳健）
- **强调色**：金黄 #FFD166（佣金/成就高亮），警示红 #EF476F（风控/驳回）
- **按钮风格**：圆角胶囊按钮，主操作使用渐变填充，次操作使用描边样式
- **字体**：标题使用 Noto Serif SC（宋体韵味，传递专业感），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：卡片式布局，任务卡片带左侧难度色带标识，顶部导航栏 + 侧边栏（管理后台）
- **图标风格**：线性图标搭配微渐变色填充，难度等级使用盾牌/星章图标

### 4.3 响应式设计

- 桌面优先设计，核心内容区最大宽度 1280px
- 平板端（≤1024px）：侧边栏折叠为汉堡菜单，任务卡片单列展示
- 移动端（≤768px）：底部 Tab 导航替代顶部导航，表单全屏分步展示，触控优化按钮最小 44px

### 4.4 3D 场景

不适用，本项目以 2D 界面为主。
