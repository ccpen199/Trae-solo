## 1. 产品概述

工程依赖漏洞扫描平台是面向平台工程师、运维、开发者、应用负责人和安全管理员的专业漏洞管理系统，实现应用接入、配置变更、执行记录、权限审计和故障恢复的完整业务链路闭环。

- 解决软件供应链安全问题，实现依赖组件漏洞的全生命周期管理
- 核心价值：关键对象可追溯、处理动作可审计、结果口径可验证

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 平台工程师 | 管理员分配 | 系统配置、接入管理、全局视图 |
| 运维工程师 | 管理员分配 | 环境配置、任务执行、故障恢复 |
| 开发者 | 管理员分配 | 应用接入、漏洞查看、修复提交 |
| 应用负责人 | 管理员分配 | 应用审批、告警处理、漏洞闭环 |
| 安全管理员 | 管理员分配 | 安全策略、权限审计、合规检查 |

### 2.2 功能模块

1. **工作台**：风险概览、待处理事项、责任人标注、建议动作、关闭依据
2. **档案管理**：应用、环境、版本、密钥、执行任务、调用日志、变更单、告警记录
3. **扫描管理**：扫描任务配置、执行记录、漏洞详情、修复跟踪
4. **配置中心**：系统配置、规则管理、通知配置、权限配置
5. **审计中心**：操作日志、权限审计、变更历史、时间线追溯

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝安全主题 (#1e3a5f)，强调专业可信
- 辅助色：警告橙 (#f59e0b)、危险红 (#ef4444)、成功绿 (#10b981)、信息蓝 (#3b82f6)
- 按钮风格：直角微圆角 (2px)，点击有明显状态反馈
- 字体：专业等宽字体用于代码展示，清晰无衬线字体用于正文
- 布局风格：左侧导航 + 顶部操作栏 + 主内容区，卡片式信息展示
- 图标风格：lucide-react 线性图标，保持简约专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 风险仪表盘 | 统计卡片、风险热力图、趋势折线、待办列表 |
| 应用档案 | 列表页 | 数据表格、筛选栏、批量操作、分页、状态标签 |
| 应用档案 | 详情页 | 标签页切换、信息卡片、时间线组件、操作按钮 |
| 扫描任务 | 详情页 | 进度条、漏洞等级分布饼图、漏洞列表、修复建议 |
| 告警中心 | 列表页 | 告警等级色标、快速处理按钮、状态流转下拉 |
| 变更中心 | 详情页 | 变更对比、操作者信息、回滚按钮、审批流 |

### 4.3 响应性

- 桌面端优先设计，支持 1280px 以上分辨率
- 表格区域支持水平滚动，避免内容压缩
- 关键操作按钮保持在可视区域
- 模态框居中显示，适配不同屏幕尺寸

### 4.4 交互细节

- 表单提交前进行字段完整性、过期状态、停用状态、权限匹配校验
- 关键操作二次确认，防止误操作
- 数据加载使用骨架屏，避免页面闪烁
- 操作结果使用 Toast 提示，成功/失败状态明确
