## 1. 产品概述

AI原生简历创作与职业发展协同平台——通过自然语言对话驱动简历生成，结合STAR法则重写、行业术语强化与ATS友好排版，打造从简历创作、优化到职业发展的全链路智能体验。
- 解决求职者简历撰写效率低、表达不规范、ATS通过率低的痛点，面向1-10年工作经验的职场人群
- 产品价值：将简历制作从"手工打磨"升级为"AI协作精炼"，显著提升求职竞争力与投递转化率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |

| 普通用户 | 邮箱/手机注册 | 简历创建、编辑、导出、简历实验室、案例库浏览 |
| 高级用户 | 付费订阅 | 解锁高级模板、无限AI重写、批量导出、数据迁移 |

3. **简历编辑器页**：模板引擎、CSS主题切换、模块化拖拽编辑、实时预览
4. **简历实验室页**：PDF上传解析、优化建议、动词强度分析、量化检测、排版冗余检测
5. **案例库页**：行业/岗位/经验层级分类筛选、HR点评锚点、案例详情
6. **数据仪表盘页（管理员）**：简历质量趋势、ATS通过率预估、模板使用热力图、用户活跃度
7. **个人中心页**：简历版本快照管理、跨端同步状态、数据导出与迁移、端到端加密设置

## 3. 核心流程

### 3.1 AI对话创作流程
用户进入AI对话页 → 输入职业背景描述 → AI生成结构化简历框架 → 用户补充项目经历 → AI以STAR法则重写经历描述 → 行业术语自动强化 → 用户确认内容 → 进入编辑器精调 → 选择模板与主题 → 导出简历

### 3.2 简历实验室流程
用户上传PDF简历 → 系统OCR解析提取结构化内容 → AI分析动词强度/量化数据/排版 → 生成分项评分与优化建议 → 用户逐条确认修改 → 一键应用优化 → 导出优化后简历

## 4. 用户界面设计

### 4.1 设计风格

- **整体美学方向**：Editorial/Magazine（编辑杂志风）——精致排版、强对比层级、优雅留白，传递"专业职场精英"的信任感
- **主色调**：深墨绿 (#0A2E1C) 为底色，搭配明亮翡翠绿 (#00D68F) 作为强调色，传达成长与专业
- **辅助色**：暖金色 (#D4A843) 用于高亮评分和成就标识，浅灰白 (#F7F8FA) 用于内容区域背景
- **按钮风格**：圆角6px、微投影、hover时轻微上浮+色彩加深，CTA按钮使用翡翠绿实心填充
- **字体方案**：标题使用 Playfair Display（衬线体，杂志感），正文使用 DM Sans（几何无衬线，清晰易读），数据/代码使用 JetBrains Mono
- **布局风格**：左侧固定导航栏+右侧内容区，编辑器采用双栏（编辑/预览）布局
- **图标风格**：线性图标（24px），1.5px描边，圆角端点，与整体精致感统一

### 4.3 响应式设计

- 桌面优先（1440px基准），逐步适配1024px平板和375px移动端
- 编辑器在移动端切换为标签页模式（编辑/预览切换），而非双栏并排
- 对话页面在移动端采用全屏对话+浮动预览按钮切换
- 拖拽功能在移动端改为长按排序
- 导航栏在移动端收缩为底部标签栏

### 4.4 动效设计

- 页面加载：元素分批淡入+轻微上浮（stagger animation）
- 对话生成：打字机效果逐字显示，配合光标闪烁
- 拖拽排序：拖起时缩放0.95+投影增强，放下时弹性回弹
- 主题切换：CSS变量过渡动画，颜色平滑渐变（transition: all 0.3s）
- 评分仪表盘：数字滚动计数动画
- 背景效果：Hero区域使用CSS渐变流动动画+微粒点缀
