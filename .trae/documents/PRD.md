## 1. 产品概述

房产交易可信协作平台，聚焦房源真实性治理与经纪人作业提效，通过AI验真、智能派单、VR交互分析与购房决策辅助，构建购房者、经纪人、经纪公司三方可信协作生态。

- 解决二手房交易中房源虚假、信息不对称、带看效率低、决策链路长等核心痛点
- 目标用户：购房者（C端）、房产经纪人（B端）、经纪公司管理层（B端管理）

## 3. 核心流程

### 3.1 AI真房源验证流程

购房者浏览房源时，系统自动触发AI验真引擎：首先从多个房源平台抓取同地址挂牌价进行交叉比对，若价差超过阈值则标记价格异常；然后对房源图片进行篡改检测（EXIF一致性、边缘伪造检测、重复使用检测）；最后校验经纪人历史挂牌记录一致性。三项综合计算房源可信度评分，验真报告实时展示在房源详情页。

```mermaid

    "房源录入" --> "触发AI验真引擎"
    "触发AI验真引擎" --> "多源挂牌价交叉比对"
    "触发AI验真引擎" --> "图片篡改检测"
    "触发AI验真引擎" --> "经纪人挂牌一致性校验"
    "多源挂牌价交叉比对" --> "综合可信度评分"
    "图片篡改检测" --> "综合可信度评分"
    "经纪人挂牌一致性校验" --> "综合可信度评分"
    "综合可信度评分" --> "可信度 ≥ 80%"
    "综合可信度评分" --> "可信度 < 80%"
    "可信度 ≥ 80%" --> "验真通过标签"

```

### 3.2 带看智能派单流程

购房者提交看房需求后，系统创建带看任务进入任务池。智能派单引擎根据经纪人实时位置（距离权重30%）、客户意向匹配度（需求画像与经纪人擅长领域匹配，权重40%）、历史成交率（权重30%）计算综合匹配分，向匹配度最高的经纪人推送任务，经纪人可在30秒内接单或转交。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0D4F4F) 搭配金色点缀 (#D4A843)，传达专业可信与高端品质感
- **辅助色**：浅灰底 (#F5F6F8)、白色卡片、状态色（绿-验真通过、橙-待核验、红-异常）
- **按钮风格**：圆角矩形（8px），主按钮实心深青色，次按钮描边，悬停时微上浮+阴影加深
- **字体**：标题使用 Noto Serif SC（衬线体，传递信赖感），正文使用 DM Sans（几何无衬线体，现代清晰）
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式内容组织，数据可视化区域使用深色背景突出图表
- **图标风格**：线性图标搭配微渐变，数据指标使用圆形图标背景
- **整体美学**：新中式商务风——融合东方美学的留白与对称，现代数据驱动的视觉语言，深色调传达权威感，金色细节点缀品质感

### 4.3 响应式设计

- 桌面端优先设计（1440px基准），平板端（768px-1024px）侧边栏折叠为底部导航，移动端（<768px）单列布局+底部Tab导航
- 数据看板在移动端简化为核心指标+横向滑动图表
- VR全景在移动端支持陀螺仪交互
- 触摸优化：按钮最小点击区域44px，卡片滑动切换

### 4.4 3D场景指引

- VR全景：等距圆柱投影全景图，热点标记支持缩放平移，过渡动画使用淡入淡出
- 户型热力图：2.5D等轴测视角户型底图，热力层叠加使用半透明渐变色
- 环境氛围：暖色调室内光照模拟，适度景深模糊提升空间感
