## 1. 产品概述

广东省人力资源和社会保障厅官方移动政务中台，面向全省居民、用人单位及人社管理者的综合性政务服务平台。整合社保查询、就业服务、人才申报、劳动维权四大核心业务域，实现人社服务"一网通办、掌上可办"。

- 目标用户：广东省居民（参保人员、求职者、专业技术人才、劳动者）、企业HR、人社管理人员
- 核心价值：打破业务壁垒，实现跨域数据互通；线上全流程办理，减少跑腿次数；智能匹配推送，提升服务精准度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 个人用户 | 实名认证（粤省事账号体系） | 社保查询、就业服务、人才申报、劳动维权 |
| 企业用户 | 统一社会信用代码认证 | 岗位发布、面试管理、劳动合同签署 |
| 管理员 | 内部授权 | 数据看板、工单管理、政策维护、审核操作 |

### 2.2 功能模块

1. **首页门户**：服务入口导航、政策公告轮播、快捷服务卡片、地市切换
2. **社保查询**：五险参保明细、缴费记录、电子参保证明生成
3. **就业服务**：岗位智能推送、线上面试预约、视频面试连通
4. **人才服务**：职称申报全流程、材料OCR识别、进度跟踪、评审管理
5. **劳动维权**：劳动合同电子签署、欠薪线索直报、工单跟踪
6. **数据看板**：地市维度数据治理、操作日志、政策检索（管理员）

## 3. 核心流程

### 3.1 社保查询与证明生成流程

用户进入社保查询模块 → 选择险种查看参保明细 → 核实缴费记录 → 点击"生成参保证明" → 系统生成含防伪水印PDF → 用户下载或分享

```mermaid
flowchart TD
    "进入社保查询" --> "选择险种"
    "选择险种" --> "查看参保明细"
    "查看参保明细" --> "核实缴费记录"
    "核实缴费记录" --> "生成参保证明"
    "生成参保证明" --> "添加防伪水印"
    "添加防伪水印" --> "PDF预览"
    "PDF预览" --> "下载/分享"
```

### 3.2 就业服务智能匹配流程

用户填写专业/技能标签 → 系统匹配企业招聘需求 → 推送岗位列表 → 用户查看岗位详情 → 预约面试 → 视频面试连通

```mermaid
flowchart TD
    "填写技能标签" --> "系统智能匹配"
    "系统智能匹配" --> "岗位推荐列表"
    "岗位推荐列表" --> "查看岗位详情"
    "查看岗位详情" --> "预约面试时段"
    "预约面试时段" --> "视频面试连通"
    "视频面试连通" --> "面试评价"
```

### 3.3 职称申报全流程

用户选择申报类别 → 填写申报表单 → 上传材料（OCR识别）→ 提交审核 → 初审/复审 → 专家评审在线打分 → 公示 → 发证

    "填写申报表单" --> "上传证明材料"

用户提交欠薪线索 → 系统生成工单 → 受理分配 → 调查核实 → 处置执行 → 结果反馈 → 用户评价

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：政务蓝 (#1A4B8C) 搭配活力橙 (#E86830) 作为强调色，传递权威与温暖
- **辅助色**：浅灰蓝 (#F0F4F8) 背景、深灰 (#2D3748) 文字、翠绿 (#38A169) 成功态、琥珀 (#D69E2E) 警告态、红 (#E53E3E) 错误态
- **按钮风格**：圆角8px，主按钮填充渐变（蓝→深蓝），次要按钮描边，带微交互hover上浮+阴影
- **字体**：标题使用思源宋体（Noto Serif SC）传递政务庄重感，正文使用 HarmonyOS Sans / PingFang SC 保证可读性
- **布局风格**：顶部导航栏+侧边栏双栏布局，卡片式模块组织，数据看板采用网格布局
- **图标风格**：线性图标+微渐变填充，统一4px描边粗细，圆角端点
- **视觉细节**：政务盾牌纹理水印背景、卡片微阴影层次、数据图表渐变填充

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px完整展示
- 平板（768-1280px）侧边栏折叠为汉堡菜单，卡片单列排列
- 移动端（<768px）底部Tab导航，卡片全宽，表格横向滚动
- 触摸优化：按钮最小44px点击区域，滑动操作支持
