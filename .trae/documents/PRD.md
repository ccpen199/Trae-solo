## 1. 产品概述

毛衫与服装产业链垂直信息撮合平台，聚焦采购找货、加工接单、辅料供应三大核心需求，通过智能匹配引擎连接供需双方，为服装产业链上下游企业提供从寻源到交付的全链路数字化服务。
- 解决服装产业信息不对称、寻源效率低、供应链透明度不足等核心痛点
- 面向毛衫/服装工厂、品牌采购商、设计师工作室、辅料供应商等B端用户，打造产业数字化基础设施

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 采购商 | 手机号+企业资质认证 | 发布采购需求、BOM比价、下单支付、验厂观看 |
| 加工厂 | 手机号+工厂执照认证 | 接单报价、展示产能档期、在线验厂直播 |
| 辅料供应商 | 手机号+营业执照认证 | 发布辅料产品、报价响应、物流发货 |
| 设计师 | 手机号+作品集认证 | 发布设计需求、对接加工厂、BOM清单管理 |
| 平台管理员 | 内部账号 | 产业地图管理、信用评分、资讯发布、报告生成 |

### 2.2 功能模块

1. **首页**: 平台数据总览、快捷入口、行业资讯、推荐供应商
2. **供需大厅**: 采购找货/加工接单/辅料供应三大板块，智能推荐与搜索
3. **智能匹配**: 基于多维度筛选的供需匹配引擎，BOM清单导入比价
4. **产业地图**: 热力图展示产业集群分布与产能富余度
5. **订单中心**: 订单全流程管理、物流跟踪、定金担保支付
6. **供应商中心**: 供应商信用评分、在线验厂、样品寄送管理
7. **资讯报告**: 行业资讯聚合、政策解读、季度产能供需平衡分析报告

## 3. 核心流程

### 3.1 采购商寻源流程
采购商注册认证 → 发布采购需求/BOM导入 → 智能匹配推荐供应商 → 查看供应商信用评分 → 样品寄送确认 → 在线验厂 → 下单定金担保支付 → 生产跟踪 → 验收完成

### 3.2 加工厂接单流程
工厂注册认证（上传执照）→ 完善产能/工艺/档期信息 → 接收匹配推荐 → 报价接单 → 在线验厂直播 → 签约生产 → 交付验收

### 3.3 智能匹配引擎流程
用户输入需求条件 → 多维度权重计算（地理位置30%+产能档期25%+工艺能力25%+历史成交价20%）→ 匹配评分排序 → 推荐Top供应商列表

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深靛蓝(#1B2A4A)为基底，搭配暖琥珀金(#D4A853)作为强调色，青蓝(#2E8B8B)用于数据可视化
- **辅助色**: 浅灰底(#F5F6FA)、白色卡片、深灰文字(#2D3748)
- **按钮风格**: 圆角6px、琥珀金主按钮带微阴影、深靛蓝次按钮描边风格
- **字体**: 标题使用 Noto Serif SC 衬线体彰显行业专业感，正文使用 Noto Sans SC 保证可读性
- **布局风格**: 左侧导航栏+顶部操作栏的经典B端布局，卡片式内容组织，数据密集但层次分明
- **图标风格**: Lucide线性图标，2px描边，与整体专业调性一致
- **装饰元素**: 微妙的纺织纹理背景、纱线/织物线条装饰、传统编织图案融入品牌视觉

### 4.3 响应式设计
- 桌面优先设计，目标分辨率1920x1080
- 平板端（768px+）: 侧边栏收起为图标模式，卡片从三列变两列
- 移动端（<768px）: 底部Tab导航，单列卡片，筛选面板全屏抽屉弹出

### 4.4 动效设计
- 页面加载: 数据指标数字递增动画、卡片依次淡入上移
- 热力图: 区域切换时平滑过渡色彩变化
- 订单状态: 状态变更时进度条平滑过渡、状态点脉冲动画
- 匹配结果: 匹配度环形进度条加载动画
- 鼠标交互: 卡片悬停微上浮+阴影增强、按钮悬停色彩加深
