## 1. 产品概述

职业发展智能辅助平台，聚焦求职者简历制作与竞争力提升。面向求职者与HR双端用户，提供中英双语简历智能编辑、JD语义匹配诊断、大牛案例库与求职全流程管理，同时为HR提供协作空间与AI初筛能力，内置GDPR/《个人信息保护法》合规组件，所有简历内容禁止用于训练外部模型。

- 解决求职者简历质量参差、岗位匹配度低、求职过程混乱的核心痛点
- 面向C端求职者（应届生/社招）与B端HR/招聘团队的双边平台

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 求职者 | 邮箱/手机注册 | 简历编辑、智能诊断、案例浏览、求职管理、合规设置 |
| HR/企业用户 | 企业邮箱注册+审核 | 模板定制、评分标准、投递分析、AI初筛、合规管理 |
| 管理员 | 系统分配 | 用户管理、案例审核、合规审计、系统配置 |

### 2.2 功能模块

1. **首页/工作台**：平台介绍、快速入口、数据概览、最近简历/投递
2. **简历编辑器**：中英双语模板选择、模块化拖拽编辑、ATS友好格式、关键词密度报告、实时预览
3. **智能诊断**：JD语义匹配分析、语法错误标红、岗位适配度评分、优化建议列表
4. **案例库**：行业/职级/公司分类筛选、匿名脱敏浏览、结构化解析、收藏与对比
5. **求职管理**：网申记录看板、面试日程安排、Offer对比矩阵、状态追踪
6. **HR协作空间**：专属模板定制、评分标准配置、投递分析报告、AI初筛阈值过滤
7. **合规中心**：数据最小化采集设置、一键删除权、加密存储状态、合规审计日志

## 3. 核心流程

### 求职者核心流程

求职者注册登录后，选择或创建简历模板，通过拖拽编辑器完成简历内容填写，然后进入智能诊断系统粘贴目标JD进行分析，系统返回匹配度评分与优化建议，求职者根据建议优化简历后导出ATS友好格式PDF，同时可在案例库中参考大牛简历，在求职管理中追踪所有网申/面试/Offer进度。

```mermaid
flowchart TD
    "注册/登录" --> "选择简历模板"
    "选择简历模板" --> "拖拽编辑简历"
    "拖拽编辑简历" --> "查看关键词密度报告"
    "查看关键词密度报告" --> "智能诊断"
    "智能诊断" --> "粘贴JD进行匹配"
    "粘贴JD进行匹配" --> "查看适配度评分与建议"
    "查看适配度评分与建议" --> "优化简历"
    "优化简历" --> "导出PDF"
    "优化简历" --> "参考案例库"
    "导出PDF" --> "投递岗位"
    "投递岗位" --> "求职管理看板"
    "求职管理看板" --> "面试/Offer追踪"
    "面试/Offer追踪" --> "Offer对比决策"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝（#0F2B46）作为品牌主色，搭配琥珀金（#D4A853）作为强调色，传递专业、可信赖、精英感的视觉调性
- **辅助色**：象牙白（#FAFAF5）背景、石墨灰（#2D3436）文字、翡翠绿（#00B894）成功状态、珊瑚红（#E17055）警告/错误
- **按钮风格**：圆角微弧（8px），主按钮深蓝实底+金色hover渐变，次按钮描边风格，禁用态低透明度
- **字体方案**：标题使用 Playfair Display（英文）/ Noto Serif SC（中文），正文使用 DM Sans（英文）/ Noto Sans SC（中文）
- **布局风格**：左侧固定导航栏 + 内容区卡片式布局，编辑器采用双栏布局（编辑+实时预览）
- **图标风格**：线性图标（Lucide），1.5px描边，搭配微妙的金色点缀

### 4.3 响应式设计

- 桌面优先设计，最低支持1280px宽度
- 平板端（768-1279px）：侧边导航折叠为图标模式，编辑器单栏切换预览
- 移动端（<768px）：底部Tab导航，卡片单列堆叠，编辑器全屏编辑模式

### 4.4 动效设计

- 页面切换：淡入+微上移（200ms ease-out）
- 卡片交互：hover时微抬升（translateY -2px）+ 阴影加深
- 评分展示：数字递增动画、雷达图路径绘制动画
- 拖拽反馈：拖起时卡片缩小+半透明、放置区域虚线高亮
- 加载状态：品牌色脉冲骨架屏
