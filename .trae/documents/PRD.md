## 1. 产品概述

新时代健康产业专属展业协同平台，围绕"人-货-场"重构直销业务数字化体系，服务直销员、生活馆店主与总部运营团队三大核心角色。
- 解决传统直销展业效率低、合规风险高、数据孤岛严重等痛点，实现全链路数字化协同
- 目标价值：提升直销员展业效率300%，降低合规风险事件90%，实现总部-区域-终端三级数据穿透

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 直销员 | 邀请码注册 | 个人展业空间、客户管理、分享追踪、培训学习、业绩查看 |
| 生活馆店主 | 总部审核注册 | 生活馆管理、预约服务、库存管理、服务记录、评价管理 |
| 总部运营 | 系统分配 | 产品全生命周期管理、合规风控配置、课件下发、数据看板、促销引擎 |

3. **产品中心（货）**: 产品列表、批次溯源、库存同步、促销活动管理
4. **生活馆（场）**: 生活馆列表、预约到店、服务记录、客户评价聚合
5. **合规风控**: 敏感话术识别、收入提现校验、地理围栏管理
6. **培训激励**: 课件中心、考试题库、业绩排行榜
7. **数据看板**: 团队裂变图谱、产品动销分析、区域饱和度预警

## 3. 核心流程

### 3.1 直销员展业流程
直销员登录 → 进入个人展业空间 → 生成专属二维码/分享内容 → 客户扫码进入 → 传播追踪记录转化 → 客户关系图谱自动更新 → 合规风控实时监测

### 3.2 产品管理流程
总部创建产品 → 设置批次信息 → 分配库存至生活馆 → 配置促销活动规则 → 直销员推广 → 批次溯源可查 → 库存实时同步

### 3.3 生活馆服务流程
客户预约到店 → 生活馆确认预约 → 提供服务并记录 → 客户提交评价 → 评价聚合分析 → 服务质量改进

### 3.4 合规风控流程
展业行为触发 → AI实时话术检测 → 违规内容标记 → 地理围栏校验 → 收入提现反洗钱校验 → 风险预警通知 → 整改跟踪

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 翡翠绿 (#059669) 象征健康产业活力，辅以深炭灰 (#1F2937) 体现专业沉稳
- **辅助色**: 琥珀金 (#D97706) 用于警示和强调，珊瑚红 (#DC2626) 用于风控预警
- **按钮风格**: 圆角8px，主按钮填充色+悬停加深，次要按钮描边风格
- **字体**: 标题使用 Noto Serif SC 衬线体体现品牌质感，正文使用 Noto Sans SC 无衬线体保证可读性
- **布局风格**: 左侧固定导航栏 + 顶部信息栏 + 主内容区，卡片式布局
- **图标风格**: Lucide线性图标，2px描边，与整体简洁风格统一
- **数据可视化**: 渐变色图表、热力地图、关系图谱采用力导向布局

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页仪表盘 | 数据概览 | 4列统计卡片（图标+数字+趋势线），翡翠绿渐变背景头部 |
| 首页仪表盘 | 业绩快报 | 面积图+柱状图组合，深色主题图表区 |
| 首页仪表盘 | 待办事项 | 列表卡片，左侧色条标记优先级，悬停展开详情 |
| 展业空间 | 个人主页 | 左侧头像+信息卡，右侧二维码+数据统计，渐变品牌背景 |
| 展业空间 | 客户图谱 | 全屏力导向图，节点大小表示客户价值，连线表示关系 |
| 产品中心 | 产品列表 | 网格卡片布局，产品图+基本信息+溯源按钮 |
| 产品中心 | 促销引擎 | 时间轴+规则卡片，拖拽式条件配置 |
| 生活馆 | 预约到店 | 日历视图+时段选择器，状态色彩编码 |
| 合规风控 | 话术识别 | 左侧对话列表，右侧AI标注面板，违规词高亮标红 |
| 数据看板 | 裂变图谱 | 树形层级图+热力节点，可缩放钻取 |
| 数据看板 | 饱和度预警 | 地图热力层+右侧预警列表，琥珀金渐变警示 |

### 4.3 响应式设计

- 桌面优先（1440px基准），适配1280px/1024px断点
- 侧边栏在1024px以下折叠为图标模式
- 数据图表在移动端简化为关键指标展示
- 客户图谱等复杂组件仅桌面端完整展示，移动端提供简化列表

### 4.4 动效设计

- 页面切换：淡入+微上移（200ms ease-out）
- 数据加载：骨架屏闪烁→内容渐显
- 卡片悬停：微上浮+阴影加深（transform 2px, shadow transition）
- 图表渲染：数据从零生长动画（800ms ease-out）
- 导航高亮：左侧色条滑入效果
- 风控预警：脉冲红色边框动画
