## 1. 产品概述

面向公交/客运/物流行业的实时车辆位置与运行状态监控服务平台，接入GPS/北斗终端数据流，支持JT/T 808、GB/T 35658等多协议解析，提供Web控制台实现车辆轨迹回放、电子围栏告警、异常停驻识别、班次准点率统计、驾驶员行为分析等核心能力。

- 目标用户：公交集团、客运公司、物流企业的调度员/管理员/安全员
- 核心价值：实时掌握车辆运行状态，降低安全风险，提升调度效率和运营透明度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 集团管理员 | 系统初始化分配 | 全集团数据查看、组织管理、系统配置 |
| 分公司管理员 | 集团管理员创建 | 本分公司及下属车队数据查看与管理 |
| 车队调度员 | 上级管理员创建 | 本车队车辆监控、调度、告警处理 |
| 安全员 | 上级管理员创建 | 驾驶员行为分析、告警审核、围栏管理 |
| API调用方 | 管理员授权 | 通过API网关调用指定接口 |

### 2.2 功能模块

1. **实时监控大屏**：车辆在线/离线统计、告警汇总、地图全局态势
2. **实时监控地图**：地图展示全部车辆实时位置、方向、速度，点击查看详情
3. **轨迹回放**：按时间段回放指定车辆行驶轨迹，支持倍速、暂停
4. **电子围栏**：围栏绘制/编辑/删除，围栏进出告警规则配置
5. **告警中心**：围栏告警、异常停驻、超速、疲劳驾驶等统一告警列表
6. **班次准点率**：线路班次计划管理、到站准点率统计报表
7. **驾驶员行为分析**：急加速/急刹车/疲劳驾驶事件统计与详情
8. **设备管理**：终端绑定、固件升级任务、离线状态监控
9. **组织管理**：集团-分公司-车队三级组织树与用户权限
10. **API网关**：第三方调用密钥管理、接口调用统计与限流

## 3. 核心流程

### 3.1 实时监控流程

用户登录后进入监控大屏，系统通过WebSocket推送车辆实时位置更新。地图自动刷新车辆标记位置，当有新告警时在滚动条和右上角通知提示。用户可点击车辆查看详情，或切换至监控地图页面按组织筛选。

```mermaid
flowchart TD
    "用户登录" --> "进入监控大屏"
    "进入监控大屏" --> "WebSocket连接建立"
    "WebSocket连接建立" --> "接收车辆位置推送"
    "接收车辆位置推送" --> "地图标记更新"
    "接收车辆位置推送" --> "告警检测引擎"
    "告警检测引擎" --> "围栏越界告警"
    "告警检测引擎" --> "异常停驻告警"
    "告警检测引擎" --> "超速告警"
    "围栏越界告警" --> "告警中心展示"
    "异常停驻告警" --> "告警中心展示"
    "超速告警" --> "告警中心展示"
    "告警中心展示" --> "调度员处理"
    "调度员处理" --> "告警状态流转"
```

### 3.2 轨迹回放流程

用户选择车辆和时间段，系统查询历史定位数据，在地图上绘制轨迹线，提供播放控制。

```mermaid
flowchart TD
    "选择车辆" --> "选择时间段"
    "选择时间段" --> "查询历史轨迹数据"
    "查询历史轨迹数据" --> "绘制轨迹线"
    "绘制轨迹线" --> "播放控制"
    "播放控制" --> "播放/暂停"
    "播放控制" --> "倍速切换"
    "播放控制" --> "进度拖动"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰(#0f1923)背景 + 青蓝(#00d4ff)科技感强调色 + 橙红(#ff6b35)告警色
- **次色调**：深灰(#1a2332)卡片背景 + 翠绿(#00e676)在线/正常状态 + 靛蓝(#5c6bc0)辅助
- **按钮风格**：圆角微凸，主要操作使用青蓝填充，危险操作使用橙红
- **字体**：数据/标题使用 DIN Alternate 风格等宽体，正文使用 Source Han Sans / Noto Sans SC
- **布局风格**：左侧导航栏 + 顶部信息栏 + 主内容区，地图占据主要视觉空间
- **图标风格**：线性图标(lucide)，2px描边，统一科技感
- **氛围**：暗色大屏监控风格，数据可视化为主，地图为视觉中心

### 4.3 响应式设计

- 桌面优先设计，最小支持1366px宽度
- 地图区域自适应容器尺寸
- 表格在窄屏下启用横向滚动
- H5移动端：简化布局，重点支持实时监控和告警查看

### 4.4 动效设计

- 页面加载：数据卡片数字滚动动画
- 地图：车辆标记平滑移动过渡
- 告警：新告警闪烁提示，列表项入场动画
- 轨迹回放：轨迹线渐显绘制效果
- 页面切换：左侧导航高亮过渡
