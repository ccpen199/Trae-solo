## 1. 产品概述

速驿通——面向快递员与末端网点经营者的物流作业协同工作台，支持跨2100+快递公司的统一揽收调度与网点数字化管理。系统整合多源面单云打印、客户关系追踪、协议客户管理、物流轨迹聚合查询与网点经营看板，内置三级角色权限隔离与操作留痕，满足邮政行业数据合规要求。

- 目标用户：末端网点经营者、快递员、区域主管
- 核心价值：将碎片化的多快递公司操作统一到单一工作台，降低网点运营复杂度，提升揽收效率与客户复购率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 快递员 | 网点管理员邀请注册 | 揽收作业、轨迹查询、面单打印、个人业绩查看 |
| 网点管理员 | 平台自主注册 | 全部快递员权限 + 客户管理、员工分账对账、经营看板、面单模板配置 |
| 区域主管 | 上级指派注册 | 多网点经营看板、区域热力分析、跨网点客户与业绩对比、合规审计 |

### 2.2 功能模块

1. **工作台首页**：今日揽收概览、待办任务队列、快捷入口、实时公告
2. **面单云打印中心**：多源面单模板管理、PC/移动端双端打印驱动、批量打印队列
3. **客户关系管理**：手机号/二维码客户绑定、复购追踪、协议客户档案、客户分群标签
4. **智能录单**：批量下单、OCR识别录单、历史录单回溯
5. **物流轨迹聚合**：多快递公司轨迹统一查询、异常件预警、时效分析
6. **网点经营看板**：日揽件量趋势、区域热力图、客户留存率、面单耗材统计
7. **分账对账中心**：员工分账规则配置、对账报表、结算明细
8. **系统设置**：角色权限管理、操作日志审计、数据合规设置

## 3. 核心流程

### 3.1 揽收作业主流程

快递员登录后从工作台接收待揽收任务，到达客户处后扫描包裹或手动录入信息，系统自动匹配快递公司面单模板并调用云打印生成面单，快递员贴单后确认揽收，系统同步更新轨迹并记录客户交互。

```mermaid
flowchart TD
    "快递员登录" --> "查看待揽收任务"
    "查看待揽收任务" --> "到达客户处"
    "到达客户处" --> "扫描/录入包裹信息"
    "扫描/录入包裹信息" --> "系统匹配面单模板"
    "系统匹配面单模板" --> "云打印生成面单"
    "云打印生成面单" --> "贴单确认揽收"
    "贴单确认揽收" --> "轨迹同步更新"
    "轨迹同步更新" --> "客户交互记录"
```

### 3.2 客户绑定与复购追踪流程

客户首次寄件通过手机号自动建档，系统生成专属二维码供后续扫码绑定，每次寄件自动关联客户档案并更新复购数据，协议客户到期前自动提醒续签。

```mermaid
flowchart TD
    "客户首次寄件" --> "手机号自动建档"
    "手机号自动建档" --> "生成专属二维码"
    "生成专属二维码" --> "后续扫码绑定"
    "后续扫码绑定" --> "寄件自动关联档案"
    "寄件自动关联档案" --> "复购数据更新"
    "复购数据更新" --> "协议到期提醒"
```

### 3.3 网点经营管理流程

网点管理员通过经营看板实时监控揽件量与区域分布，结合客户留存率与耗材统计调整运营策略，定期查看分账对账报表确保结算准确。

```mermaid

    "查看经营看板" --> "监控客户留存"
    "查看经营看板" --> "统计面单耗材"
    "分析揽件量趋势" --> "调整运营策略"
    "查看区域热力" --> "调整运营策略"

    "统计面单耗材" --> "调整运营策略"
    "调整运营策略" --> "查看分账对账"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1A2332）+ 橙色点缀（#FF6B35），体现物流行业的专业与活力
- 辅助色：浅灰背景（#F5F6FA）、白色卡片、绿色状态（#22C55E）、红色警告（#EF4444）
- 按钮风格：圆角8px，主按钮实色填充，次按钮描边，带微妙阴影
- 字体：数字/数据使用 DIN Alternate 等量级字体，正文使用 Noto Sans SC
- 布局风格：左侧固定导航栏 + 顶部面包屑 + 主内容区卡片式布局
- 图标风格：线性图标，2px描边，统一视觉语言

### 4.3 响应式设计

- 桌面端优先（1440px+），适配1280px/1024px断点
- 移动端适配：导航栏折叠为底部Tab，卡片单列布局，打印功能适配移动端驱动
- 触控优化：按钮最小触控区域44px，滑动操作支持
