# 短视频应用产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
构建一个完整的短视频平台，涵盖内容消费（刷视频）和内容创作（拍摄发布）全链路。

### 1.2 项目目标
- 实现流畅的视频浏览体验（推荐、附近、关注）
- 提供完整的视频创作工具链（拍摄、编辑）
- 支持社交互动（评论、点赞、分享、关注）
- 完善的用户认证和权限管理

## 2. 用户角色

| 角色 | 描述 | 权限 |
|------|------|------|
| 游客 | 未登录用户 | 仅可浏览推荐/附近视频 |
| 普通用户 | 已登录用户 | 完整功能权限 |
| 管理员 | 运营人员 | 后台管理权限 |

## 3. 功能模块

### 3.1 用户认证模块

| 功能 | 描述 | 约束 |
|------|------|------|
| 登录 | 手机验证码、第三方授权、手机密码 | 未登录自动跳转 |
| 注册 | 手机号注册 | 短信验证码验证 |
| 找回密码 | 滑块验证 + 短信验证码 + 重置密码 | 多重验证 |
| 权限控制 | 关注、点赞、评论、聊天、制作视频、查看消息、个人主页需登录 | 401 自动跳转 |

### 3.2 首页推荐模块

| 功能 | 描述 | 交互 |
|------|------|------|
| 全屏播放 | 后台推荐视频全屏播放 | 点击暂停/播放 |
| 视频切换 | 上下滑动切换视频 | 流畅过渡动画 |
| 作者主页 | 左滑进入作者主页 | 滑动手势 |
| 附近页面 | 右滑进入附近页面 | 滑动手势 |

### 3.3 附近页面模块

| 功能 | 描述 | 约束 |
|------|------|------|
| 定位城市 | 基于定位展示视频 | 可手动切换城市 |
| 距离排序 | 按距离展示视频封面 | 网格布局 |
| 视频详情 | 点击封面进入全屏播放 | 与推荐页一致 |

### 3.4 关注页面模块

| 功能 | 描述 | 约束 |
|------|------|------|
| 时间倒序 | 关注对象视频按时间倒序 | 最新优先 |
| 发布者信息 | 展示头像、昵称、发布时间 | 可取消关注 |
| 视频操作 | 播放、点赞、评论、分享 | 评论输入框 |
| 视频信息 | 时长、点赞数、评论数 | 实时更新 |

### 3.5 拍摄编辑模块

#### 拍摄页功能
- 音乐选择
- 摄像头翻转
- 拍摄速度调节
- 滤镜效果
- 美颜功能
- 时长选择（照片/15s/60s）
- 本地上传
- 道具特效

#### 编辑页功能
- 自动美颜
- 变声效果
- 滤镜调节
- 音乐剪辑
- 特效添加
- 文字贴纸
- 发布设置

### 3.6 社交互动模块

| 功能 | 描述 |
|------|------|
| 点赞 | 视频点赞/取消点赞 |
| 评论 | 发表评论、查看评论列表 |
| 分享 | 视频分享功能 |
| 关注 | 关注/取消关注用户 |

## 4. 非功能需求

### 4.1 性能要求
- 页面加载时间 < 2s
- 视频切换流畅无卡顿
- API 响应时间 < 500ms

### 4.2 安全要求
- 用户密码加密存储
- API 接口鉴权
- SQL 注入防护
- XSS 攻击防护

### 4.3 兼容性要求
- 主流浏览器支持（Chrome、Safari、Firefox、Edge）
- 响应式设计，支持移动端

## 5. 数据模型

### 核心数据表
1. users - 用户表
2. videos - 视频表
3. comments - 评论表
4. likes - 点赞表
5. follows - 关注表
6. messages - 消息表

## 6. 验收标准

- 所有核心功能正常运行
- 未登录用户权限控制正确
- 视频播放流畅无卡顿
- 数据持久化到 SQLite 数据库
- 前后端联调成功
