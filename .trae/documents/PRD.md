## 1. 产品概述
轻量级任务型用户增长与激励中台，通过步数计数、视频完播、签到、邀请好友等行为激励用户获取金币，金币按阶梯汇率兑换现金并支持T+0提现至微信零钱，核心目标为提升DAU与分享裂变率。
- 目标用户：注重收益的移动端用户群体，追求零花钱补贴的年轻用户
- 核心价值：通过任务激励机制驱动用户活跃与社交裂变，实现低成本获客与高效留存

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 微信授权登录 | 完成任务、赚取金币、提现、邀请好友 |
| 运营管理员 | 后台账号分配 | 任务配置、数据看板、风控管理、广告SDK配置 |

### 2.2 功能模块

#### 用户端（C端）
1. **首页/任务中心**：任务入口聚合、金币余额展示、热门活动Banner、快捷签到入口
2. **步数赚钱页**：步数数据同步、步数-金币转换、每日步数目标进度
3. **视频任务页**：视频列表、完播检测、金币奖励弹窗
4. **签到日历页**：连续签到奖励、补签机制、签到日历可视化
5. **邀请好友页**：邀请码/链接生成、邀请关系链展示、多级返佣明细
6. **钱包页**：金币余额、阶梯汇率展示、兑换操作、提现记录、T+0提现至微信

#### 管理端（B端后台）
1. **数据看板**：DAU趋势、任务ROI分析、获客成本、留存率、变现转化率
2. **任务管理**：任务创建/编辑、限时活动配置、节日专题、地域定向投放
3. **用户管理**：用户列表、风险标签、LTV预测评分、异常行为标记
4. **风控中心**：提现拦截规则引擎、设备指纹异常、行为序列告警、IP限频配置
5. **广告管理**：穿山甲/优量汇SDK配置、广告位管理、收益统计

## 3. 核心流程

### 3.1 用户任务完成与金币获取流程
用户打开APP → 查看任务中心 → 选择任务类型（步数/视频/签到/邀请）→ 完成任务行为 → 系统验证（防刷检测）→ 发放金币 → 金币到账通知

### 3.2 金币兑换与提现流程
用户进入钱包 → 查看金币余额与阶梯汇率 → 选择兑换金额 → 确认兑换 → 风控规则引擎校验 → 提现至微信零钱（T+0到账）

### 3.3 邀请裂变流程
用户生成邀请码/链接 → 分享至社交平台 → 新用户通过链接注册 → 系统自动绑定邀请关系 → 新用户完成首任务 → 邀请人获得一级返佣 → 新用户再邀他人 → 邀请人获得二级返佣

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：金色渐变（#FFD700 → #FFA500）象征金币与收益，搭配深色背景（#1A1A2E）营造高端金融感
- **辅助色**：翡翠绿（#00C853）用于收益增长指标，珊瑚红（#FF5252）用于限时/紧急提示
- **按钮风格**：圆角胶囊按钮，金色渐变主按钮带微光效果，次级按钮半透明描边
- **字体**：标题使用 DIN Alternate（数字展示感强），正文使用 PingFang SC
- **布局风格**：卡片式布局，底部Tab导航，顶部渐变状态栏
- **图标风格**：线性+微渐变图标，金币/钱袋等收益相关图标带闪光动效
- **整体调性**：轻奢金融风，暗色主题搭配金色点缀，强调收益可视化的即时反馈感

### 4.3 响应式策略
- Desktop-first设计，C端页面适配移动端（375px起）与桌面端
- B端后台以桌面端为主（1280px+），最小支持1024px
- 触控优化：按钮最小44px触控区域，卡片点击热区充足
