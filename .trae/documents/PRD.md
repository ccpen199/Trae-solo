## 1. 产品概述

广西全域数字生活操作系统是一体化整合政务、交通、医疗、文旅、金融五域服务的省级数字平台，面向公职人员、企业法人、市民、游客四类角色提供千人千面的服务入口。系统以统一身份中枢为信任基石，以服务聚合引擎为智能调度核心，以跨域通办通道打破行政壁垒，实现"一屏览八桂、一码通全域"的数字生活愿景。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 认证方式 | 核心权限 |
|------|----------|----------|
| 公职人员 | 广西政务云统一认证 | 政务OA、公文交换、会议纪要、任务督办 |
| 企业法人 | 电子营业执照+法人实名 | 营业执照调用、政策精准推送、补贴申领 |
| 市民 | 实名认证+人脸核身 | 医保电子凭证、社保查询、高龄补贴、新生儿免证办 |
| 游客 | 手机号+第三方登录 | 多语种导览、景区预约、跨境支付、投诉直连 |

### 2.2 功能模块

1. **千人千面首页**: 基于LBS与用户画像的智能服务聚合，动态展示最相关服务
2. **统一身份中枢**: 对接广西政务云+银联+微信/支付宝的统一认证与角色切换
3. **智政办公**: 公文智能摘要、会议纪要生成、任务督办看板
4. **智游八桂**: 景区预约限流预警、小众路线AI规划、文旅投诉直连
5. **智惠民生**: 高龄补贴自动申领、新生儿出生免证办、医保社保查询
6. **运营监测中心**: 各厅局API响应SLA监测、政策兑现追踪审计

## 3. 核心流程

**市民异地就医流程**：市民登录 → 身份核验 → 选择异地就医备案 → 系统自动同步全国医保平台 → 备案通过 → 跨市就医直接结算

**游客景区游览流程**：游客进入智游八桂 → LBS定位推荐附近景区 → 查看实时客流 → 选择时段预约 → AI规划个性化路线 → 游览中多语种导览 → 问题投诉直连文旅局

**企业政策兑现流程**：企业法人登录 → 政策精准推送匹配 → 查看可享补贴 → 一键申领 → 后台追踪到账时效 → 审计报表生成

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深靛蓝(#1a365d) + 翠绿(#2d8a56) 呼应广西山水人文，辅以暖金(#d4a843)点缀重要操作
- **按钮风格**: 圆角8px，主按钮渐变色，悬浮时微上浮+阴影加深
- **字体**: 标题使用"思源宋体"风格衬线字体体现政务庄重感，正文使用无衬线字体保证可读性
- **布局**: 左侧固定导航 + 右侧内容区，卡片式布局，数据可视化区域适当使用深色背景
- **图标**: 线性图标为主，景区等文旅模块使用彩色插画图标
- **动效**: 页面切换淡入、卡片悬浮微动、数据加载骨架屏、关键指标数字滚动动画

### 4.3 响应式设计

- 桌面优先设计，主要适配1920×1080和1440×900分辨率
- 平板端(768-1024px)左侧导航折叠为图标模式，卡片从多列变为双列
- 移动端(<768px)底部Tab导航，卡片单列堆叠，表格转为卡片列表

### 4.4 动效设计

- 页面加载：骨架屏 → 内容淡入（stagger 50ms）
- 卡片悬浮：translateY(-4px) + shadow-lg + 0.2s ease
- 数据指标：数字从0滚动到目标值，持续1s ease-out
- 导航切换：内容区fade + slide-right 0.3s
- 告警状态：红色脉冲动画 2s infinite
